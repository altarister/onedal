# 인성플렉스 페이지표

실물 인성플렉스 앱(`insung.quickflex`)의 페이지 · 팝업을 하나도 빼지 않고 적는다 — 정의 표(`networkPages.isflex`)와 시뮬레이터 화면을 만들 재료.

- 사진: 같은 폴더의 `NN_이름.png` (adb screencap)
- 받은 글자: `NN_이름.xml` (`uiautomator dump` — 원달앱이 받는 것과 같은 접근성 글자). 🔴 뽑을 때마다 원달앱 접근성이 끊겼다 붙는다 — 운행 중에는 쓰지 않는다
- 받는 동안 원달앱은 **직접 모드**(아무것도 안 누름). 🔴 확정 · 배차 단추는 누르지 않는다 — 실물 계약이 된다
- 공통 = 기준 페이지 자리 · 세 배차망과 같은 규칙 / 플러그인 = 인성플렉스만의 글자 · 칩 · 칸

## 원달앱 기록에서 본 것

- 원달앱은 지금 이 앱 화면을 «배차망 밖 앱»(OTHER_APP)으로 보고 화면 글자를 남기지 않는다. 누른 단추 글자만 남는다(«변경» · «출근하기» · «지도» — 사진의 글자와 같다).
- `uiautomator dump` 뒤 원달앱 접근성 서비스가 다시 붙는다(«1DAL 서비스 가동 완료» · 블루투스 다시 붙음).

## 목록 글자에서 본 것 (공통 규칙에 닿는 것)

- 예약 · 시각 모양이 줄마다 다르다: «@낼08:20/수원이의동» · «@낼8:30)방배동» · «@낼09시/충무로5가» · «@남대문로2가»(시각 없는 «@») — 공용 예약 읽기(`core/ReservationText.kt`)의 «낼» · «HH:MM» · «N시»로 읽힐 모양이다. «@»만 있는 줄의 뜻 → 12 에서 풀림: «@»는 예약이 아니라 출발지 표시(늘 붙음)
- 도착지 앞 «10:20전/» — 하차 마감 시각(«전»). 공용 예약 읽기는 상차 쪽 글자만 보므로 날짜를 잘못 바꾸지 않는다 · 하차 마감으로 쓸지는 따로 정할 일
- 접근성은 칸마다 따로 준다(웹뷰처럼 한 덩어리로 붙지 않는다) — 칸 이름(resource-id)이 있어 파서가 칸을 고르기 쉽다
- 칸 머리 «출발지까지(km)»의 줄바꿈은 글자 안에 줄바꿈 문자로 온다
