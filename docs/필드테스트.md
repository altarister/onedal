## 1-5. 돌아와서 — 로그 회수 (**당일에 한다**)

🔴 **서버 로그는 3일 뒤 지워지고, 폰 logcat 버퍼는 4~5시간이면 돈다.** 미루면 사라진다.

```bash
OUT=~/Desktop/1dal-주행로그-$(date +%Y%m%d); mkdir -p "$OUT"/{raw,표,폰로그}

# ① 서버 (EC2)
scp -i ~/.ssh/onedal_mac_key ubuntu@<EC2_IP>:.pm2/logs/onedal-web-server-out-0.log   "$OUT/raw/server-out.log"
scp -i ~/.ssh/onedal_mac_key ubuntu@<EC2_IP>:.pm2/logs/onedal-web-server-error-0.log "$OUT/raw/server-error.log"
scp -i ~/.ssh/onedal_mac_key ubuntu@<EC2_IP>:onedal/onedal/onedal-web/server/data.db{,-wal,-shm} "$OUT/raw/"

# ② 폰 (USB · 각각 꽂아서)
adb -s <A24> logcat -d -v time > "$OUT/폰로그/A24_원달앱_logcat_전체.log"
adb -s <S23> logcat -d -v time > "$OUT/폰로그/S23_관제앱_logcat_전체.log"
```

⚠️ **`adb kill-server` 를 함부로 하지 않는다** — 인증이 풀려 폰에서 다시 "허용"을 눌러야 한다.

### 🔴 발견 1 — 콜 카드가 **빈 껍데기**로 잡힌다 (최우선)

`💸 [요금 못 읽음]` 뒤가 **공백**이다. 요금을 못 읽은 게 아니라 **카드에 글자가 하나도 없다.**
한 번 스캔에 **약 30개**씩 빈 카드가 나온다 (12,467 ÷ 413).

```kotlin
// InsungParser.kt:500  groupListNodes
val fareNodes = allNodes.filter { it.text.matches(차종정규식) }  // 차종 글자로 카드를 찾고
val rowNodes  = allNodes.filter { y좌표가 겹치는 것 }             // 같은 줄 글자를 묶는다
```

**필터가 나쁜 게 아니었다. 필터까지 갈 기회조차 없었다.**

가설(미확정): ① `rect` 가 비어 y 비교가 아무것도 못 고른다 ② 정규식이 화면의 딴 글자에
걸려 가짜 카드를 만든다 ③ 웹뷰 스크롤로 노드가 재사용되며 좌표가 어긋난다.

→ 확인하려면 **그룹의 좌표와 원본 노드 수**를 로그에 같이 남겨야 한다.
  지금 로그는 *"비었다"* 까지만 말하고 *"왜 비었나"* 는 안 말한다.
