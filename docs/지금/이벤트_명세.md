# 이벤트 명세 — 앱·서버·관제웹의 모든 이벤트 (6하원칙 + 결과)

> **2026-08-17 코드 실측.** 원천은 코드다 — `pnpm map`(소스 추출)·`pnpm audit:socket` 이 살아 있는
> 지도이고, 이 문서는 거기에 **언제·왜·결과**를 붙인 스냅샷이다. 코드가 바뀌면 `pnpm map` 으로 대조할 것.
>
> - 용어는 [용어집](용어집.md)을 따른다. 코드 로그의 `판결` 은 용어집의 **결재**와 같은 말이다 (통일 후보)
> - 빈칸 = 아직 확인 못 함 (지어내지 않는다)
> - ⚠ = 짝이 없는 이벤트 (죽은 문 후보)

## 1. 큰 그림 — 통신은 세 길뿐이다

```
앱 ──── REST ───▶ 서버              앱은 소켓을 안 쓴다 (모바일 웹소켓 끊김 회피)
앱 ◀── 피기백 ─── 서버              서버는 앱을 먼저 못 부른다 — 응답 꼬리에 실어야 한다
서버 ◀── Socket.IO ──▶ 관제웹       io.to(userId) 개인 룸 — 전역 방송 0곳
```
