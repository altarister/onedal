# D. 이 문서를 어떻게 쓸 것인가

🔴 **한 번 찍고 끝이 아니다.** 이 문서의 값어치는 «지금 맞추는 것»이 아니라
**«다음에 내가 틀린 전제로 판을 짜기 전에 여기서 걸리는 것»** 이다.

👉 **판을 시작할 때 규칙** (제안):
   기획서 맨 앞에 **«이 판이 참이라고 보는 전제»** 를 적고, 이 표의 번호를 가리킨다.
   표에 없는 새 전제면 **여기에 줄을 하나 더한다.**

⚠️ **이걸 해도 다 안 나온다.** 내가 «묻지 않은 것»은 목록에도 없다.
   그래도 하나씩 부딪히는 것보다 낫고, 위 규칙이 나머지를 잡는다.
