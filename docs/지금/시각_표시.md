# 시각 표시 — 정거장 하나의 시각을 어떻게 그리나

> **아웃풋을 안 정해서 혼란스러웠다.** (기사님 2026-08-30)
>
> 지금 화면은 같은 자리에 「약속」과 「도착 예상」과 「밀린 분」을 섞어 적는다.
> 그래서 `신둔면 ~03:15 +5분` 처럼 **한 줄이 두 말을 하는** 화면이 나왔다.
>
> 🔴 이 문서는 규칙 ⑤-4 의 **④ 화면**을 확정하는 자리다.
> 여기가 비어 있으면 화면이 조용히 거짓말한다. **정해지기 전에 코드를 고치지 않는다.**
>
> 말의 원천은 [용어집](용어집.md) · 시각을 만드는 규칙은 [판정](판정.md) 과
> `shared/src/timing.ts` 의 `deriveRouteTimeline` 하나다 (규칙 ③).

## 이 문서의 상태

✅ **모양은 확정됐다** (기사님 2026-08-30) — 다섯 안을 견주어 골랐다.

```
접힌 줄   안 C — 기호로만          «틀어졌나»만 답한다
펼친 카드  안 A — 화살표로 전부      «원래 몇 시라 했지»를 답한다
```

⬜ 아직 남은 것: ⑩ 「부터~까지」 구간 약속 · ⑪ 예약 콜 · ⑫ 상차는 지켰는데 하차만 밀림 ·
⑬ 심사 중 후보콜 — **그릴지 말지 미정.**

---

## 1. 시각 하나가 가진 네 축

| 축 | 값 | 어디서 오나 |
|---|---|---|
| **출처** | 추정 · 통화 확정 · 실측(다녀옴) | `promiseConfirmed` · `occurred_at` |
| **움직임** | 그대로 · 밀림(+) · 당겨짐(−) | `dwellShiftMinutes` |
| **위험** | 여유 · 빠듯 · 지각 | `lateMinutes` |
| **재료** | 있음 · 모름 | `driveMinutes` · `soloMinutes` 가 `null` 인가 |

🔴 **넷은 섞이지 않는다.** 「추정인데 밀렸고 지각이다」가 동시에 참일 수 있다.
한 축을 다른 축의 색으로 그리면 화면이 두 말을 한다 — 이번에 그렇게 났다.

## 2. 무엇이 화면에 적히는 값인가

**적히는 것은 「약속」이다.** 도착 예상이 아니다.

```
약속   화주와의 것. "몇 시까지 갈게요"          ← 화면의 숫자
예상   내가 그때 거기 있을 것 같은 시각          ← 약속과 견주는 데 쓴다
```

둘이 벌어지면 그게 **지각(⑥)** 이고, 약속 자체가 움직이면 그게 **밀림(④⑤)** 이다.

> 🔴 2026-08-30 에 이 구분을 안 해서 사고가 났다. 약속 옆에 「도착 예상 밀림」을
> 붙였더니 **약속은 30분 당겨졌는데 화면은 「+5분」** 이라 적었다.
> 지금은 실측이 약속까지 밀어서 둘이 같은 말을 한다 (`sheetEditMinutes.test.ts` 가 묶는다).

## 3. 경우와 표현

기사님이 꼽으신 셋(①④⑥)에 코드가 이미 하는 것과 빠진 것을 채웠다.

| # | 언제 | 화면 | 색 (⬜ 미확정) |
|---|---|---|---|
| ① | 최초 — 추정만 | `~2:20` | 회색 |
| ② | 통화로 확정 | `2:20` (물결 없음) | 기본 |
| ③ | 통화로 시각이 바뀜 | `~2:20 → 2:40` | 기본 |
| ④ | 합짐·실측으로 밀림 | `2:20 → 2:50 (+30)` | 주황 |
| ⑤ | 당겨짐 | `2:20 → 2:10 (−10)` | 초록 |
| ⑥ | 밀려서 **약속을 넘김** | `2:20 → 2:35 (+15) ⚠️` | 빨강(저채도) |
| ⑦ | 이미 다녀옴 | `2:18` | 흐림 |
| ⑧ | 건너뜀 (통화·도착 안 찍음) | `~2:20 (안 함)` | 회색 점선 |
| ⑨ | 재료가 없음 | `주행 모름` | 회색 |

### ⬜ 기사님 확인이 필요한 넷

**⑩ 「부터~까지」 구간 약속** — *"12시부터 12시 30분 사이"*.
칸은 이미 있다(`promised_arrival_from_at`). 지금 화면은 **「까지」만** 그린다.
```
2:20~2:50
```

**⑪ 예약 콜** — 노하우 자료의 *"10시 예약"*. 지금 가도 못 싣는다.
**기다리는 시간**이라 밀림(④)과 뜻이 다르다. 같은 주황으로 칠하면 «문제»로 읽힌다.
```
2:20 (10시 예약 · 대기)
```

**⑫ 한 콜 안에서 상차는 지켰는데 하차만 밀림**
지금은 두 시각이 따로 그려져 «이 콜이 괜찮은가»를 한눈에 못 본다.

**⑬ 심사 중 후보콜** — 아직 경로에 없어 **혼자 갔을 때** 값으로 그린다.
잡으면 바뀌는데 화면에 그 구분이 없다.

## 3-1. ✅ 확정된 모양

기사님 화면의 한 줄은 **한 콜**이다 — 정거장별로 줄을 늘리지 않는다.

```
1 곤지암읍 ~21:12 → 관고동 ~21:48        ← 지금 모양. 이걸 유지한다
```

### 접힌 줄 — 안 C

```
1 초월읍 2:33· → 신둔면 3:20▲
2 곤지암읍 2:40 → 관고동 3:44▲⚠️3
```

**기호 어휘** — `~` 는 이미 쓰던 것이고, 새로 외울 것은 `▲▼` 둘뿐이다.

| 기호 | 뜻 | 축 |
|---|---|---|
| `~3:20` | 통화 전 **추정** | 출처 |
| `3:20` | 통화로 **확정** (물결 없음) | 출처 |
| 흐리게 | **다녀옴** — 지난 일이다 | 출처 |
| `▲` | 예측보다 **밀림** | 움직임 |
| `▼` | 예측보다 **당겨짐** | 움직임 |
| `⚠️N` | 약속을 **넘김**(지각) — N분 | 위험 |

🔴 **밀린 분(숫자)은 접힌 줄에 안 적는다.** 달리면서 필요한 답은 «틀어졌나» 하나다.
   몇 분인지는 통화하려고 펼칠 때 필요하다.

### 펼친 카드 — 안 A

```
초월읍   2:20 → 2:33          다녀옴
신둔면   3:15 → 3:20 (+5)
```

원래 값과 지금 값을 **둘 다** 적는다. 통화의 대사가 거기서 나온다 —
*"원래 3시 15분이라 했는데 20분쯤 되겠습니다."*

### 왜 이 조합인가

| 언제 | 필요한 답 | 어느 것 |
|---|---|---|
| 달리다 먼발치로 | *"틀어졌나"* | 접힌 줄 (기호 하나) |
| 통화하려고 펼칠 때 | *"원래 몇 시라 했지"* | 펼친 카드 (화살표) |

폭도 이유였다 — 안 A 를 접힌 줄에 넣으면 시각이 넷이라 **지명이 잘린다.**
안 D 는 한 콜이 두 줄이 되어 3콜이면 여섯 줄이다.

## 4. 🔴 색은 판정 색과 겨루지 않는다

기사님은 **색만 보고 1~2초에 누른다**(규칙 ⑤-3). 판정이 이미 색을 쓴다:

```
🔵 꿀 · 🟢 보통 · 🟡 똥 · 🔴 사고        ← 이 색은 판정의 것이다
```

시각에도 순수한 빨강·파랑이 붙으면 **무엇의 색인지 헷갈린다.**
**그리고 지도가 이미 상차=초록 · 하차=빨강을 쓴다.**

| 쓰려던 색 | 이미 임자가 있다 |
|---|---|
| 초록 = 당겨짐 | **상차지** |
| 빨강 = 지각 | **하차지** · 판정 🔴 |
| 파랑 | 판정 🔵 |

셋 다 임자가 있다. → **시각의 움직임은 색이 아니라 기호로 말한다** (`▲▼`).
안 C 를 고른 이유가 하나 더 생긴 셈이다.

**⚠️ 지각만 빨강을 허용한다.** 그건 «하차지»라는 뜻의 빨강과 달리 **행동을 바꾸라는
신호**다 (자료: *"3~40분 남았을 때부터 도착지에 전화"*). 다만 지도의 하차지 점과
겹치지 않게 **글자 쪽에만** 쓴다.

## 5. 지금 안 되는 것

- ⬜ **순번은 아직 물음표다** — `?. 초월읍`. 시각은 장부로 폴백하게 고쳤지만(`stopTimeOfRecords`)
  번호(`visitOrderMap`)는 여전히 지금 경로에서만 찾는다. 끝난 콜에는 번호가 없다.

- ⑩⑪⑫⑬ 은 화면에 아예 없다.

- 🟢 밀림 기호(`▲`)가 경로 재계산 뒤에도 남는다. 계산에는 영향이 없고(표시 전용)
  하차 완료하면 사라지지만, *"아직도 밀려 있나?"* 로 읽힐 수 있다.

### ✅ 고친 것 (2026-08-30)

- **끝난 정거장의 시각이 사라지던 것** — 경로에 없으면 장부에서 읽는다.
  읽는 순서는 `stopTimeOfRecords` 하나다: **실제로 간 시각 > 통화로 굳힌 약속 > 없음.**
  카드 머리 줄과 펼친 블록이 같은 문으로 들어온다.

- **통화로 짐을 고쳐도 예측 정차가 안 따라가던 것** — 같은 콜의 두 행이 다른 예측을
  들고 있었다(`상차지 통화` 14분 / `상차 완료` 11분, 둘 다 라면박스 20개).
  이제 통화 저장이 `computeChain` 을 다시 돌려 그 행의 정차도 함께 고친다.
