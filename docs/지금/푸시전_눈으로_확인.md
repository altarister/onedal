## 0. 띄우기 — **이미 떠 있을 수 있습니다**

먼저 확인합니다. 나오는 게 있으면 **이미 떠 있는 것**이니 그냥 쓰시면 됩니다.

```bash
lsof -nP -iTCP:3000 -sTCP:LISTEN    # 관제웹
lsof -nP -iTCP:4000 -sTCP:LISTEN    # 서버
```

없으면 띄웁니다:

```bash
cd ~/reps/onedal/onedal-web && pnpm dev
```

떴는지: `curl -s localhost:4000/api/health | python3 -m json.tool` 의 `bootedAt` 이 **방금**인가.

### 🔴 **에이전트가 띄운 것은 기사님 터미널의 Ctrl+C 가 안 닿습니다**

기사님 2026-09-12: *"3000번을 너가 열었는데 이건 어떻게 내가 하지?"*

- ✅ **`pnpm lab`·`pnpm drive` 는 그냥 돌리시면 됩니다** —
  떠 있는 3000·4000 에 **붙는** 것이라 누가 띄웠든 상관없습니다
- 🔴 **껐다 켜야 할 때만** 포트를 쥔 것을 직접 죽입니다:

```bash
lsof -ti :3000 -ti :4000 | xargs kill        # 둘 다 내린다
cd ~/reps/onedal/onedal-web && pnpm dev      # 기사님 터미널에서 다시
```

  그 뒤로는 **기사님 터미널이 주인**이라 Ctrl+C 가 그대로 듣습니다.
  ⚠️ 내리면 **그 서버를 쓰던 다른 에이전트도 함께 잃습니다** — 확인만 하실 거면 안 내려도 됩니다.

## ① 지도 실험실 하나로 — 5분 (콜을 안 세워도 됩니다)

**주소: http://localhost:3000/mockup/map**

기사님 계정·콜을 **하나도 안 건드립니다.** 오늘 고친 궤적이 여기서 그대로 보입니다.

| 무엇을 누르나 | 보여야 하는 것 |
|---|---|
| **지도를 두 번 클릭** (▲상차 → ▼하차) | 콜 하나가 서고 오른쪽에 심사석이 뜬다 |
| 왼쪽 위 **🌅 볼트 오전** | 콜 일곱이 한 번에 선다 (문제지) |
| 오른쪽 위 **🚗 보통** 고르고 **▶️ 주행** | 내 위치가 경로를 따라 움직인다 (멈출 때는 같은 자리가 **⏸ 멈춤**) |
| 🔴 **주행하는 동안 지도를 확대** | **오늘 고친 것** — 지나온 자리에 **검은 실선**이 남는데, 그것이 **카카오 곡선 그대로**여야 한다. 각진 직선 토막이면 실패다 |
| 위 토글 **동선** 끄기/켜기 | 검은 실선만 사라지고 색 경로선은 남는다 |
| 위 토글 **그물** | 파란 마름모·동그라미가 뜬다 |
| 왼쪽 손잡이 **현위반경·목적반경** 을 끌어 본다 | 🔴 **끄는 동안** 지도의 파란 영역이 따라 움직인다 (손 떼고 나서가 아니다) |

🔴 **궤적만 보시려면**: **🌅 볼트 오전** 켜고 → **🚀 빠름** → **▶️ 주행** → 1분쯤 두고 → 확대.
2km 넘게 튄 자리(정거장 도착)에서는 **선이 끊깁니다** — 그건 고장이 아니라 규칙입니다
(순간이동을 직선으로 그리지 않습니다).
