# 카카오 T 픽커 — 이 폴더에서 뽑은 것

> 자막 둘: **2편. 가입 및 오더 수행**(카카오 공식) ·
> **카카오퀵 노하우, 이 영상 하나로 종결**(쑥쑥)
>
> 우리가 이 판을 본 이유는 하나다 — **사업자 없이 바로 시작할 수 있다.**
> 인성은 사업자가 있어야 한다 ([일정표](../../../기획/일정표.md) 의 임계 경로).
>
> ⚠️ 여기서 얻은 것은 **인성·화물24시 판에 되가져올 «원리»** 로 쓴다.

---

## 1. 오더 수행 순서 — 우리 6단계와 어긋난다

```
출근하기 → 목록/오더카드 → 오더 클릭 → 수락하기
        → 픽업 출발하기 → 픽업 완료하기 → 배송 출발하기 → 배송 완료하기
                                                    (서명 또는 촬영)
```

| | 카카오픽커 | 1DAL (인성) |
|---|---|---|
| 잡기 | **수락하기** 한 번 | 확정 + **안전취소 30초** |
| 출발 신고 | **픽업 출발하기** 버튼이 따로 있다 | 없다 — 우리는 GPS 로 파생 |
| 완료 증빙 | **서명 또는 사진** 필수 | 없다 |
| 정산 | 포인트 → **1일 이후 출금 신청**, 당일/익일 지급 | 주선사별 |

🔴 **«픽업 출발하기»가 돈을 가르는 버튼이다** (아래 §2). 우리 판엔 이 축이 없다.

## 2. 🔴 취소 규칙 — 우리 안전취소와 **완전히 다른 판**

### 고객이 취소할 때 — 내가 어디까지 눌렀느냐가 정한다

| 내 상태 | 고객 취소 시 |
|---|---|
| 수락만 함 | **0원** |
| **픽업 출발하기** 누름 | **취소 수수료** (5만원 콜에 6~8천원) |
| **픽업 완료하기** 누름 | **운임 100%** |
| 착불 콜 | 🔴 **위 둘 다 해당 없음** — 카카오가 아직 결제를 안 받은 상태라 |

→ **잡았으면 바로 «픽업 출발하기»를 누른다.** 가는 길에 취소당하면 그 차이가 그대로 손실이다.
착불은 고객과 직접 조율해야 한다.

### 내가 취소할 때

| | 앱에서 | 그 뒤 |
|---|---|---|
| 인성·통합 | **1분 내** | 사무실 전화 → 10분 내 |
| **카카오픽커** | **10분 내** (전화 불필요) | 고객센터. 대체로 봐 주되 **페널티** |

🔴 **10분은 우리 안전취소 30초의 20배다.** 우리 설계에서 30초 안에 판정을 끝내야 하는 것은
**인성 판의 제약이지 퀵 일반의 제약이 아니다.**

## 3. 필터 설정 — **위치가 축이다**

쑥쑥은 두 벌만 쓴다. 국면이 아니라 **내가 어디 있느냐**로 갈린다.

| | 서울 안에 있을 때 | 경기 외곽으로 빠졌을 때 |
|---|---|---|
| 픽업 반경 | **5km** (20분 안에 픽업 가능한 선) | **10km** (많이 울리면 5~7km) |
| 도착지 | **서울 빼고 전부** | **모든 배송지** |
| 이유 | 서울→서울은 급송 아니면 돈이 안 된다 | 외곽엔 콜 자체가 적어 넓혀도 안 뜬다 |
| 결과 | 금액 높은 것만 골라 **0.5초 안에** 누른다 | 하루 1~2건. 그 한둘이 4만·7만 복귀콜 |

| 노하우 | 1DAL |
|---|---|
| 🔴 **픽업 반경 5km 의 근거는 «20분»이다** — 거리가 아니라 **시간이 진짜 기준** | ✅ 우리 `reach_samples` · 도달 계수가 바로 이걸 푼다 |
| 🔴 반경을 넓히면 **알림이 계속 울려 못 견딘다** | ✅ 「운전 중에는 입력을 못 한다」와 같은 뿌리 — **거르는 이유가 수익이 아니라 주의력**일 때가 있다 |
| **서울 안에서는 «서울 밖»만, 외곽에서는 «전부»** | 🔧 우리 국면(첫짐·합짐·복귀)에 **«지금 어디 있나»** 축이 겹쳐야 한다. [배차망_설정 §4](../배차망_설정/노하우_추출.md) 의 도심/외곽과 같은 축 |
| 복귀용 구(區) 지정은 만들어 뒀지만 **거의 안 쓴다** | — 지역 나열보다 «서울 밖/전부» 두 벌이 실전에서 이긴다 |

### 🔴 **금액 필터가 없다** — 이 판의 결정적 한계

*"싼 것도 많이 올라오고… 2, 3만원 이상 되는 콜은 하루에 몇 개 안 뜨고, 떠도 0.5초 만에 나간다."*

→ **거를 수단이 없으니 사람이 눈으로 걸러야 하고, 그래서 0.5초 싸움이 된다.**
1DAL 이 인성 판에서 하는 일(요금 하한을 앱이 미리 거른다)이 여기선 **불가능**하다.

## 4. 오더 카드를 끄는 법 — **앱을 끌 수 없다**

오더를 잡은 상태에서는 앱을 끌 수 없어 카드가 계속 뜬다.
쑥쑥은 **콜이 안 뜨는 지역 하나(괴산군)만 골라 둬서** 카드를 사실상 끈다.

🔧 **우리에게 주는 것** — «지금은 안 받는다»가 **필터 조작이 아니라 한 번의 토글**이어야 한다.
기사님이 운전 중에 지역 목록을 다시 고르게 하면 안 된다.

## 5. 서포트 카드 — 몇 초 먼저 본다

- 콜을 **1·3·5·7건** 수행할 때마다 1장, 하루 **4장**
- 켜면 **1시간** 유지. 주위 콜을 몇 초 먼저 본다
- 쓰는 때: **하루 시작할 때** · **외곽에서 다음 콜을 잡기 시작할 때**
- *"엄청 중요한 건 아니고 적당히 중요한 것"*

→ 이 판은 **선빵이 상품화되어 있다.** 우리 판(인성)에서 «먼저 보는 것»이 왜 값어치가 있는지를
플랫폼이 스스로 증명한 셈이다.

## 6. 이 판의 자리 — **보조 수단**

| | 쑥쑥 (승용차) | 카카오 전업 기사 (공식 인터뷰) |
|---|---|---|
| 주력 | 인성 · 통합 | **카카오 95%** · 타사 5% |
| 카카오 비중 | 주 **1~4건** (하루 한 건 탈까 말까) | 주 6일 · 하루 16~17건 |
| 쓰는 법 | 리스트를 안 본다. 내비 보다가 **오더 카드가 뜨면 바로 수락** | — |

🔴 **왜 카카오를 쓰나 — 정산이다.** 전업 기사가 첫손에 꼽은 이유:
*"출금이 자유롭다. 타사는 주 1회, 심지어 월 1회 정산하는 데도 있다."*
그리고 **선호하지 않는 콜을 가장 빨리 정리해 준다.**

→ **«돈이 언제 들어오나»가 기사가 배차망을 고르는 첫 기준**이라는 건 기억해 둘 것.

## 7. 가입 — 사업자가 필요 없다

```
앱 설치 → 카카오계정 연결 → 실명·휴대폰 인증
       → 배송 수단 등록 (승용차·오토바이는 차량번호 + 운전면허증)
       → 신분증 등록 → 내부 심사 평균 2~3일
       → 🔴 안전보건 교육 이수 (2023-07-01부터 의무. 타 플랫폼 수료증으로 대체 가능)
```

**가입비 없음.** 심사 2~3일과 안전보건 교육이 실제 대기 시간이다.

## 🔧 여기서 가져올 것 (인성·화물24시 판으로)

- **반경의 진짜 단위는 시간(20분)이다** — km 는 대리값일 뿐
- **«지금 어디 있나» 축** — 서울 안/밖으로 필터가 통째로 바뀐다. 우리 국면 축과 곱해져야 한다
- **알림 피로도 거르는 이유다** — 수익만이 필터의 근거가 아니다
- **«지금은 안 받는다»는 토글 하나로** — 운전 중에 목록을 고르게 하지 않는다
- **잡은 직후의 «출발 신고»가 돈을 가른다** — 우리 판에도 비슷한 분기가 있는지 볼 것
