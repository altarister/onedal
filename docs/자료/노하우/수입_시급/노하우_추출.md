## 1. 차종이 전략을 가른다

| | 승용차 (자차) | 소형차 | 스타리아 3밴 | 1t (기사님) |
|---|---|---|---|---|
| 표본 | 하루 | 하루 | **7일** | 목표값 |
| 콜 수 | 9콜 | 8콜 | 4.6콜 | 6콜 |
| 이동(묶음) 횟수 | 3회 | 3회 | 2회 | 2회 |
| **평균 합짐 수** | **3.0** | **2.7** | **3.0** | **3.0** |
| 하루 물리적 주행 | 400~500km | 400~500km | 261km | **200~300km** |
| 평균 단가 | 29,333원 | 약 43,000원 | 49,804원 | **100,000원** (목표) |
| 시급 | 28,700원 | 약 35,000원 | 28,268원 | — |
| 상하차 | 박스·서류, 거의 공짜 | 박스 | 중간 | **파레트 — 지게차 4분 · 수작업 27분** |

**같은 매출을 1t 는 2.6콜이 채운다.** 기사님의 *"3콜씩 왕복"* 이 감이 아니라 **단가 구조**에서 나온다.

### 🔴 평균 합짐 수는 차종과 무관하게 **3에 수렴한다**

```
승용차   9콜 ÷ 3회 = 3.0
소형차   8콜 ÷ 3회 = 2.7
1t      6콜 ÷ 2회 = 3.0
```

달라지는 것은 합짐 수가 아니라 **ⓐ 이동 횟수와 ⓑ 콜당 거리**다.

```
승용차   3콜 × 43km × 3회 = 9콜 · 26만원
1t      3콜 × 80km × 2회 = 6콜 · 25~30만원   ← 같은 돈을 절반의 콜로
```

→ 짐칸·상하차·시간 세 제약이 **어느 차종에서나 3 근처에서 만난다.**

### 🔴 그런데 물리적 주행은 1t 가 절반이다

배송거리 합은 비슷한데(385 vs 390km) **하루에 실제로 굴리는 거리가 두 배 다르다.**

```
승용차   배송합 385km  ·  실주행 400~500km   1.0~1.3배  ← 실주행이 더 크다
1t      배송합 390km  ·  실주행 200~300km   0.5~0.8배  ← 실주행이 절반
```

**합짐이 겹치기 때문이다.** 같은 길을 한 번 달리면서 **운임은 세 번 받는다.**
반대로 승용차는 콜이 많아 **픽업 지점도 많고**, 그 이동이 배송거리를 넘어선다.

🔴 **그래서 1t 는 매출이 같아도 기름값·피로가 절반이다.**

```
승용차   단가가 낮아 많이 잡아야 한다. 대신 상하차가 싸서 많이 잡을 수 있다
1t      단가가 높아 적게 잡아도 된다. 대신 상하차가 비싸서 많이 못 잡는다
```

🔴 **승용차 셈법을 1t 에 가져오면 상하차에서 무너진다** — 30km 짜리 아홉이면 상차만 아홉 번이고,
수작업이 섞이면 27분씩 물린다.

⚠️ **거리는 대부분 자막에 없다.** 확실한 것은 **1t 의 200~300km 하나뿐**(기사님 실측)이라
나머지는 **우리 실측**으로 채운다 (규칙 ④ — 없는 숫자를 지어내지 않는다).

## 2. 🔴 시급이 가장 안 흔들린다 (7일 편차)

| | 최소 ~ 최대 | 최대/최소 |
|---|---|---|
| 매출 | 138,500 ~ 312,000원 | **2.25배** |
| **km당** | 554 ~ 1,250원 | **2.26배** ← 가장 흔들린다 |
| 콜당 | 41,667 ~ 56,250원 | 1.35배 |
| **시급** | 24,800 ~ 30,383원 | **1.23배** ← 가장 안정적 |

매출은 두 배 넘게 흔들리는데 **시급은 좁은 띠 안에 모인다.**

→ **흔들리는 값으로는 판단할 수 없다. 안정적인 값이라야 기준이 된다.**

⚠️ **1t 도 그런지는 모른다.** 거리가 길고 콜이 적으니 km당이 더 안정적일 수 있다 —
**우리 실측이 쌓이면 이 표를 1t 로 다시 그려야 한다.**

## 3. 🔴 차종마다 보는 값이 다르다

기사님(2026-08-20): *"큰 차들은 **km당 단가**를 중요하게 생각하고, 소형은 **시급**을 중요하게 생각하는 것 같다."*

```
스타리아  261km · 4.8콜 · 콜당 50,180원 · 시급 28,268원
1t       200~300km · 6콜 · 콜당 100,000원
```

거리는 거의 같은데 **콜당 단가가 절반**이다. 같은 돈을 벌려고 같은 거리를 굴린다.

→ **큰 차의 이점은 매출이 아니라 `km당 단가`** 다. 같은 시급을 내면서 **덜 굴리는 것**이 1t 의 값어치다.

| 판정 분모를 **차종에 따라** 달리 볼 것 | 🔧 지금 판정은 시급 하나로 본다 |

## 5. 실력론 — 1DAL 의 존재 이유를 업계가 말한다

- *"고르면 못 번다 — 바퀴가 굴러야 돈이 된다"* 와 *"뭘 안 잡느냐가 더 중요하다"* 가 **동시에** 참이다.
  그 사이를 가르는 것이 실력이고, **그 실력을 값으로 만드는 것이 우리 판정**이다.
- 인터뷰어도 적요 불일치를 두고 *"시스템으로 보완되면 좋겠다"* 고 말한다 — 우리가 푸는 문제다.

## 6. 🔴 시급 4만은 어떻게 나왔나 — **하루를 한 방향으로 접는다**

승용차 · **9건 32.8만원 / 8시간 = 시급 4.1만**. 앞 편들이 «원리»였다면 이건 «실황»이다.

```
09:00  아침에 장거리 4개를 한 방향으로 묶음        17.5만
       + 내려가는 길에 두 개 추가                24.7만  ← 11시 전에 하루치를 거의 끝냄
11:50~ 가까운 쪽부터 순서대로 하차
13:15  종점에서 탈출콜 3개                        32.8만
16:54  퇴근
```

🔴 **하루의 절반 이상이 아침 두 시간에 정해졌다.** 나머지는 실행이다.

| 노하우 | 1DAL |
|---|---|
| 🔴 **묶었으면 중간에 잔잔한 걸 붙이지 않는다** — *"쭉 내려가면 1시간 반인데 들렀다 가면 2시간 반. **뒤에 있는 게 다 한 시간씩 밀린다**"* | 🔴 **우리에게 없는 개념** — 지금 판정은 «이 콜의 우회 비용» 만 본다. **뒤 콜 전부에 주는 피해**를 안 센다. 합짐 4개째의 진짜 값은 *자기 우회 × 남은 콜 수* 다 |
| 다만 **시간이 딱 맞으면 급송 하나 정도**는 붙여도 좋다 | 🔧 «붙일 수 있다/없다» 가 아니라 **여유가 얼마 남았나**로 답해야 한다 |
| 🔴 **장거리는 시간이 널널하다** — *"아침에 보내는 물건은 점심 끝날 때까지만 가도 크게 뭐라 안 한다"* (단, **한 번은 확인 전화**) | 🔧 우리 규칙은 일괄 «잡은 시각 + 60분» 이다. 거리·화물에 따라 달라야 한다는 증언 |
| 🔴 **탈출콜** — 외지는 빈차로 나오기 십상 | 🔴 **국면에 「탈출」이 없다.** 지금 다섯(첫짐·합짐·운행·관내·복귀) 중 «외지에서 나오는 것» 은 복귀와 다르다 — 집이 아니라 **콜이 있는 곳**으로 나온다 |
| 🔴 **들어가기 전에 나올 계획을 세운다** — *"미리 생각하고 가야 콜이 떴을 때 바로 잡는다"* | 🔧 **하차지를 정할 때 «여기서 나올 수 있나» 를 같이 본다** |
| 🔴 **물건이 나오는 시간이 있다** — 공통으로 **오전 9~10시**(출근 후) · **오후 2시**(점심 후) | 🔧 **시간대별 콜 빈도** — «어디서» 뿐 아니라 «몇 시에» 로 넓힌다 |
| 🔴 **상차 반경이 지역 성격에 따라 다르다** — 시내 5~7km · **외지 10~20km**(한 콜 잡으면 10km) | 🔧 [배차망_설정 §4](../배차망_설정/노하우_추출.md) 로 정리했다 |
| 🔴 **도착 10~20분 전에 전화한다** — 지방 공장은 받으러 나오는 데 시간이 걸린다 | 🔧 우리는 «KEEP 직후 통화» 만 있다. **도착 전 통화**는 다른 시점이고 **대기 시간을 직접 줄인다** |
| **직권 배차** — 사무실이 동선을 보고 전화로 제안. 보통 칼질이 심해 안 받지만 **동선이 맞으면 받는다** | 🔧 직접콜은 심사하지 않지만(규칙 ①) **동선 적합도만이라도 보여 주면** 판단이 빨라진다 |
| 🔴 **욕심을 끊는다** — 탈출콜 3개를 잡고 *"더 이상 욕심 부리면 안 된다"* | 🔧 **«지금 멈춰야 한다» 를 앱이 말해 줄 수 있다** — 남은 여유가 다음 콜을 감당 못 하면 |

### 이 편이 우리 설계에 던지는 것 넷

**① 합짐의 값은 «자기 우회» 가 아니라 «뒤에 주는 피해» 다.**
콜 4개를 실었으면 한 시간 우회는 **네 시간짜리 손해**다.

**② 국면이 하나 빠졌다 — 「탈출」.** `복귀` 는 집으로, `탈출` 은 **콜이 있는 곳으로**. 방향이 다르다.

**③ 시간은 지역과 화물에 따라 다르다.** `잡은 시각 + 60분` 은 시내 기준이다.

**④ «언제» 가 «어디» 만큼 중요하다.** 후속 콜 빈도에 **시간축**을 넣어야 한다.

## 🔧 여기서 나온 기획 후보

- **차종별 판정 분모** — 큰 차는 km당, 소형은 시급
- **오늘 시급 표시** — 실시간으로 재는 습관을 화면이 대신한다
- **순익률을 차종별로** — `× 0.7` 은 승용차의 값이다
- **우회 비용을 뒤 콜 수로 곱한다** — 지금 판정의 가장 큰 구멍
- **「탈출」 국면** — 복귀와 방향이 다르다
- **시간대별 콜 빈도** — 물건이 나오는 시각이 있다
