```

       ↓ 수내 하차(급송 29분) → 용인 영덕 하차 + 석우에서 대전콜 픽업 (동시 5콜)

       ↓ 대전 2건 하차 (에어컨 끄고 잔여 20km 사수, 0% 도착)
16:00  4시 대차 예약을 미리 받아 두고 충전 — 하루는 계속된다
```

### 읽어낼 것 셋

- 🔴 **릴레이는 왕복(3콜×2회)과 다른 하루 모델이다.** 내려가며 줍고, **콜밭을 종점으로** 고른다.
  우리 국면 모델로는 전진(첫짐→합짐→운행)이 계속 이어지는 형태 — **복귀 국면 없이
  하차지에서 다음 뼈대를 다시 세운다.** 승용·SUV 는 픽업이 싸서 릴레이가 된다.
  → 1t 왕복 모델과 어느 쪽이 나은지는 **차종·짐 크기가 정한다.**
- 🔴 **전기차는 충전이 시한 변수다.** 지각의 원인 복기가 정확하다 —
  *"욕심 한두 개 + 충전 미비 + 사고 정체 + 충전기 고장이 전부 겹쳤다."*
  우리 판(1t 디젤)엔 충전이 없지만 원리는 같다 —
  **차량 준비 상태(연료·적재 공간)는 시한 계산의 숨은 항이다.**
- **저단가의 후회가 데이터 문제다.** *"이렇게 콜이 많이 뜰지 모르고"* 8시에 저단가를 선점했다 —
  **시간대별 수급**을 알았다면 다르게 골랐다.

### 이 편의 통화 대사 네 장면

| | 대사 | 1DAL |
|---|---|---|
| ⓐ 첫인사 | *"○○ 보내드릴 기사입니다"* | ✅ 통화 시트 |
| ⓑ 시한 약속 | *"바로 갈 거고요, 한 시간 안 걸릴 겁니다"* | ✅ **도착 약속**(`promisedArrivalAt`) |
| ⓒ 도착 예고 | *"도착 10분 남아서 전화 먼저 드렸습니다"* | 🔧 도착 전 통화 |
| ⓓ 인수 확인 | *"성함만 알려주시겠어요? 그렇게 적어놓겠습니다"* | 🔧 인수자 기록 |

**비대면 하차의 처리 순서**도 이 편에 있다 — ⓐ 사진 꼼꼼히 → ⓑ 문자 전달 →
ⓒ 고객사에 정중히 양해 → ⓓ **책임 부담을 스스로 인지** → ⓔ 주선사에 *"적요에 점심시간 좀 써 달라"* 피드백.
📖 사용설명서감이고, `places` 에 «점심시간» 한 줄이면 **다음 기사는 안 당한다.**

## ⭐ 1t 하루 — **야상을 쓰는 법** (나는 용달러다 · LPG)

**우리와 같은 1t 의 하루**다. 지금까지 1t 칸은 기사님 목표값뿐이었는데 처음으로 실측이 생겼다.

```
전날 밤    야상 2건을 미리 싣는다 (다음 날 아침 하차분)
새벽 3~4시  눈 뜨면 바로 출발 — "6시에 출발해야 하면 눈 뜨자마자 나간다"
08:00      첫 하차 · 09:00 둘째 하차   ▶ 9만원으로 하루를 시작
낮         빈파레트 8개(10km·30분) · 수작업 콜 · 원두 30박스(1파레트)
14:30      내일 몫 야상 2건을 미리 싣는다
16:30      마무리 — 5콜 · 350,000원 (야상 91,000원은 내일 매출로 넘김)
```

| | 값 |
|---|---|
| 콜 수 | **5콜** |
| 매출 | **350,000원** · **콜당 70,000원** |
| 기본 컨디션 | 25~30~35만원 |

🔴 **콜당 70,000원 — 스타리아(49,804원)의 1.4배다.** *"1t 는 단가가 높아 적게 잡아도 된다"* 가
실측으로 확인된다. 5콜로 35만원이면 기사님 목표(6콜 25~30만)를 넘는다.

🔴 **야상이 그 비결의 절반이다.** 아침 8시·9시에 이미 9만원을 벌고 시작한다 —
그 시간대는 원래 *"콜을 기다리는 시간"* 인데, **전날 밤에 그 시간을 미리 사 둔 것**이다.

| 노하우 | 1DAL |
|---|---|
| 🔴 **전날 밤 예약콜(야상)** | 🔴 **없음** → 🔧 지금 필터·판정은 «지금 뜬 콜» 만 본다 |
| 🔴 **수작업은 시간이 아니라 돈으로 판단한다** — *"수작업을 할 만큼 배송료가 받쳐 줘야"* | 🔴 우리는 상하차를 **분**으로만 넣고 운임과 견주지 않는다 → 🔧 |
| 🔴 **콜이 마르면 방법을 바꾼다** — 코스·노선·시간대를 바꿔 매출을 되돌렸다 | 🔧 «전략을 설정으로 받는다» 의 근거 |
| **콜 빼기의 선** — 적요와 **다른 현장**이면 조율해 뺄 수 있다. 하기 싫어서는 어렵다 | ✅ 취소 세 갈래의 실제 판단선 |

## 🔧 여기서 나온 기획 후보

- **야상 / 예약콜** — 전날 밤에 아침 시간을 사 둔다. 1t 판에서 실측으로 효과가 확인됐다
- **「탈출」 국면** — 릴레이는 복귀와 다르다. 집이 아니라 **콜이 있는 곳**으로 나온다
- **차량 준비 상태를 시한에 넣기** — 연료·적재 공간은 숨은 항이다
- **도착 전 통화** — 대기 시간을 직접 줄인다
- **수작업을 운임과 견주기** — 분이 아니라 돈으로 판단한다
