## 시트는 «오늘 한 일»을 남긴다 — 화면의 사이클은 하루다

**2026-09-15 기사님 확정** (2026-08-19 «이번 운행(사이클)만 보인다»를 바꾼다).

> *"이천 왕복 하루에서 여러 건의 콜을 수행했는데 모두 사라져 버려서 뭘 수행했는지가 안 보여."*
> *"기획이 바뀌었어. 지금처럼 순회하는 거면 사이클이 하루를 의미하게 되는 거라… 시트에 남기는 것이 맞아."*

옛 규칙은 진행 중인 콜이 0건이 되는 순간 하차한 콜까지 한꺼번에 뺐다. 노선 3 + 복귀 3 을 도는 하루에는
콜 사이에 빈 차로 서는 틈이 여러 번 있어, 그때마다 **그날 한 일이 화면에서 지워졌다.**

- 시트에 남는 것: 진행 중인 콜 + **오늘(영업일) 하차한 콜.** 경계는 자정 영업일 전환 하나다
- 취소·방출은 여전히 안 싣는다 — «없던 일»
- 지나간 콜은 시트 상태바 오른쪽 «지나간 콜 숨기기»로 가렸다 보였다 한다 — 누르면 **지도의 그 콜 선·번호도 가린다**
- 콜 번호는 **하루 1~N** 이다 (운행마다 1 부터 다시 세지 않는다)
- 지도 자취는 **하루 종일 쌓는다** — 콜 0건 틈에 지우지 않는다. 영업일이 바뀌면 지운다
- 자정을 넘긴 운행은 **오늘 내린 콜만** 오늘 시트에 올린다 — 서버를 다시 켜도 «오늘 하차»한 콜은 되살린다 (잡은 날이 어제여도)
- 상태는 여전히 콜별 즉시(`ORDER_DELIVERED`)다 — 바뀌는 것은 화면뿐이다
- 지금 지키는 곳: `shared/src/index.ts` 의 `deckOfCycle` · `server/tests/rules/cycleDeck.test.ts` · `client-app/src/lib/sheetStatus.ts` · `client-app/src/lib/pastCalls.ts` (36d11b1b) · [화면규칙](../기획/화면규칙.md) L7·L8·L9·M4·M6·B4

## 절대 문턱을 버리고 시급으로 잰다 — 목표 시급 3만은 문제지로 맞췄다

## 콜 시한은 임시다 — 통화로만 늘어난다

**2026-08-19 기사님 확정.** 시한 = 배송 주행 × 1.5 + 픽업 20분 (콜 받은 시각 기산). 업계 관행 값이다.

> *"시한은 콜 받는 순간 임시로 정해진다. 내가 전화 통화를 통해서 늘릴 수 있다."*
> *"픽업 20분은 일반적인 값이라 하니 되돌리지 말고 20분(상차) / 10분(하차)로 하자."*

**2026-08-31 기사님 확정** — 상차 약속 = 콜 잡은 시각 + 20분. *"상차는 좀 늦어도 되지만 상차하고는 150%를 꼭 지켜야 한다."*
그래서 코드의 하차 마감은 «상차 완료 + 배송 주행 × 150%» 다.

임시 약속이라서 **통화로 굳힌 약속만** 깨짐을 «사고»(무조건 빨간불)로 센다. 임시 약속이 깨지면 약속 점수가 0점이 되지만 색은 덮지 않는다.

- 지금 지키는 곳: `shared/src/timing.ts` 의 `DEFAULT_DEADLINE_RULES`(`deadlineRatioPct` 150) · `DEFAULT_JUDGMENT.unknown.pickupPromiseMin` 20 · `timing.ts` 의 `lateMinutes` 가 `declared` 를 본다
- ⚠️ 임시 약속이 깨진 콜을 빨간불로 볼지는 점검표 8부 ⑤

## 무조건 빨간불은 약속·성질 둘만 — 만석은 가중치로

**2026-08-29 기사님 확정.** 판정 전수조사 때 «만석이면 무조건 빨간불로 할까» 여쭸다.

> *"나중에 가중치를 높일 거야. 그러면 빨간색으로 보일 거야."*

점수와 무관하게 «잡으면 사고»인 것은 통화로 굳힌 약속을 깨는 것과 실린 짐과 상극인 성질 둘이다.
만석은 공간 점수 0점이지 색을 덮지 않는다.

## 못 쟀으면 `null` 이다 — 대답은 셋이다

**2026-08-29 확정.** 기준의 대답은 «쟀다 / 잴 게 없다 / 잴 수 없다» 셋이다. 0 은 «나쁘다»로 읽히니 못 잰 것을 0 으로 지어내지 않는다.

- «잴 수 없다»(카카오가 터졌다 · 주소를 못 찾았다)는 🔴 + 「잴 수 없음」 딱지 — 재료가 없는데 «괜찮다»고 넘어가는 사고를 막는다
- «모른다»가 너무 많던 것은 버그였다 — 차종만 알면 짐이 나온다(`defaultCargoByVehicle`). 고치니 남은 「일반값」 딱지는 배송주행 추정 하나뿐
- 지금 지키는 곳: `shared/src/judge.ts` 의 `Outcome` · `server/tests/core/stopTimingVehicleDefault.test.ts` · `verdict.test.ts`

## 모든 콜은 금액까지 판정에 넣는다 — ⑤-1 의 전제가 사라졌다

## 무조건 빨간불은 확정값만 본다 — 신고한 적재 · 통화로 굳힌 약속

**2026-09-19 기사님 확정.** 만석을 무조건 빨간불로 올릴지 묻자 *"신고한 적재만 무조건 빨간불, 추정이면 감점, 이렇게 정하자."*
