# 약속을 "도착 시각" 기준으로 — 상차 시간과 분리한다 (⑤-4 계획 · 기사님 확정 2026-08-18)

> 기사님: *"상차 시간이 물건의 양에 따라 변하는 값인데, 그걸 도착 시간에 연결하려니 문제가 있다.
> 기본 도착 약속 — 말 그대로 '몇 시까지 갈게요'라고 해야 한다."*
>
> 실측 배경: 통화로 "40박스 수작업"을 신고하자 상차 소요가 15→30분으로 늘며
> **완료 기준 약속이 흔들려 갑자기 지각**이 떴다 (2026-08-18 리허설).
> 전화로 화주와 잡는 것은 **도착 시각**이다 — 약속은 도착으로 고정하고,
> 완료 시각은 도착 + 상차 소요로 **파생**한다 (규칙 ③).

## 이 계획은 CLAUDE.md ⑤-5 를 개정한다

⑤-5 의 *"상차 마감은 실어 보내는 시각 — 상차 시간을 포함한다"* (기사님 2026-08-16 픽스)를
**기사님 지시(2026-08-18)로 뒤집는다.** 화주와의 약속 단위가 완료가 아니라 도착이 된다.
완료 시각 개념 자체는 남는다 — 저장하지 않고 파생할 뿐이다.

## 확정된 값

| | 확정 |
|---|---|
| 약속의 뜻 | **도착 시각** ("몇 시까지 갈게요") — 상차 소요와 분리 |
| 기본 도착 예상 | **콜 잡은 시각 + 카카오 주행 시간** |
| 격자 미리 눌린 칸 | **도착 예상 + 30분** (상차·하차 동일) |
| 완료 시각 | 도착 약속 + 상차 소요 — **파생, 저장 안 함** |
| 신고로 소요가 바뀌면 | 도착 약속 불변 · 완료 예상만 갱신 |
