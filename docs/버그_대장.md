# 버그 대장 — 클래스로 센다

> 2026-08-18 신설. 기사님: *"발견된 버그를 정확히 진단할 수 있어야 재발 방지가 된다.
> 이 루틴을 끊어 버리고 싶어."*
>
> **버그를 하나씩 세면 "또 새 버그"로 보이고, 클래스로 세면 "저번 그거"가 보인다.**
> 같은 클래스가 두 번 나오면 인스턴스가 아니라 **그 클래스를 없애는 수정**을 한다.

## 규칙 — 순서를 뒤집는다

```
진단  →  이 버그를 잡았을 검사를 먼저 만든다 (빨간불 확인)  →  수정  →  초록불
```

검사가 **빨간불이 안 뜨면 진단이 틀린 것**이다. 그때는 고치지 말고 진단으로 돌아간다.

## 왜 통과했는가 — 우리 검사의 사각 (2026-08-18 측정)

| 관문 | 무엇을 보는가 | 값이 틀린 걸 잡나 |
|---|---|---|
| `tsc` | 타입이 맞나 | ❌ |
| `jest` | 함수가 규칙대로 도나 | ❌ (DB 를 여는 테스트가 **0개**였다) |
| `scenario` | **소켓으로 방송된 상태**가 맞나 | ❌ (DB 행은 씨앗 고를 때만 썼다) |
| `audit:socket`·`audit:dead` | 배선이 이어져 있나 | ❌ |
| **`scenario` 장부 검사** 🆕 | **실제로 저장된 행·화면 문구** | ✅ |

→ 2026-08-18 이전에는 **타입이 맞고 소켓 방송이 맞으면 값이 증발해도 전부 초록불**이었다.

## #50 · 폰마다 다른 숫자를 "필터"의 숫자인 척 그렸다 (2026-08-23)

**클래스: `한 벌짜리 자리에 여럿인 값을 놓는다`**

#49 를 붙인 지 몇 분 만에 기사님이 짚으셨다.

- 🔴 **필터는 한 벌, 성적표는 폰마다다.** 필터는 서버가 만들어 **모든 폰에 똑같이**

- 고침: 성적표를 **폰 카드 안**으로 옮겼다 (`DeviceControlPanel`). 폰 이름·화면 상태·

- 아직 안 훑은 폰은 **줄이 안 뜬다** — `0건`이라고 적지 않는다. 모르는 것과 없는 것은 다르다
- ⚠️ 동점이면 선언 순서를 유지한다. 스캔마다 `도착지 2 · 차종 2` 의 앞뒤가 뒤집히면
  화면이 깜빡이는 것으로 읽힌다
- 검사: `server/tests/rules/filterTally.test.ts` (8건, 자리 규칙 2건 신설) ·
  `client-app/src/lib/filterTally.test.ts` (5건, 순서·null)
- ⚠️ **자리 규칙은 서버 쪽 한 곳에만 뒀다.** 앱→서버→화면 왕복을 통째로 보는 검사가
  거기라서다. 두 벌이면 나중에 한쪽만 고쳐진다

> **#49 와 같은 뿌리다.** #49 는 *"화면이 말을 안 한다"*, #50 은 *"화면이 **누구** 얘긴지
> 안 밝히고 말한다"* 였다. 값을 화면에 올릴 때는 **그 값의 주어가 하나인지 여럿인지**를

- 🔴 유령을 문에서 막아도 이건 따로 고친다 (규칙 ② — 안전장치는 겹쳐 둔다)
- 검사: `routeOrderSingleSource.test.ts` 「계측 로그 — 값이 안 바뀌면 다시 안 찍는다」 4건

> 그건 로그를 안 봤으면 **아무 화면에도 안 나타났다.** 계측이 시끄러워서 잡힌 것이다 —

## #54 · 한 화면이 **두 서버를 동시에** 보고 있었다 (2026-08-26)

**클래스: 주소가 두 벌** (「파생값 두 곳」의 친척)

기사님: *"폰이름이 v2로 되어 있어."* → 로컬 DB 에는 `1234` 밖에 없는데.

- 증상: 관제웹이 로그인은 되는데 `GET /api/orders` 만 **401**. 기기 이름은 `v2`.
  로컬 서버 로그에는 **그 한 줄만** 도착했고, 로그인 POST 도 소켓 연결도 안 왔다.
  그래서 *"관제탑이 접속을 안 했다"* 와 *"관제웹은 잘 붙어 있다"* 가 **동시에 참**이었다
- 뿌리: `useOrderEngine` 이 `fetch("/api/orders")` 로 **주소를 손으로 적고** 있었다
  ```
  로그인·소켓·기기목록 → apiBase()  = 라이브   ← v2, filter-init 전부 라이브
  이력(orders) 한 줄만  → 상대경로   = 로컬     ← 라이브 토큰이라 401
  ```
- 🔴 **어제까지는 증상이 없었다.** 브라우저에서 서버를 안 바꾸면 상대 경로가 곧 정답이다.
  볼륨 업 스위치(2026-08-25)가 생기면서 **잠복해 있던 두 벌이 갈라졌다**
- 🔴 **관제앱에서는 더 나쁘다** — 거기서 `/api` 는 `https://localhost`, 자기 번들이다.
  이력이 **영영 안 온다**(취소·완료 탭이 조용히 빈다). 아무도 몰랐다
- 고침: `fetch(\`${apiBase()}/orders\`)`
- 검사: `serverTarget.test.ts` 「관제웹 전체 — 서버 주소를 손으로 적은 곳이 없다」

> 🔴 **검사가 세 파일을 «지목»하고 있었다.** 어제 만든 `serverTarget.test.ts` 는
> `apiClient`·`socket`·`roadmapLogger` 를 이름으로 확인했다. 그래서 **네 번째를 못 잡았다.**
> 지목하는 검사는 목록에 없는 것을 영원히 못 본다 — 이제 `src/` 를 통째로 훑는다.

> ⚠️ **진단을 두 번 틀렸다.** 처음엔 #53(유령 세션)이 이 401 의 원인이라고 봤다.
> #53 은 별개로 진짜였지만(05:22 외래키 오류 실측) **이 증상의 원인이 아니었다.**
> 기사님이 *"5번째 같은 질문을 하고 있어. 진짜 원인을 못 찾았거나 잘못된 부분을
> 원인으로 잡고 있을 수 있어"* 라고 하신 뒤에야 401 이 난 **호출 지점**
> (`useOrderEngine.ts:101`)을 봤다. **에러가 가리키는 줄을 먼저 읽었어야 했다.**

## #55 · 개발 브라우저를 **관제앱으로 오인**해 라이브로 보냈다 (2026-08-26)

**클래스: 화면이 조용히 거짓말한다** — 그중에서도 가장 비싼 형태

기사님: *"집에서 브라우저로 `http://localhost:3000/` 으로 접속했는데 v2 로 보여."*
그리고 로컬 스토리지를 지운 뒤에도 그대로였다.

```ts
/^https?:\/\/localhost(:\d+)?$/     ← `(:\d+)?` 가 `:3000` 을 통과시킨다
```

Capacitor 가 `https://localhost`(**포트 없음**)에서 번들을 띄우는 걸 잡으려던 무늬인데,
**개발 브라우저까지 «앱»으로 읽혔다.** 그러면 `apiBase()` 가 라이브를 돌려준다.

- 증상: 로그인은 되는데 로컬 서버 로그에 **아무것도 안 남는다.** 기기 이름이 `v2`
  (라이브 DB · 로컬은 `1234`), 필터·콜·이력이 전부 라이브 것
- 🔴 **로컬을 고치면서 라이브를 보고 있었다.** 오전 내내 로컬 서버는
  *"관제탑이 아직 접속하지 않았습니다"* 를 1분마다 찍고 있었고, 화면은 멀쩡히 돌았다
- 🔴 **`localStorage` 를 지워도 안 고쳐진다** — 저장값이 없으면 **이 판단으로 떨어진다.**
  그래서 "지웠는데 그대로"가 오히려 정상이었다
- 🔴 어제(2026-08-25) 볼륨 업 스위치를 만들며 태어난 무늬다. **하루짜리 버그**인데
  그 하루 동안의 브라우저 테스트는 전부 라이브를 상대로 한 것이었다
- 고침: 판단을 `client-app/src/lib/appOrigin.ts` 하나로 빼고 **포트를 허용하지 않는다**
- 검사: `server/tests/rules/appOrigin.test.ts` (3건 — 개발 포트 · 앱 · 남의 주소)

> **#53 → #54 → #55 는 같은 증상을 세 번 다르게 진단한 기록이다.**
> `v2` 하나를 두고 유령 세션(#53) → 상대 경로(#54) → origin 오인(#55) 으로 갔다.
> 앞의 둘도 **진짜 결함이었지만** 이 증상의 원인은 아니었다.
>
> 🔴 **무엇을 먼저 봤어야 했나: "이 화면이 지금 어느 서버를 보고 있나".**
> 루트 CLAUDE.md 「무엇이 실제로 돌고 있는가」가 정확히 이걸 경고한다. 서버·앱·관제웹
> 세 줄짜리 표까지 있는데, **정작 «관제웹이 어느 서버를 보는가»는 그 표에 없었다.**
> 어제 스위치가 생기며 그 축이 새로 생겼는데 표를 안 늘렸다 → 표에 한 줄 추가했다.
