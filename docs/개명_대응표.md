## 대응표

### A. 식별자 (TypeScript · 서버+관제웹+shared)

| 옛 이름 | 새 이름 | 용어집 근거 |
|---|---|---|
| `HuntPhase` / `huntPhase` | `CallTarget` / `callTarget` | 타겟 |
| `setHuntPhase` | `setCallTarget` | |
| `filterHuntBlocker` | `callFilterBlocker` | 콜 필터 |
| 소켓 `set-hunt-phase` / `hunt-phase-ack` | `set-call-target` / `call-target-ack` | 서버↔관제웹 전용이라 안전 |
| `deathValley*` / `DeathValley*` | `safeCancel*` / `SafeCancel*` | 안전취소 |
| `corridor*` (`corridorRadiusKm` 등 12형) | `detour*` (`detourRadiusKm` 등) | 경유. 기존 `detourAllowKm`(경유 +N km)과 한 가족이 됨 — 반경=허용÷2 파생 관계 그대로 |
| `eyelinePct` / `eyelineLabel` | `callDiscountPct` / `callDiscountLabel` | 콜할인율 |
| `mainCall` / `subCalls` | `firstCall` / `mergeCalls` | 첫짐 콜 / 합짐N 콜 |
| `slackMin` (판정 입력) | `detourBufferMin` | 경유버퍼 |
| 테스트 파일 `huntPhase.test.ts` / `filterHunt.test.ts` | `callTarget.test.ts` / `callFilterBlocker.test.ts` | |

**바꾸지 않는 식별자**: `pickupDeadlineAt` 등 deadline 계열(중립 영어) · `dispatchPhase`(확정 용어) · `securedOrder`(후보콜 — 영어명 유지, 표시만 후보콜)
