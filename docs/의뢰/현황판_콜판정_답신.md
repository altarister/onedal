# ✅ 둘 다 됐습니다 — `verdict` 가 콜마다 실려 옵니다

기사님 지시로 처리했습니다. **사본을 지우셔도 됩니다.**

---

## ① 앱 — 판정을 콜에 싣습니다

```kotlin
val verdict: String?   // "pass" | "vehicle" | "region" | "fare"
                       // | "pickup" | "blacklist" | "routeOrder" | "locked" | null
```

의뢰서에 적어 주신 일곱에 **`locked` 하나를 더했습니다.**
필터가 잠긴 동안(선점 중·대기)은 `decide()` 가 첫 줄에서 돌아서며 **평가 자체를 안 합니다** —
그것을 `"fare"` 같은 축으로 적으면 거짓말이 됩니다. 「잠겨서 안 봤다」는 걸러진 것과 다릅니다
(규칙 ④). 화면에서는 **«못 잼»과 같은 자리**로 그리시면 맞습니다.

### 🔴 분기는 한 곳뿐입니다

성적표(`tally`)를 채우던 그 `when` 이 **곧 축 이름**이 되게 했습니다. 따로 세면 그 순간
«성적표는 요금, 화면은 지역»으로 갈라집니다 (규칙 ③).

```kotlin
val axis = when {
    result -> "pass"; !vehicleMatch -> "vehicle"; !regionMatch -> "region"
    !fareMatch -> "fare"; !distanceMatch -> "pickup"; !blacklistClear -> "blacklist"
    else -> "routeOrder"
}
tally?.let { … when (axis) { … } }      // 성적표도 이 값을 쓴다
return Verdict(result, axis)
```

`decide()` 는 그대로 삽니다 — `judge()` 를 감싼 한 줄이 됐습니다. 호출부는 안 바뀝니다.

⚠️ **성적표를 두 번 세지 않습니다.** 판정은 스크랩 한 번에 두 번 돌지만(순수 계산이라 쌉니다)
`tally` 는 처음 한 번만 넘깁니다 — 두 번 세면 «이 축을 풀면 몇 개가 들어오나»가 두 배로 읽힙니다.

```

POST /api/scrap                       ← 받아서 넣습니다
GET  /api/sim/intel  rows[].verdict   ← 실어 보냅니다
```

**실측으로 확인했습니다** — 앱 규격 그대로 한 건을 쏘아 `verdict=vehicle` 이 담기고
`/api/sim/intel` 로 나오는 것까지 보고 시험 행은 지웠습니다.
