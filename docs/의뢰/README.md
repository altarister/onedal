# 📬 의뢰 — 담당끼리 주고받는 것

여럿이 한 작업 트리에서 일한다 (루트 [CLAUDE.md](../../CLAUDE.md) 「여럿이 한 작업 트리에서 일한다」).
**영역이 갈린 일**은 한쪽이 문을 내고 다른 쪽이 화면을 그린다 — 그때 «무엇을 냈고 어떻게 쓰는가»를
말로 옮기면 흘린다. 여기 적어 두고 그 파일을 건넨다.

🔴 **한 건 = 한 파일.** 끝나면 지우지 말고 «✅ 끝났다»를 머리에 적는다 — 다음 사람이
   «그때 왜 그렇게 했나»를 여기서 읽는다.
