# 순환 풀었습니다 — 그런데 **막는 게 둘이었습니다**

## ① 지적하신 것, 맞았습니다

기사님 *"출발을 해야 상차를 하지"* 그대로입니다. 읽어 주신 것 전부 검증했고 사실이었습니다:

| 확인한 것 | 결과 |
|---|---|
| `activePolyline` 이 `GATHERING` 에 있나 | ✅ `drawHolder.routePolyline` — 콜을 잡으면 서버가 계산 |
| `mockStops` 에 상차지가 드나 | ✅ `liveRoute` 의 상차·하차 **전부** (`useRouteDerivations:88`) |
| `isDriving` 의 정체 | ✅ `filter?.dispatchPhase === 'DELIVERING'` (`useRouteDerivations:82`) |

## ② 🔴 그런데 **막는 곳이 하나 더 있었습니다** — 서버

답신에서 *"`isDriving` 이 다른 곳에서도 쓰이는지는 확인 못 했습니다"* 라고 적어 주셨는데,
그쪽 말고 **서버에** 하나 더 있었습니다.

```ts
// server/src/services/geoService.ts — dropOffDutyMockLocation
if (session.activeFilter?.dispatchPhase === 'DELIVERING') return;
console.log(`🧟 [가상 좌표 만료] 운행 국면이 아닌데 시뮬 좌표가 남아 있습니다 — 걷어내고…`);
session.driverLocation = null;
```

**클라만 고쳤으면 좌표가 서버에서 매번 지워져 아무 일도 안 났을 겁니다.** 둘 다 고쳤습니다.

| 어디 | 전 | 후 |
|---|---|---|
| `useMasterGps.ts` | `canMock = DEV && isDriving && 경로있음` | `canMock = DEV && 경로있음` |
| `geoService.ts` | `DELIVERING` 이면 안 걷음 | `DELIVERING` **또는 `GATHERING`** 이면 안 걷음 |

🔴 **빈 차(STANDBY)에서는 여전히 걷어냅니다.** 그게 그 장치의 원래 목적입니다 —
2026-08-14 에 시뮬이 파주에서 멈춘 뒤 가상 좌표가 남아 다음 콜 경로가
«파주 → 광주 → 파주» **156km** 로 그려졌습니다. 콜을 쥔 뒤로는 **실제로 움직이는 중**이라
지우면 안 되고, 빈 차인데 가짜가 남으면 안 됩니다.

## ③ ⚠️ 알아 두실 것 하나 — 화면 문구를 고치실 때 씁니다

**`GATHERING` 에서 모의를 켜면 실 GPS 로 자동 전환이 안 됩니다.**
실 GPS 감시(`watchPosition`)는 여전히 `isDriving`(=DELIVERING)일 때만 도는데, 그건
배터리 때문에 원래 그랬던 것이라 그대로 뒀습니다. 테스트용이니 문제되지 않습니다.

그래서 의뢰서에 적었던 *"실 GPS 가 살아 있으면 진짜가 이깁니다"* 는
**DELIVERING 에서만 참**입니다. 정정합니다.

## ④ 화면 문구 — 이렇게 바꾸시면 됩니다

```
켜지는 때     콜을 잡아 경로가 생기면        ← 「운행 중(DELIVERING)」이 아닙니다
```

`available` 은 이제 **개발 빌드 + 경로 있음** 둘뿐입니다. 국면은 안 봅니다.
「지금 국면」 줄은 그대로 두셔도 좋습니다 — 다만 *"운행 중이 되어야 켜진다"* 는 말은
이제 틀립니다.

## ⑤ `sidePanel.test.ts` — 갱신했습니다

주신 갱신안 그대로 넣었습니다. 실제 코드(`StatusBoard.tsx:616` `flex flex-col gap-2`)와
맞는 것을 확인했습니다.

```js
expect(panel).toMatch(/h-full/);
expect(panel).toMatch(/overflow-y-auto/);
expect(panel).toMatch(/flex flex-col gap-2/);      // 줄마다 한 단 — 칸이 자리를 안 옮긴다
expect(panel).not.toMatch(/columnWidth/);          // 신문 단을 되살리지 않는다
expect(panel).not.toMatch(/overflow-x-auto/);      // 가로로 숨기지 않는다
```

검사 주석에 **왜 바뀌었는지**(기사님 *"그냥 한줄로 만들고"*)와 이 답신 경로를 적어 뒀습니다 —
다음 사람이 «신문 단이 왜 사라졌나»를 거기서 읽습니다.

## ⑥ 아직 없는 것
