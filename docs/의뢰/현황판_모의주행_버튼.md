# 현황판에 「🎭 모의 주행」 버튼을 붙여 주세요

기사님 지시 (2026-09-12):
> *"오른쪽 영역에서 호출해서 모의 주행을 진행하고 싶어"*
> *"경로가 생기면 현황판도 알게 될 거고 그때 **버튼을 활성화해서 클릭**하도록 하면 될 듯 싶은데?"*
> *"이건 그냥 **테스트용** 모의 주행이야 — 라이브에서는 폰의 GPS를 쓸 거야."*

**관제웹 쪽 문은 다 냈습니다. 현황판은 버튼만 그리면 됩니다.**

---

## 쓰는 법 — 다리 하나뿐입니다

```ts
import { useMockDriveStore, MOCK_DRIVE_SPEEDS } from './bridge';

const { available, running, speed, start, stop, setSpeed } = useMockDriveStore();
```

| 값/함수 | 뜻 |
|---|---|
| `available` | **버튼을 켤 수 있나** — 개발 빌드이고 **경로가 있을 때** 참. 관제웹이 올립니다 |
| `running` | 지금 도는가 |
| `speed` | 배속 (숫자) |
| `start()` | 시작 — `available` 이 거짓이면 **아무 일도 안 합니다** |
| `stop()` | 멈춤 |
| `setSpeed(n)` | 배속 바꾸기 |
| `MOCK_DRIVE_SPEEDS` | `[{label:'🐢 느림',value:5},{label:'🚗 보통',value:15},{label:'🚀 빠름',value:40}]` — 목업과 같은 세 단 |

🔴 **`available` 을 직접 계산하지 마세요.** «경로가 있나»를 현황판이 제 손으로 다시 보면
두 곳이 다른 답을 냅니다 (규칙 ③). 오늘 필터 전수 조사에서 그 모양으로 11건이 나왔습니다.

🔴 **`bridge.ts` 를 지나세요.** 안쪽(`stores/mockDriveStore`)을 직접 import 하면 나중에
어드민으로 옮길 때 어디를 고쳐야 하는지 세어 봐야 합니다 — `sidePanel.test.ts` 가 잠급니다.

## 화면 제안 (그대로 하실 필요는 없습니다)

```
🎭 모의 주행          [🐢] [🚗] [🚀]
   [ ▶️ 시작 ]  ← available=false 면 흐리게 + "콜을 잡고 출발하면 켜집니다"
   [ ⏸ 멈춤 ]  ← running 일 때
```

- `available === false` 일 때는 **감추지 말고 흐리게** 두는 편이 낫습니다 — 감추면
  «이 기능이 어디 갔나»가 됩니다 (이 레포가 여러 번 정한 규칙).
  이유를 한 줄 붙이면 더 좋습니다: *"콜을 잡고 출발하면 켜집니다"*.
- 속도 셋은 목업(지도 실험실)과 **같은 라벨**을 쓰시면 손맛이 한 벌이 됩니다.

## 알아 두실 것

1. **이건 서버까지 GPS 를 보냅니다.** 폰 GPS 자리를 대신하는 것이라 도착 감지·마일스톤·
   경로 갱신·궤적 저장이 **전부 실제로 돕니다.** 그래서 «잘 되는가»를 볼 수 있습니다.
2. **라이브에는 안 나갑니다** — `import.meta.env.DEV` 게이트가 관제웹 쪽에 있습니다.
   현황판에서 따로 막지 않으셔도 됩니다 (`available` 이 늘 거짓이 됩니다).
3. **실 GPS 가 살아 있으면 진짜가 이깁니다** — 켜 두셔도 폰이 좌표를 보내면 그쪽을 씁니다.
4. **경로가 사라지면 저절로 멈춥니다** (`setAvailable(false)` 가 `running` 도 내립니다).
5. **끝까지 가면 저절로 멈춥니다** — 경로 끝에 닿으면 `running` 이 내려가고, 서버의
   가상 위치도 걷힙니다.
6. **정거장에서 18초 섭니다.** 이건 배속을 곱하지 않습니다 — 정차 감지(5km/h↓ 10초)가
   실제로 발화할 시간을 주려는 것이라 줄이면 뜻이 없어집니다.

- **📍 내 위치 찍기** (콜을 잡기 **전에** 위치를 옮겨 «여기 서 있으면 어떤 콜이 뜨나»를 보는 것).
  목업에는 있고 실물에는 없습니다. 기사님이 *"테스트할 때도 GPS 정보가 있어야 여기서 콜이
  잘 뜬 건가 확인할 수 있는 거 아냐?"* 하신 것이 정확히 이 이야기인데, 모의 주행은
  **경로가 있어야** 돌아서 그 전 구간을 못 덮습니다. 만들면 문은 같은 다리에 얹겠습니다.
- **새 콜이 뜨면 자동 일시정지** (목업에 있습니다). 지금은 없습니다.
