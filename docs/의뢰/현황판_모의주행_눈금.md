# 🎭 모의 주행 「연기 눈금」 셋을 돌릴 수 있게 해 주세요

기사님 지시 (2026-09-12):
> *"모의 주행의 **정차시간, 서행하는 거** 오른쪽 어드민에서 설정하면 좋겠는데..
> 코드에 상수로 들어가 있는 거지?"*

그렇습니다. 지금까지 `simStep.ts` 에 박혀 있었습니다. **관제웹 쪽 문은 다 냈습니다 —
현황판은 손잡이만 그리면 됩니다.**

---

## 쓰는 법 — 다리 하나뿐입니다 (앞 의뢰와 같은 자리)

```ts
import { useMockDriveStore, MOCK_DRIVE_DEFAULTS } from './bridge';

const { dwellSec, approachKm, slowFactor,
        setDwellSec, setApproachKm, setSlowFactor } = useMockDriveStore();
```

| 값 | 뜻 | 지금 기본 | 범위 |
|---|---|---|---|
| `dwellSec` | ⏸️ 정거장에서 **서 있는 실초** (배속 안 곱함) | **18** | 0~120 |
| `approachKm` | 🐢 이 반경 안에 들면 **서행** | **1** | 0~20 |
| `slowFactor` | 🐢 서행할 때 걸음을 **몇 분의 일**로 (4 = ¼) | **4** | 1~20 |

`setXxx(n)` 를 부르면 **그 자리에서 브라우저에 저장**됩니다 — 「저장」 버튼을 따로 두지
마세요. 눈금은 돌리는 것이지 결재하는 것이 아닙니다.

`MOCK_DRIVE_DEFAULTS` 로 기본값을 읽을 수 있습니다 (「되돌리기」를 두신다면 쓰십시오).

## 화면 제안 (그대로 하실 필요는 없습니다)

「🎭 모의 주행」 칸 **안**, 속도 셋 아래가 자연스럽습니다 — 같은 «시뮬을 어떻게 돌릴까»니까요.

```

[🐢 느림] [🚗 보통] [🚀 빠름]
[        ▶️ 시작        ]
  ⏸️ 정차  [ 18 ]초   🐢 서행  [ 1 ]km  [ ÷4 ]      ← 이 줄이 새로 필요합니다
```

접어 두셔도 됩니다 — 자주 만지는 값은 아닙니다.

## 알아 두실 것

1. **브라우저에만 삽니다** (`localStorage`). 기사님 확정 — 개발 빌드에서만 도는 **시험
   도구의 눈금**이라 DB 까지 갈 값이 아닙니다. 넣으면 라이브 스키마에 시험용 칸이 남습니다.
   · 판을 새로 열어도 맞춰 둔 값은 그대로입니다.
2. 🔴 **⚙️ 설정 →「화면」의 «주행·정차로 굳는 시간»과 다른 층입니다.**
   · 저것은 **실운행에서도 쓰는 제품 규칙** (DB `user_settings.motion_hold_sec`)
   · 이것은 **시뮬이 어떻게 연기하나** (브라우저)
   한 칸에 섞으면 «시험용 값이 실운행을 바꾸는» 자리가 됩니다 (규칙 ⑤-4 ⑤).
3. ⚠️ **정차 18초를 줄이면 정차 규칙을 못 봅니다.** 그 시간은 «5km/h↓ 가 이어져야 정차»가
   실제로 발화할 길이를 주려는 것입니다. 줄이시려면 ⚙️ 설정의 「굳는 시간」도 함께 줄여야
   짝이 맞습니다.
4. **값이 바뀌면 다음 틱부터 곧바로 따릅니다** — 시뮬이 매 틱 스토어에서 «지금 값»을
   읽습니다. 주행을 멈췄다 다시 켜실 필요가 없습니다.

## 제가 한 것 (참고)

| 파일 | 무엇 |
|---|---|
| `hooks/simStep.ts` | `DriveDial` 을 **인자로** 받는다 — 순수 함수는 스토어를 안 읽는다 |
| `stores/mockDriveStore.ts` | 눈금 셋 + `localStorage` 저장·복원 |
| `hooks/useMockGpsSimulator.ts` | 매 틱 «지금 값»을 읽어 넘긴다 (클로저에 안 가둔다) |
| `statusboard/bridge.ts` | `MOCK_DRIVE_DEFAULTS` 재수출 |
| `hooks/simStep.test.ts` | 3건 — **돌리면 정말 달라지는가** |

🔴 마지막 셋이 중요합니다. **인자로 받게만 해 두고 안 쓰면 조용히 기본값으로 돕니다** —
오늘 그 모양을 한 번 당했습니다(설정 10초가 클로저에 갇혀 기사님이 1초로 바꿔도 안 먹었습니다).
그래서 «정차를 3초로 두면 3초만 서는가 · 서행 배수를 키우면 더 느린가 · 반경 0 이면
감속을 안 하는가»를 검사가 직접 먹여 봅니다.
