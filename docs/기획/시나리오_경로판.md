# 시나리오 — 지금까지 정한 것이 하루에 어떻게 흐르나

> 기사님(2026-09-04): *"지금까지 결론을 시나리오를 만들어서 이야기해 봐줘."*

**🔴 아직 코드 없음.** 계획 셋을 **한 줄기로 이어 붙여 앞뒤가 맞는지 보는 문서**다.
각 판의 근거는 원 문서에 있다 —
[내비 갈아타기](내비_갈아타기.md) · [경로를 고른다](경로를_고른다.md) · [남은 주행 분](남은_주행_분.md)

[경우의 수](시나리오_경우의수.md) 에 있다 — **그쪽을 먼저 읽는 것이 낫다.**

표시: 🆕 새로 생기는 것 · 🟢 이미 있는 것 · 🔴 아직 못 푼 것

## 08:10:30 — 첫콜 결재 🆕 **여기가 새로 생기는 자리다**

관제웹에 색과 함께 **경로 셋**이 함께 뜬다:

```
🔵 꿀콜   초월읍 상차 → 방화동 하차

   ▸ 추천          104분   1,900원      ← 미리 눌려 있다
     무료도로       132분       0원      +28분 · 공짜
     고속도로우선     98분   3,800원      −6분 · +1,900원
```

- 🔴 **그냥 KEEP 하면 지금과 똑같이 동작한다.** 고르는 건 선택이지 관문이 아니다
  (규칙 ⑤-3: 색만 보고 1~2초에 누른다)
- **이름이 아니라 맞바꿈을 보인다** — «빠른길»보다 `−6분 · +1,900원` 이 빠르다
- ⚠️ 셋을 **한 번에** 불러야 한다. 시차를 두면 «옵션 차이»가 아니라 **«교통 차이»** 를 본다
  (실측: 같은 구간이 30분 만에 104분/1,900원 → 114분/3,800원)

### 왜 하필 여기인가

```
STANDBY(첫짐 탐색)   경로가 아예 없다 — 고를 대상이 없다
      ↓  첫콜 KEEP   ◀── 🎯 여기. 경로가 여기서 태어난다
GATHERING(합짐 수집) 필터가 이미 그 경로로 돌기 시작했다 — 늦다
```

그리고 이때 **기사님은 서 있다.** 하루에 몇 없는, 입력이 가능한 순간이다.

⚠️ **합짐 콜에는 이 선택을 안 준다.** 경로는 첫콜이 정하고 합짐은 거기 붙는다.

## 08:11 — 경로가 태어난다

🟢 서버가 카카오에 물어 전체 경로를 만든다 (경유 **30개**까지 가능 — 3콜 6정거장은 여유).
🟢 지도에 선이 그려지고, 필터가 `GATHERING` 으로 넘어가며 **경유 지역이 그 선에서 나온다.**

🆕 **고른 기준이 그 호출에 실린다** — 추천 `RECOMMEND` · 무료도로 `avoid=toll` ·
   고속도로우선 `TIME`(🟡근사).
🆕 **통행료가 저장된다** (`summary.fare.toll`). 지금도 응답에 오는데 안 읽고 있었다.
   ⚠️ 배차망에서 긁은 `tollFare`(탁송료/경유비)와 **다른 칸**이다.
🆕 **무엇을 골랐는지 콜에 남는다** — 안 남기면 어느 전략이 나았는지 영영 모른다.

## 08:11 — 내비 🆕 **한 구간씩 보낸다**

`/navi`(개인 폰)의 큰 버튼이 바뀐다:

```
🧭 카카오내비로 열기
   다음 ① 초월읍 상차

🗺️ 카카오맵으로 열기          ← 작게. 되돌아갈 길
```

누르면 카카오내비가 **초월읍 하나만** 안내한다. **경유지를 안 쓴다.**

| 왜 | |
|---|---|
| 3콜 = 6정거장 = 경유 **5개**인데 카카오내비는 **3개**뿐이다 | 애초에 안 맞는다 |
| 🔴 **가정 셋이 통째로 사라진다** | 경유지가 없으니 «지나면 넘어가나 · 재탐색이 순서를 지키나»를 물을 것이 없다 |
| 🟢 **전체 경로는 관제웹 지도가 보여준다** | 09-03: *"전체가 같이 보이는 건 좋았는데 지금 가는 곳만 보고 싶다"* — 지도의 「현구간」이 이미 그 일을 한다 |

🆕 고른 기준이 내비에도 실린다 (`rpOption` 100 · 2 · 6).

## 08:11~08:35 — 주행

🆕 **시트 상태바의 분이 살아 있다.**

```
⏸ ① 초월읍 ~12분   1번 콜 · 상차
```

GPS 마다 «선에 떨어뜨려 남은 거리 빼기»를 다시 한다 — 939점 실측 **1.2μs**.
지금은 «카카오 호출 시점부터의 누적»이라 30분 달려도 안 변한다.

🔴 **길을 벗어나면?** 숫자가 **끊기지 않고 서서히 나빠진다.** «경로 이탈»이라고 안 적는다 —
기사님이 이미 아는 말이고, 그때가 숫자가 **가장 필요한 순간**이다.
500m 밖이 5회 연속이면 서버가 카카오에 다시 물어 **선이 바뀐다.**

🟢 지도: 계획선(파랑) + 내 궤적. 둘이 벌어지는 것이 «이탈»의 표시다.

## 🔴 터널·고속도로 구역을 필터에서 뺄 수 있나 — **틀린 도구다**

기사님(2026-09-04): *"어제처럼 긴 지하차도나 고속도로 근처 지역을 필터에서 빼면
거기 콜은 안 올라올 텐데.. 그건 어렵겠지?"*

**기술로는 된다.** 지금도 서버가 폴리라인에서 경유 지역을 만들고 있으니 빼는 것도 가능하다.
**그런데 손해가 더 크다.**

| | 왜 |
|---|---|
| **지역 단위가 너무 크다** | 고속도로가 지나는 「금천구」를 통째로 빼면 **금천구의 좋은 콜도 다 잃는다** |
| **규칙 ⑤ 를 어긴다** | 앱의 일은 «놓치지 않는 것»이다. 조이는 방향은 반대다 |
| **문제를 잘못 짚었다** | 그 콜이 나쁜 게 아니라 **비용이 우리 눈에 안 보이는 것**이다 |

### 둘은 서로 다른 문제이고, 각각 맞는 도구가 있다

**① 고속도로 근처** → **반경을 «분»으로 잰다.**
직선 2km 가 22분이면 자연히 밖으로 나간다. **지역을 빼는 게 아니라 자를 바꾸는 것**이라,
좋은 콜은 그대로 남는다.

**② 터널·지하차도** → **필터가 아니라 «좌표를 안 믿는 것»이다.**
지하차도 안에 상차지가 있어서 문제가 아니라, 거기서 **GPS 가 얼었다 튀어** 도착·지나침
판정이 망가진다 (09-03: 서부간선지하도로에서 9~10분 얼고 나오며 8.2km 따라잡음).
👉 `todo.md` **0-C(못 믿을 좌표를 한 곳에서 판정)** 이 그 자리다.

🟡 **덤으로 알게 된 것** — 카카오 응답은 **도로 조각마다 이름을 준다**
(`name` · `distance` · `traffic_speed` · `vertexes`). 이름에 «터널/지하차도/지하도로»가 들어가면
**그 구간을 미리 알 수 있다** — 거기서 도착 감지와 지나침 판정을 잠시 멈추면 된다.
⚠️ **다만 터널 이름이 실제로 나오는 것은 아직 못 봤다** (재 본 구간에 터널이 없었다).
   **확인이 필요하다.**

## 이 시나리오가 서 있는 땅

### 🟢 확인한 것

| | |
|---|---|
| URL 하나로 카카오내비가 열린다 | 기사님 폰 · 2026-09-04 |
| 경유지 칸은 `via_list` (`viaPoints` 는 조용히 무시) | 두 벌을 눌러 갈랐다 |
| `rpOption` 표 (100·2·6) | 공식 레퍼런스 |
| 우리 길찾기는 경유 **30개** | 실측 5개 = 67.4km, 그날 68km 와 맞음 |
| 통행료가 응답에 온다 | `fare.toll` 1,900원 = 내비 앱 화면과 같음 |
| 차종이 «갈 수 있는 길»을 바꾼다 | 이륜차는 고속도로를 뺀다 (7km·29분 차이) |
| 값이 30분 만에 늙는다 | 104분/1,900원 → 114분/3,800원 |
| 이탈 임계 500m | 09-03 GPS 2,350점 · 중앙 46m · 500m 밖 17% |

### 🟡 근사·가정

- **「고속도로우선」은 `TIME` 근사다** — 8구간 중 7개는 추천과 같았고, 갈린 하나에서
  정확히 고속도로를 골랐다. **어긋남이 0 은 아니다.** 그래서 §5(고른 것을 남긴다)로 잰다
- **터널 이름이 응답에 나오는지** 아직 못 봤다

### 🔴 가설 — 재 본 적이 없다

- *"무료도로를 고르면 합짐이 는다"*
- *"30분이 생기면 비싼 콜을 잡는다"*

👉 그래서 **고른 것을 남기는 일**이 코드보다 먼저다. 쌓여야 답이 나온다.
   지금 우리 몫은 **기사님이 고를 수 있게 해 드리는 것**까지다 (규칙 ① 콜의 주인은 기사님이다).
