v1~v22 의 최종 정리본. 앞으로 새 경우는 그림을 새로 그리지 않고 이 표에 한 줄 추가한다. 구현 시 이 문서가 곧 명세다.

Ⅱ. 무대 부품

부품정의상태(변형)
지도 (배경)한 사이클 전체 — 모든 정거장 + 현위치 + 경로선 정거장 색: 지나옴 초록 · 지금 목표 파랑(크게+빛) · 남음 회색 · 후보 노랑
평가 중엔 후보 구간을 노란 점선으로 겹침
이름표지금 목표 정거장에 «⑨ 동이름 · 거리·분 · N번 콜 · 단계 · 📞» 탭 → focus={콜,단계} + 시트 전체
접근 알림(2km) 오면 강조·통화 유도
시트 (그릇)3단 스냅: 엿보기(1줄) · 반(무대 60%) · 전체(무대 100%). 드래그 손잡이 상단 웹 자작 (React — OS·RN 아님) · 한 번 만들어 계속 씀
엿보기 줄🔴 상태에 따라 내용이 바뀌는 한 줄 — 시트가 내려가 있어도 이 줄이 무대의 자막 아래 Ⅲ 표의 «엿보기 줄» 열이 정의
콜 카드 + 스텝 시트시트 안 내용물 — 지금 콜 덱 그대로 (요약줄·카드·6단계·신고 시트) focus 가 오면 그 콜·그 단계 펼친 채 그림

Ⅲ. 상태 규칙 표 — 이 표가 제품이다

상태 (신호)슬롯시트 높이엿보기 줄지도
S1 콜 없음필터엿보기«진행 중인 경로 없음 · 새 콜 대기»현위치만
S2 정차·콜 있음 (5km/h↓ 10초)필터반(목록이 올라와 있음)사이클 상단부
S3 주행 (20km/h↑ 10초)필터엿보기다음 정거장·단계 · 남음/총 · 속도사이클 전체 + 이름표
S4 새 콜 평가 (심사 시작)심사석최소—후보 붙인 미리보기 (노란 점선 · +km +분)
S5 KEEP 직후필터 복귀전체 (자동)—흐림
　→ 그 콜의 상차지 통화 스텝이 열린 채 — 통화 완료/스킵이 시트를 도로 내림 (킵 직후 바로 통화 원칙)
S6 정거장 탭 (지도)그대로전체——
　→ focus={그 콜, 그 단계} — 지나온 곳은 확인·수정, 남은 곳은 미리보기. 저장이 시트를 내림
S7 정거장 도착·정차 (GPS 500m)필터전체 (자동)—그 정거장 확대
　→ 그 콜의 신고 시트가 마중 — S6 과 같은 문법의 자동판
취소/타임아웃필터 복귀이전 상태로—미리보기 걷힘

Ⅳ. 전환 원칙

자동이 안전한 이유시트 높이·지도는 표시만 — 필터·콜 상태를 안 바꾼다 (국면 전환과 다름)
사용자 손이 이긴다드래그가 곧 의사 표현 — 터치 후 30초는 자동 전환 유예
완료 행동이 문을 닫는다통화 완료·시트 저장 → focus 해제 + 시트 자동 복귀 (뒤로가기를 찾을 일 없음)
통신은 부모를 통해패널 간 직접 통신 없음 — stage(시트높이) · focus(콜·단계) · 파생 제조소 세 상태를 Dashboard 가 들고 모두가 바라봄
