# 폰 상태 바 — 관제웹이 폰에 대해 보여 주는 모든 것

> **2026-09-02 기사님과 함께 정리.**
> **2026-09-18 기사님 피드백 반영: 3단계 상태 분류 체계 확립 및 상태 용어 명확화.**
> 기사님: *"폰 상태영역에서 각 폰에 노출되는 것이 정확하지 않은 것 같아. '연결끊김'은 접근성이 꺼진 건지 연결이 끊긴 건지 단어를 명확하게 하고 싶고, 배차망 안의 알 수 없는 화면인지 그냥 바탕화면인지 분류해서 한눈에 알고 싶어."*
> 화면 파일: `client-app/src/components/dashboard/DeviceControlPanel.tsx`
> 공통 로직: `shared/src/screenLabels.ts`, `shared/src/index.ts`

이 문서의 핵심 목적은 **폰의 물리적 상태와 배차망 앱의 위치를 왜곡 없이 1~2초 만에 파악**하여 기사님이 필요한 조치를 즉각 취할 수 있도록 하는 것이다.

## 1. 폰 상태 3단계 계층 분류 체계 (2026-09-18 확정)

단순히 "연결 끊김"이나 "알 수 없는 화면"으로 뭉뚱그리지 않고, **기기 상태 → 배차망 내부 위치 → 배차망 밖 이탈**의 3계층으로 구분한다.

```
[Tier 0: 기기/통신 건전성] 폰 하드웨어 및 원달 앱 생존 여부
       ↓ 정상일 때
[Tier 1: 배차망 앱 내부]  배차망(인성/픽커/화물24) 안에서의 현재 화면
       또는
[Tier 2: 배차망 앱 외부]  배차망 앱 밖으로 벗어난 상태 (런처 홈/타 앱)
```

## 3. 포함 관계와 진실 공급원 원칙

```
1 폰 이름
├ 5 앱 버전 (접힘)
└ 2 살아있나 ────── 3 조용한가 (⏱️) · 4 누적 (접힘)
  └ 6 화면 켜짐 (💤 화면 꺼짐)
    └ 7 접근성 (⚠️ 접근성 꺼짐)
      └ 8 배차망 ─── 9 화면명 (6+8+9 한 배지로 통합 렌더링)
        ├ 10 앱 작업 단계 (접힘)
        └ 11 성적표 (통과 0일 때만)

12 모드 (자동/알람/직접 — 관제가 변경하는 유일한 설정)
└ 13 필터 배지 (첫짐/합짐/경로)
```

### 포함 관계의 핵심 규칙
1. **위가 꺼지면 아래는 그리지 않는다 (단언 금지)**:
   - 폰 통신이 끊겼거나 접근성이 꺼졌을 때, 과거에 마지막으로 봤던 `[픽커 콜리스트]`를 그대로 유지하면 기사님이 "지금도 리스트를 보고 있구나"라고 착각하게 된다.
   - 따라서 통신이 끊기면 화면명 대신 **왜 끊겼는지(`⚠️ 접근성 꺼짐`, `📵 통신 두절`, `🛑 앱 종료됨`, `📵 통신 끊김`)**를 그 자리에 즉시 교체하여 노출한다.
   - 화면이 꺼졌으면 `[💤 화면 꺼짐]` 하나만 노출하며, 이전의 배차망과 화면명은 지운다.
2. **배차망 밖과 배차망 안의 분리**:
   - 사용자가 홈 버튼을 눌러 런처로 나가면 `[픽커]` 배지를 떼고 `[📱 바탕화면 (홈)]`으로 표시한다.
   - 사용자가 다른 앱(카카오톡 등)을 켜면 `[📱 기타 앱 (배차망 밖)]`으로 표시하여 스캔이 불가능한 상태임을 명확히 알린다.
   - 배차망 앱 안에 머물고 있으나 알 수 없는 화면인 경우 `[픽커 ⚠️ 미등록 팝업]`으로 표시하여, 앱을 켤 필요 없이 팝업만 닫으면 됨을 알려준다.
3. **관제웹 소켓 단절과 폰 단절의 분리**:
   - 상단 헤더 시계 자리의 웹소켓 연결이 끊겼을 때는 `☁️ 서버 끊김`으로 표기하여 폰의 `📵 통신 두절`과 명확히 구분한다.

## 4. UI 렌더링 규격 및 공간 엄선

폰 한 줄 공간(약 56칸, 400px 내외) 안에 필수 정보가 겹침 없이 1~2초에 읽혀야 한다.

```
[평소 정상]      A24  [픽커 콜리스트]      첫짐  13:19                     [자동]
[미등록 팝업]    A24  [픽커 ⚠️미등록팝업]  첫짐  13:19 ⏱️                  [자동]
[홈으로 나감]    A24  [📱 바탕화면 (홈)]         13:19 ⏱️                  [자동]
[기타 앱 실행]   A24  [📱 기타 앱(밖)]          13:19 ⏱️                  [자동]
[접근성 꺼짐]    A24  [⚠️ 접근성 꺼짐]          13:19                     [자동]
[화면 슬립]      A24  [💤 화면 꺼짐]            13:19                     [자동]
[통신 끊김]      A24  [📵 통신 두절]            13:19 ⏱️                  [자동]
```

- **상시 노출 6요소**: 폰 이름, 배지(상태/화면), 필터 배지, 시각(분 단위), 모드 버튼, 조용함 아이콘(`⏱️`, 30초 이상 정적 시).
- **조건부 노출**: 성적표(`본42 · 통과0 요금12`) — 필터 통과 콜이 0개일 때만 원인 분석을 위해 자리 제공.
- **접힌 서랍**: 누적 카운트, 앱 버전, 세부 작업 단계는 폰 이름을 탭했을 때 하단 카드로 펼쳐짐.
