## 3. 두 층으로 가른다

```
[1층] 되나 안 되나 — 무조건 빨간불
   성질  같이 못 싣는 짐인가 (위험물 상극 · 금지 낱말)
   약속  통화로 굳힌 약속이 늦나         (임시 약속이 늦으면 → 2층에서 약속 0점)
   공간  신고한 적재로 자리가 없나       (추정 적재로 없으면 → 2층에서 공간 0점)
      │
      └─ 하나라도 걸리면 🔴 사고. 점수 평균에 들어가지 않는다
      🔴 무조건 빨간불은 확정값만 본다 — 통화로 굳힌 약속 · 기사님이 신고한 적재.
         추정값(잡은+20분 임시 시한 · 차종 글자에서 넣은 기본 박스 수)은 점수다
      │
[2층] 얼마나 좋나 — 점수
   합짐  우회 시급 하나 — 두 점 꺾은선       (안 잡아도 손해가 없다 → 엄격하게)
   첫짐  시급 × 목적지 전진 배수             (안 잡으면 0원이다 → 너그럽게)
```

- 🔴 **판정은 색만 낸다.** 점수가 높다고 자동으로 잡지 않는다 (규칙 ①)
- **첫짐과 합짐은 눈금이 다르다** — 기회비용이 다르기 때문이다. 함수는 하나다(08-29 결정 유지). 사실을 채운 뒤 국면(`first`/`merge`)으로 눈금만 고른다
- **확정값만 무조건 빨간불** — 약속(통화로 굳힌 것만, 코드 그대로)과 공간(신고한 적재만, 기사님 확정)이 같은 원칙이다.
  추정값으로 색을 덮으면 오독 한 번에 멀쩡한 콜이 🔴 가 된다 — 차종 불일치를 딱지로 내린 것과 같은 까닭

## 4. 공식

### 4-1. 무조건 빨간불

| 기준 | 🔴 가 되는 조건 | 값의 출처 | 조건이 추정값에만 걸리면 |
|---|---|---|---|
| 성질 | 실린 짐과 상극인 성질 · 금지 낱말 | 콜 글자 · 실린 콜의 성질 | — (추정 없음) |
| 약속 | 이미 실린 콜의 **통화로 굳힌** 도착 약속이 늦는다 | `timing.ts` 의 `declared` 약속 | 약속 점수 0 (색은 안 덮는다) |
| 공간 | **기사님이 신고한** 박스 수로 자리가 없다 | 통화 신고 · 콜 옵션에서 고른 값 | 공간 점수 0 (색은 안 덮는다) |

⚠️ 잡아 둔 콜을 전부 더해 적재를 세는 셈(예약 ≠ 실린 짐)은 따로 고친다. 그 전에는 신고값으로도 3~4콜에서 막힐 수 있다.

### 4-2. 합짐 — 두 점 꺾은선

기사님이 정하는 숫자는 둘이다. **보통 시급 T**(50점) · **꿀 시급 H**(100점).

```
ΔT ≤ 0          →  100점  (길목이다. 우회가 없다)
h = 추가 운임 ÷ ΔT(추가 우회 분) × 60

h ≤ T           →  50 × h / T
h > T           →  50 + 50 × (h − T) / (H − T)      ← 100 에서 자른다
```

| 우회 시급 h | 점수 | 색 |
|---:|---:|---|
| 1.5만 | 25 | 🟡 똥 — 우회할 가치 없음 |
| 2.4만 | 40 | 🟢 보통 하한 |
| 3.0만 | 50 | 🟢 보통 — 일상적인 합짐 |
| 3.9만 | 73 | 🔵 꿀 하한 |
| 4.0만 | 75 | 🔵 꿀 — ep5 의 «가치 있는 콜» |
| 5.0만 이상 | 100 | 🔵 꿀 — ep5 의 «대박» |

### 4-3. 첫짐 — 시급 × 목적지 전진 배수

```
돈점수     = min(100, h_solo ÷ S × 100)                    S = 첫짐 기준 시급
h_solo     = 운임 ÷ (주행 + 대기·상하차 분) × 60

전진율 p   = (dist(현위치, 목적지) − dist(하차지, 목적지)) ÷ dist(현위치, 하차지)
             −1 ≤ p ≤ 1   (완전히 목적지 쪽 1 · 수직 0 · 반대 −1)

목적지배수 = clamp(1 + (Mmax − 1) × p,  Mmin,  Mmax)

첫짐점수   = min(100, 돈점수 × 목적지배수)
```

**왜 덧셈이 아니라 곱셈인가** — 덧셈(`돈 × 0.4 + 목적지 × 0.6`)이면 **요금 0원짜리가 60점(보통)이 된다.**
목적지 가치는 돈을 **키우는 배수**이지 돈과 더하는 것이 아니다. 곱셈이면 「돈이 0이면 총점도 0」이 저절로 따라온다.

**전진율의 분모가 «현위치 → 목적지»가 아닌 까닭** — 그 분모는 목적지에 가까워지면 0 으로 수렴해 터지고,
터지기 전에도 목적지 근처에서는 어떤 콜이든 전진율이 낮게 나온다. 목적지 근처가 콜이 많은 곳일 수 있다.
분모를 **이 콜이 움직이는 거리**로 두면 0 이 되지 않고 뜻도 정확해진다 — «이 콜로 움직이는 거리 중 얼마가 목적지 쪽으로 줄어드는가».

**전진율은 지리 기준의 첫 잴 값이다** (기사님 확정) — 08-29 에 «잴 값이 생기면 켠다»고 열어 둔 자리 그대로다.
첫짐에만 곱한다. 합짐의 지리는 우회 시급이 이미 센다. 하차지 주변에 콜이 얼마나 있나(후속 콜 빈도)는 **별개**라 건드리지 않는다.

**목적지 좌표의 출처** — 기사님이 그날 콜 필터에 두신 목적지(노선 타겟)다. 지역 목록(강남 +30 같은 것)은 지어내지 않는다 (규칙 ④).

**잴 수 없을 때** (규칙 ⑤-2)

| 경우 | 배수 | 딱지 |
|---|---:|---|
| 목적지를 안 정하셨다 | 1.0 | 「목적지 미설정」 |
| 목적지 이름으로 좌표를 못 구했다 | 1.0 | 「목적지 미확인」 |
| 현위치가 목적지 반경(`destinationRadiusKm`) 안이다 | 1.0 | — (도착했으니 전진할 것이 없다) |

🔴 **거리는 직선으로 잰다.** 전진율은 방향 지표이지 거리 값이 아니다. 도로로 재면 콜마다 카카오를 불러야 한다.
왕복 분리 도로에서 직선이 실제와 크게 다른 것은 알려져 있으니 **이 값을 거리로 읽지 않는다.**
