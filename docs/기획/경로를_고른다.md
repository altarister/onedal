## 1. 무엇이 맞바꿔지나

**고속도로는 시간을 사고 합짐 기회를 판다. 국도는 반대다.**

```
고속도로   주행 ↓      ·  경로 주변 합짐 ↓ (진출입이 드물다)  ·  통행료 ↑
국도       주행 ↑      ·  경로 주변 합짐 ↑                    ·  통행료 0
```

그리고 기사님이 짚은 두 번째 고리 — **줄어든 주행이 그냥 사라지지 않는다.**

```
상차버퍼 = 상차 약속 − (현위치→상차지 주행 + 상차 정차)
           ↑ 콜 잡은 시각 + 20분 (고정)      ↑ 경로 선택이 줄인다
```

상차 약속은 **주행에서 파생되지 않는 고정값**이라(규칙 ⑤-5), 주행이 줄면 **상차버퍼가
그만큼 커진다.** 그 자리에서 더 기다릴 수 있고, 그러면 **급하게 아무거나 안 잡아도 된다.**

👉 **그래서 이건 «빠른 길 찾기»가 아니라 «어떻게 벌 것인가»의 선택이다.**

| | 벌이의 방식 |
|---|---|
| 고속도로 | 빨리 끝내고 **좋은 첫콜을 골라** 번다 |
| 국도 | **가는 길에 합짐을 붙여** 번다 |

어느 쪽이 나은지는 그날 콜이 얼마나 뜨는지, 경로 주변 밀도가 어떤지에 달렸다 —
**우리가 정할 수 없다. 그래서 기사님이 고른다** (규칙 ① 콜의 주인은 기사님이다).

## 1-1. 🔴 **선택은 «어디서 콜을 잡을지»를 함께 정한다** (기사님 2026-09-04)

> *"그래서 내가 타입을 **노선 · 관내 · 복귀** 이렇게 부르는 거야.
> 파주를 목적지로 첫 콜이 들어오면 그걸 가지고 **3가지 노선이 들어오고**, 기사가
> **30초 안에 3개를 눌러보고 하나를 선택하고 킵**을 누르는 거야. 그럼 **노선이 결정
> 나는** 거지.
> 기사는 **고속도로를 선택했다면 최대한 지금 자리에서 파주 가는 콜을 많이 잡고 출발**
> 하려 할 거야. **무료도로를 선택했다면 여기서 조금만 대기하고 가는 길에 나오는 콜을
> 많이 잡겠다**는 생각을 할 거야."*

**이것이 이 판의 뼈대다.** 경로 선택은 «어느 길로 가나»가 아니라
**«어디서 콜을 모으나»** 를 정하는 일이다.

| | 고속도로를 골랐다 | 무료도로를 골랐다 |
|---|---|---|
| 속뜻 | *"길에서는 못 줍는다"* | *"길에서 줍겠다"* |
| **어디서 모으나** | **지금 이 자리** — 출발 전에 최대한 | **가는 길** |
| 상차버퍼를 어떻게 쓰나 | **다 쓴다** (여기서 기다린다) | **조금만 쓰고 출발** |
| 그래서 필터는 | **현위치 주변을 넓게** | **경로 주변을 넓게** |

### 🟢 그 두 축이 **이미 있다** — 새로 만들지 않는다

| 축 | 지금 뜻 (`shared/src/index.ts`) |
|---|---|
| **`pickupRadiusKm`** | *"내 위치 반경 상차지 탐색(km)"* → **「여기서 잡는다」** |
| **`detourRadiusKm`** | *"경로 주변 이탈 허용 반경"* → **「가는 길에 잡는다」** |

👉 **경로 선택이 이 둘의 무게를 옮긴다.** 축을 더하는 게 아니라 있는 축의 값을 바꾼다 (규칙 ③).

```
고속도로우선 →  pickupRadiusKm ↑   ·  detourRadiusKm ↓
무료도로     →  pickupRadiusKm ↓   ·  detourRadiusKm ↑
추천         →  지금 값 그대로
```

🔴 **이게 열린 물음 ①의 더 나은 답이다.** 나는 *"고속도로 구간에서 띠를 좁힌다"* 고
   제안했는데, 그건 **손해를 줄이는** 답이었다. 기사님 모델은 **다른 데서 벌게 하는** 답이다.
   띠를 좁히면 잡을 데가 없어지는데(경우의 수 B-1), 그때 **현위치 반경이 대신 열린다.**

⚠️ **얼마나 옮길지는 아직 숫자가 없다.** 표본이 쌓여야 안다 (§5).
   처음에는 **기사님이 손으로 조절할 수 있게** 두는 것이 맞다.

## 2. ② 값 — 카카오가 실제로 주는 것 (실측 2026-09-04)

09-03 실제 구간(집 127.294001,37.377178 → 가산동 126.883619,37.468967 · `car_type=1`):

| 보낸 것 | 거리 | 시간 | 통행료 |
|---|---|---|---|
| `priority=RECOMMEND` | 47.5km | **104분** | 1,900원 |
| `priority=TIME` | 47.5km | 104분 | 1,900원 |
| `priority=DISTANCE` | **44.8km** | 111분 | 1,900원 |
| `avoid=toll` | 51.9km | 132분 | **0원** |
| **`avoid=motorway`** | 54.6km | **134분** | **0원** |
| `avoid=ferries` · `schoolzone` · `uturn` | 47.5km | 104분 | 1,900원 (이 구간엔 차이 없음) |

🔴 **고속도로가 30분을 산다. 값은 1,900원** — 시간당 3,800원인 셈이다.
   이 숫자가 기사님 논리의 뒷받침이다.

⚠️ `RECOMMEND` 와 `TIME` 이 이 구간에선 같았다. **다른 구간에서도 같은지는 모른다** —
   선택지를 «추천/최단시간» 둘로 나눌 값어치가 있는지 더 재 봐야 한다.

### 🟢 대안경로도 API 로 온다 — 우리가 안 읽고 있었을 뿐이다

`alternatives=true` 를 넣으면 **경로가 여럿** 온다:

```
routes[0]  49.0km / 105분 / 3,800원
routes[1]  56.6km / 115분 / 1,000원   ← 10분 더 걸리고 2,800원 싸다
```

🔴 `kakaoService.ts` 는 **`data.routes[0]` 만 읽는다.** 기사님이 카카오내비 화면에서
   보신 「대안경로」를 우리도 만들 수 있다.

⚠️ `alternatives=true` 를 켜면 **routes[0] 자체가 달라졌다**(47.5km/1,900원 → 49.0km/3,800원).
   왜인지 모른다 — 실시간 교통일 수도, 다른 후보군일 수도. **켜기 전에 다시 재야 한다.**

### 🟢 통행료는 이미 응답에 있다 (옛 0-I)

```
summary.fare = { taxi: 65500, toll: 1900 }
```
그 1,900원이 **카카오내비 앱 화면의 1,900원과 같았다** (2026-09-04 교차검증).

⚠️ `orders.tollFare` 는 **다른 값이다** — 배차망 화면에서 긁은 「탁송료/경유비」
(`parser.ts` 의 `extractField(lines, "탁송료")`). **한 칸에 섞으면 안 된다** (§3).

### 🔴 설정 셋이 죽어 있다 (옛 0-I)

`user_settings` 에 있는데 카카오 URL 에 **안 실린다** — `avoid_toll` · `car_hipass` · `car_fuel`.
**기사님이 「유료도로 회피」를 켜도 아무 일도 안 일어난다.** 화면이 조용히 거짓말한다.
👉 이 판이 그 셋을 살리는 자리다. 새로 만드는 게 아니라 **잇는 것**이다.

## 3. ⑤ 읽는 곳 — 🔴 **한 선택이 셋을 동시에 건드린다**

| 읽는 곳 | 무슨 질문의 답으로 | 지금 |
|---|---|---|
| **콜 필터**(앱) | *"경로 주변 어디까지 콜을 받나"* | 🔴 **직선 거리**로 잰다 |
| **서버 판정** | *"이 콜을 붙이면 얼마나 돌아가나"* | 🟢 **이미 도로 기준**이다 (카카오에 다시 묻는다) |
| **내비 링크** | *"기사님 폰이 어느 길로 안내하나"* | 🔴 **기준을 안 실어 보낸다** |

### 3-1. 진짜 손해는 «잡아 놓고 취소하는 것»이다

서버 판정은 이미 맞다. 문제는 **콜 필터의 경유 반경이 직선**이라는 것이다 —
고속도로에서 *"2km 옆"* 인 콜이 실제로는 **진출입 때문에 22분**이다.

그래서 앱이 잡아 오고, 서버가 «많이 돌아간다»고 표시하고, 기사님이 취소한다.
🔴 **안전취소는 위약금이 없어도 배차망 취소 횟수 10회에 들어간다**
   ([용어집 §2-1](../지금/용어집.md)). **하루에 열 번뿐인 자원을 고속도로에서 태운다.**

⚠️ **그렇다고 필터를 조이지 않는다** (규칙 ⑤: 앱은 느슨하게, 놓치지 않는 것이 일이다).
   고칠 자리는 «반경을 줄이는 것»이 아니라 **«반경을 무엇으로 재는가»** 다. §7-② 참조.

### 3-2. 🔴 고른 기준이 내비까지 안 가면 선택이 거짓말이 된다

기사님이 «무료도로»를 고르셨는데 **카카오내비가 고속도로로 안내**하면, 화면은 무료를
약속하고 실제는 통행료가 나온다.

🟢 **풀렸다 (2026-09-04)** — `rpOption` 표를 찾았고(§7-①), 셋 다 실을 값이 있다:
   추천 `100` · 무료도로 `2` · 고속도로우선 `6`.
   👉 [내비_갈아타기](내비_갈아타기.md) §2 의 *"rpOption 은 안 보낸다"* 를 **뒤집는다 — 보낸다.**

🟡 **남은 어긋남은 «고속도로우선» 하나뿐이다** — 내비는 `6` 으로 정확히 가는데 우리는
   `TIME` 으로 근사한다(§7-①). 8구간 중 7개가 같았으니 작지만, **0 은 아니다.**
   👉 §5 에 «무엇을 골랐나»를 남기므로, 나중에 **실제로 얼마나 어긋났는지 잴 수 있다.**

## 4. ③ 시점 — **첫콜 결재 순간 하나뿐이다**

기사님 말씀이 정확하다. 앞뒤로 자리가 없다:

```
STANDBY(첫짐 탐색)   경로가 아예 없다 — 고를 대상이 없다
      ↓  첫콜 KEEP   ◀── 🎯 여기. 경로가 여기서 태어난다
GATHERING(합짐 수집) 필터가 이미 그 경로로 돌기 시작했다 — 늦다
```

**그리고 이때 기사님은 서 있다.** 운전 중이 아니라 입력이 가능한, 하루에 몇 없는 순간이다
([[driver-cannot-input-while-driving]] 의 예외).

⚠️ **합짐 콜에는 이 선택을 안 준다.** 경로는 첫콜이 정하고, 합짐은 그 경로에 붙는 것이다.
   (규칙 ⑥ 시퀀스를 압축하지 않는다)

## 5. ① 스키마 — 고른 것을 **남긴다**

🔴 **안 남기면 어느 전략이 나았는지 영영 모른다.** 이 레포에는 이미 전례가 있다 —
`reach_samples` 가 도달 계수를 역산하려고 표본을 쌓는다. 같은 이유다.

| 무엇 | 어디에 | 왜 |
|---|---|---|
| **콜별로 무엇을 골랐나** | `orders` 에 한 칸 | 그날 그 콜이 어느 기준으로 갔나 |
| **카카오 통행료** | `orders` 에 한 칸 — 🔴 `tollFare` 와 **다른 칸** | §2 — 배차망 「탁송료」와 섞으면 안 된다 |
| 평소 기준 | `user_settings` — **`avoid_toll` 이 이미 있다** | 새로 만들지 않는다. 죽은 것을 잇는다 |

⚠️ **마이그레이션은 안 한다**(테스트 단계). 지우고 다시 만든다.
   다만 **지금 안 쌓으면 과거분은 영영 없다** — 그래서 이 판이 지금 필요하다.

## 6. ④ 화면

### 6-0. 🟢 **의도를 미리 고른다 — 30초 밖에서** (기사님 안 2026-09-04)

> *"만약 필터 설정창에 **「여기서 콜을 잡고 간다」와 「가는 길에 콜을 잡는다」** 이런 버튼이
> 있다면, 첫콜이 뜰 때 그걸 **미리 선택해서 보여줄 수 있고** 기사가 다 눌러볼 필요 없이
> **그냥 킵을 누를 수 있을** 거야. 그럼 **우리 시스템이 쉬워지는** 거지."*

🔴 **이게 §6 의 뼈대가 된다.** 내 안은 «30초 안에 셋을 눌러 비교»였는데,
   **결정을 30초 밖으로 빼내는 것**이 낫다.

| | 내 안 | 기사님 안 |
|---|---|---|
| 언제 고르나 | 30초 안에 | **미리 · 여유 있을 때** |
| 무슨 말로 | 「무료도로/고속도로우선」 — **수단** | **「여기서 잡고 간다 / 가는 길에 잡는다」 — 목적** |
| 결재 때 | 셋을 눌러 본다 | **그냥 KEEP** |
| 카카오 호출 | 결재마다 3번 | **1번** (나머지는 눌렀을 때만) |

**말이 바뀌는 것이 핵심이다.** 「무료도로」는 *어떻게* 가느냐이고,
「가는 길에 잡는다」는 ***왜* 그렇게 가느냐**다. 기사님이 실제로 하는 생각은 뒤쪽이다.

```
설정에서 고른 의도            첫콜 결재에 미리 채워져 나오는 것
──────────────────────────────────────────────────────────
🚚 여기서 잡고 간다     →   고속도로우선 · pickupRadius ↑ · detourRadius ↓
🛣️ 가는 길에 잡는다     →   무료도로     · pickupRadius ↓ · detourRadius ↑
```

🟢 **기본값이 «시스템의 기본»이 아니라 «기사님이 말한 의도»가 된다.**
   그래서 **대부분 탭이 0 번**이다 ([[prefill-then-driver-confirms]] 의 제대로 된 모습).

⚠️ **그래도 숫자는 보여야 한다** — 「가는 길에 잡는다」를 골라 두셨어도 그 콜에서
   무료도로가 **200분**이면 바꾸실 수 있어야 한다. **기본이 채워진 채로 숫자가 함께 뜬다.**

🟢 **시스템도 쉬워진다** — 결재 순간에 카카오를 **한 번만** 부르고,
   다른 선택지는 **눌렀을 때** 부른다. 3배 싸고 3배 빠르다.

### 아직 안 정한 것

### ✅ 기사님이 정하셨다 (2026-09-04)

> *"버튼은 3. **기본으로 클릭 되어 있다.** 필터에서 바꾸면 바뀌어 있다.
> **오늘만·평소를 필터 설정 마지막에 선택**할 수 있다.
> 말이 풀어져 있어서 **용어집에 넣을 필요 없다.**"*

| | 정해진 것 |
|---|---|
| **버튼** | **셋.** 하나는 **언제나 눌려 있다**(빈칸이 없다 — 규칙 ④ «빈 필터는 고장이다»와 같은 결) |
| **어디서 바꾸나** | **필터에서.** 바꾸면 결재 화면에 **그게 눌린 채로** 나온다 |
| **오늘만 / 평소** | **필터 설정 맨 끝에서 고른다.** 셋을 고른 «뒤»에 «이걸 오늘만 쓸까 평소로 둘까»를 묻는다 |
| **용어집** | **안 넣는다** — 「여기서 잡고 간다」는 풀어 쓴 말이라 설명이 필요 없다 |

🔴 **«맨 끝에서 고른다»가 중요하다.** 지금 이 레포는 ⚙️설정(평소)과 🔍필터(오늘만)가
   **다른 화면**이라 2026-08-12 에 두 값이 갈라졌다(*"설정엔 파주인데 필터를 열면 용인"*).
   기사님 안은 **한 화면에서 고르고 맨 끝에 «어디에 저장할까»를 묻는** 방식이라
   갈라질 자리가 없다. **기존 두 그릇은 그대로 두되, 쓰는 문은 하나다.**

## 6-1. 결재 화면 — 미리 눌려 있고, 바꿀 수 있게

🔴 **30초 안전취소 안에 옵션까지 고르면 «색만 보고 1~2초»가 깨진다** (규칙 ⑤-3).

👉 **기본값을 미리 눌러 둔다.** 그냥 KEEP 하면 **지금과 똑같이 동작한다.**
   바꾸고 싶을 때만 바꾼다 ([[prefill-then-driver-confirms]]).

🔴 **다만 기사님은 실제로 눌러 보신다** — *"30초 안에 3개를 눌러보고 하나를 선택하고
   킵을 누르는 거야"* (2026-09-04). 그러니 **눌렀을 때 즉시 바뀌어야** 한다:
   숫자·지도 선·«어디서 모을지»가 그 자리에서 함께 움직여야 고를 수 있다.
   미리 눌러 두는 것은 **안 누르셨을 때의 안전망**이지, 안 누르시라는 뜻이 아니다.

👉 **고르라고 하지 말고 «맞바꿈»을 보여 준다.** 이름(«빠른길»)보다 숫자가 빠르다.

🔴 **셋을 다 적는다 — 거리·시간·통행료** (기사님 2026-09-04:
   *"여기에 걸리는 시간, 거리, 통행료를 감안하고 생각하겠지."*).

```
▸ 추천        130km   113분  10,000원
  무료도로      91km   200분       0원
  고속도로우선  130km   113분  10,000원
```

⚠️ **거리를 빼면 안 된다 — 거리는 기름값이다.** 그리고 시간에서 파생되지도 않는다:
   광주→파주에서 무료도로는 **더 짧으면서**(91 vs 130km) 더 느렸다(200 vs 113분).
   시간만 보면 «무료도로는 손해»인데, **기름값까지 보면 다시 셈이 선다.**
   🟢 `user_settings.car_fuel` 이 있으니 언젠가 기름값을 원으로 환산할 수 있다 —
      다만 그건 **정산의 일**이다. 지금은 **km 를 적어 기사님이 머릿속에서 재게** 한다.

⚠️ 비교를 만들려면 **선택지마다 카카오를 따로 불러야 한다** (한 콜에 2~3번).
   쿼터는 괜찮다 — 09-03 하루가 128회였고 유료는 0원이었다.
   🔴 **다만 심사 중인 모든 후보에 대해 부르지 않는다.** 결재 대상 하나만이다.

## 7. 먼저 정해야 할 것 — 여쭐 것 셋

### ✅ ① 선택지는 **셋**으로 확정 (기사님 2026-09-04)

기사님: *"추천과 무료도로 고속도로우선 이렇게 3개 있으면 딱인데."*

§1 의 **전략 세 극점과 정확히 맞는다** — 균형 / 합짐으로 번다 / 골라잡기로 번다.
(최단거리는 전략이 아니라 기술적인 값이라 뺐다.)

| 기사님 선택 | 우리 길찾기 | 내비 `rpOption` | 성격 |
|---|---|---|---|
| **추천** | `priority=RECOMMEND` | **100** | 균형 |
| **무료도로** | `avoid=toll` | **2** | 통행료 0 · 시간 ↑ · **합짐 기회 ↑** |
| **고속도로우선** | `priority=TIME` 🟡근사 | **6** | 통행료 ↑ · 시간 ↓ · **골라잡기** |

#### 🟡 「고속도로우선」은 근사다 — 왜 `TIME` 인가

우리 길찾기 API 에는 `rpOption 6` 에 딱 맞는 값이 **없다.** 그래서 09-03 여덟 구간을
전부 재서 골랐다:

**추천과 `TIME` 이 8구간 중 7개에서 같았다.** 갈린 하나가 **방화동→집** 인데:

| | 거리 | 시간 | 통행료 |
|---|---|---|---|
| `RECOMMEND` | 57.7km | 148분 | 1,000원 |
| **`TIME`** | **71.3km** | **142분** | **2,000원** |

13.6km 더 멀고 통행료가 두 배인데 **6분 빠르다** — 정확히 「고속도로 우선」의 행동이다.
👉 **갈리는 자리에서 정확히 고속도로를 고르고, 대부분 구간에서는 추천과 같아** 어긋날
여지도 작다. 완벽하지 않다는 것을 **화면과 기록에 남긴다** (§5).

#### `rpOption` 전체 표 (공식 레퍼런스 2026-09-04 확인)

| 값 | 뜻 | 우리 대응 |
|---|---|---|
| **100** | 추천 경로 *(기본)* | `RECOMMEND` ✅ |
| 1 | 가장 빠른 경로 | `TIME` ✅ |
| **2** | **무료 도로** | `avoid=toll` ✅ |
| 3 | 가장 짧은 경로 | `DISTANCE` ✅ |
| 4 | 자동차 전용 도로 제외 | `avoid=motorway` ✅ |
| 5 | 큰길 우선 | ❌ 없음 |
| **6** | **고속도로 우선** | 🟡 `TIME` 로 근사 |
| 8 | 일반 도로 우선 | ❌ 없음 |

⚠️ 2026-09-04 에 내가 *"큰길우선은 카카오에 대응이 없다"* 고 적었던 것은 **틀렸다** —
   `rpOption 5` 로 있다. 없는 것은 **우리 길찾기 API 쪽**이다.

#### 🔴 값이 실시간으로 움직인다

같은 구간(집→가산동)을 30분 간격으로 물었더니:
```
47.5km / 104분 / 1,900원   →   49.0km / 114분 / 3,800원
```
**교통이 반영된다.** 그래서:
- **비교표는 반드시 한 번에 불러야 한다** — 시차를 두면 «옵션 차이»가 아니라 «교통 차이»를 본다
- [남은 주행 분](남은_주행_분.md) 의 «값이 늙는다»가 생각보다 심각하다 — **거리와 통행료까지** 바뀐다

**② 콜 필터의 경유 반경을 무엇으로 잴 것인가** (§3-1)
직선 km 를 **분**으로 바꾸면 고속도로 문제가 저절로 풀린다. 하지만 그건
[남은 주행 분](남은_주행_분.md) 과 같은 재료를 쓰는 큰 판이다. **이 판에 넣을지 가를 것.**

~~**③ `rpOption` 조사**~~ → 🟢 **닫혔다** (2026-09-04, §7-① 표). 셋 다 실을 값이 있다.
값 1·2·3·4·5·6·8·100 의 뜻을 알아내야 한다. 문서에 없으면 **폰에서 눌러 가른다**
(경유지 이름을 그렇게 알아냈다).

## 9. 남는 의문 — 정직하게

🔴 **«국도를 고르면 합짐이 는다»는 아직 가설이다.** 그럴듯하지만 재 본 적이 없다.
   09-03 자료로 «경로 주변 콜이 실제로 몇 개였나»를 세면 실마리가 나온다. **아직 안 셌다.**

🔴 **«30분이 생기면 비싼 콜을 잡는다»도 가설이다.** 그 30분에 정말 더 좋은 콜이 오는지는
   콜이 뜨는 빈도에 달렸다. 표본이 없다.

👉 그래서 §5(고른 것을 남긴다)가 중요하다. **쌓여야 답이 나온다.**
   지금은 **기사님이 고를 수 있게 해 드리는 것**까지가 우리 몫이다 (규칙 ①).
