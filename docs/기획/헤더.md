# 헤더 — 「내 지금 상태」

> **2026-09-05 기사님 요청으로 전수조사.** 폰 상태바와 같은 방식으로 코드에서 요소를
> 꺼내 **값과 폭을 재고** 컬럼을 붙였다. ⬜ 는 **아직 화면에 없다** — 만들 것이지 있는 것이 아니다.
> 화면 파일은 `client-app/src/components/layout/Header.tsx` 다.

기사님: *"머리 부분은 **내 현상태**를 표현하고 싶었어. 로그인도 있고 내 설정을 불러오는
것도 있고 내 차도, 내 차의 상황도.. 서버랑의 통신도.."*

**다섯을 말씀하셨다.** 지금 헤더가 답하는 것은 그중 **셋**뿐이다.

| 기사님이 말한 것 | 지금 헤더에 | |
|---|---|---|
| 로그인 | ✅ 아바타 | |
| **내 설정을 불러오는 것** | ❌ **없다** | 실패해도 화면이 조용하다 |
| 내 차 | ✅ `1t` | |
| 내 차의 상황 | 🟡 건수만 | 적재·국면은 **아래 줄들**에 흩어져 있다 |
| 서버와의 통신 | ✅ 점 + 시계 | ⚠️ 시계는 **폰 시계**다 (아래 §3) |

## 2. 없는 것 — 기사님이 말했는데 헤더에 없는 것

| 요소 | 값 예 | 폭 | 지금 어디 있나 |
|---|---|--:|---|
| **설정을 불러왔나** ⬜ | `⚙️ 불러오는 중` · `⚠️ 설정 못 읽음` | 14 | **아무 데도 없다** |
| 적재 박스 | `📦 90/100` | 8 | 필터 요약줄 |
| 국면 | `합짐 수집` | 9 | 필터 요약줄 |
| 집 | `🏠 파주` | 6 | 설정창 안 |
| GPS | `📍 이동 62km/h` | 13 | 차량 줄 |

🔴 **「설정을 불러왔나」가 진짜 빈칸이다.** `GET /settings` 는 `.catch(() => {})` 로
**조용히 삼킨다** — 실패하면 차종이 `1t` 기본값으로 그려지고 **화면은 아무 말도 안 한다.**
그게 틀린 차종이면 필터가 통째로 어긋나는데 **아무 신호가 없다.**

⚠️ 나머지 넷은 **이미 다른 줄에 있다.** 헤더로 올리면 두 곳이 같은 것을 그린다 —
**올리는 것이 아니라 옮기는 것**이라야 한다. 그건 별도 판이다.

---

## 3. ⚠️ 시계는 **폰 시계**다 — 서버 시계가 아니다

`new Date()` 다. 그런데 바로 왼쪽에 **서버 연결 점**이 붙어 있어서
«서버가 이 시각을 말했다»로 읽힌다. 폰 시계가 틀어져 있으면 **아무도 모른다.**

🔴 이것은 판정에도 닿는다 — 상차 마감·안전취소 30초는 **서버 시각** 기준인데
화면은 폰 시각을 보여 준다. 둘이 갈라지면 «왜 벌써 끝났지»가 된다.

---

## 4. 정한 것 (기사님 2026-09-05)

- **테마 아이콘을 뺀다.** 지금도 아이콘은 없고 **차 이름이 곧 테마 버튼**인데,
  그건 «내 차»라는 뜻과 «테마»라는 손이 **한 칸에 겹쳐 있는 것**이다
- **내 차를 누르면 설정창**으로 간다. 테마는 그 안에 있다
  → 자주 보는 것이 자리를 갖고, 가끔 만지는 것은 그 안으로 들어간다

## 5. ⏳ 아직 안 정한 것 — 테마 자동 전환

| | 얻는 법 | 터널 | 문제 |
|---|---|---|---|
| 서버 시간 | 이미 있다 | ❌ | 계절을 못 따라간다 (겨울 17시 · 여름 20시) |
| **일출·일몰** | **API 없이 계산된다** — GPS 좌표로 태양 고도. 좌표는 이미 있다 | ❌ | 흐린 날엔 실제보다 늦다 |
| 폰 밝기 | 🔴 **지금 못 읽는다** | ✅ | 아래 |

🔴 **폰 조도는 웹에서 못 읽는다.**
`prefers-color-scheme` 은 조도가 아니라 **OS 다크 설정**이고, `AmbientLightSensor` 는
WebView 에 없다. 깔린 Capacitor 플러그인 넷(`background-geolocation`·`keep-awake`·
`haptics`·`social-login`) 중에도 없다 — **Kotlin 으로 `Sensor.TYPE_LIGHT` 을 읽는
플러그인을 새로 만들어야** 한다. 관제앱에 **네이티브 코드를 처음 쓰는 일**이 된다.

**제안** — 바탕은 일출·일몰, 터널은 나중에 조도로 얹는다. 둘은 다투지 않는다:
일출·일몰이 «오늘의 기본»을 정하고 조도가 «지금 이 순간»만 뒤집는다.
⚠️ 문턱이 없으면 터널에서 **1분에 세 번 깜빡인다.** 그 값은 **실제로 터널을 지나 봐야** 정한다.

⏳ **규칙 ⑤-4 의 다섯 중 ①②③이 비어 있다** — 스키마·기본값·읽고 쓰는 시점.
   비어 있으면 코드를 시작하지 않는다.
