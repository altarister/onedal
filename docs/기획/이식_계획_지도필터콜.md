### ① 「목업과 같게」의 뜻이 갈렸다 — **11분 만에 되돌렸다**

```
03:01  f7aaa36  목업에 없는 셋을 내리고…     ← 나: «목업에 없다 = 내린다»
03:12  8de47d6  내렸던 넷을 위 덩어리로 올려 되살린다   ← 기사님: «상단으로 이동하고 주석 풀어 줘»
```

기사님이 하신 말은 *"엘리먼트를 목업과 같이 만들고 같지 않은 것들은 주석 처리"* 였고,

하차 마감·판정 근거·카운트다운은 **없앨 것이 아니라 자리를 정할 것**이었다.
되돌린 커밋이 스스로 그렇게 적었다: *"문제는 «있다/없다»가 아니라 **자리**였다."*

🟢 **그때 잘한 것 하나** — 지우지 않고 **플래그로 내렸다**(`SHOW_CARD_EVIDENCE`).
그래서 11분 만에 되살릴 수 있었다. **이번에도 지우지 않는다.**

### ② 비교하던 자가 틀려 있었다 — **«답답하다»의 절반이 측정 오류**

퍼져 있었다 — **두 화면을 다른 자로 재 놓고 «다르다»고 이야기하고 있었다.**

### ③ 글자 크기가 조용히 일곱 자리 갈려 있었다

`dea93f0`: 폰 이름 14↔12 · 배지 13↔11.5 · 콜 줄 13.5↔14 …
눈으로 «비슷하다»고 넘어간 것들이다. 재서야 나왔다.

`min-h-[220px]` 를 위 덩어리까지 감싸는 상자에 걸었더니 그 220 을 위가 먹고

목업과 실물이 **같은 문제를 풀고 같은 답을 화면에 적으면** 이식이 된 것이다.
코드가 아니라 **화면이 답한다** (`onedal-web/CLAUDE.md` 의 `pnpm lab` 절과 같은 철학).

| 명령 | 무엇을 재나 | 언제 |
|---|---|---|
| `pnpm lab` | **화면 글자 대조** (콜 수·순번·약속·±·그물 동 수) | **P3 에서 되살린 뒤 모든 단계** |
| `pnpm drive` | 주행·도착 감지·궤적 (실물 서버) | **B 단계 필수** |
| `pnpm scenario` | 콜 생애 53건 (실물 서버) | **C 단계 필수** |
| `pnpm e2e:app` | 앱 화면 인식 → 필터 → 터치 | **C2(앱 파서) 이후 필수** |

🔴 **`pnpm lab` 을 고칠 때 반드시 넣을 것** (A4):
- **뷰포트를 `Emulation.setDeviceMetricsOverride` 로 진짜 400px 로 맞춘다** (`--window-size` 는 안 먹는다 — `ec4bb3a`)
- **잰 뷰포트·테마를 보고서 맨 위에 찍는다** — 다음 사람이 «같은 자였나»를 볼 수 있게
- **글자 크기 전수 대조**(`getComputedStyle().fontSize`)를 한 항목으로 (`dea93f0` 재발 방지)

## 12-4. 📋 요소·컴포넌트 전수 대조표 — **[이식_자리표.md](이식_자리표.md)**

§9-A2 가 요구한 «자리표»를 만들었다 (2026-09-11 · 363줄).
콜 리스트·지도·필터의 **요소 하나하나**를 목업↔실물로 놓고, 다른 점·기능 연결·위험 등급·
**처분 칸**(기사님이 채운다)을 붙였다. 디자인 토큰(색·글자 크기·바탕 축)도 대조했다.

거기서 나온 것 중 이 문서가 몰랐던 큰 것 셋:
- 🔴 **콜 색이 세 벌**이다 — 마커(4색) · 목업 선(8색) · 실물 선(7색). 「색 = 콜 번호」가 이미 깨져 있다
- 🔴 **목업 캔버스는 테마를 안 탄다** — 하드코딩 ~20종, 어두운 테마에서도 검정 글자
- 🔴 **목업 리스트의 `max-h-[240px]`** 가 실물 시트 높이 사슬(「나」=`auto`+58% 상한)을 끊는다

## 13. 그래서 지금 할 일 — 순서대로

```
1. 기사님 결정 넷 (§4 Q1~Q4)                     ← 지금 여기
2. 자리표 만들기 (A2) — 요소마다 «어디로, 어떻게»  ← 코드 전 마지막 관문
3. P2 검사 개정 → 빨간불 확인
4. P3 pnpm lab 되살리기 (400px 뷰포트 · 글자 대조)
5. A1 → A2 → A3 → B1 … (한 단계 한 커밋)
```

🔴 **2번(자리표)이 저번에 없어서 세 시간을 잃었다.** 표에 «처분» 칸을 두고
기사님이 낱말 계약(§9)의 다섯 말 중 하나로 적어 주시면, 나는 그대로만 한다.
