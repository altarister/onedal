## 0. 세 갈래는 «갈아끼움 방식»이 서로 다르다

| | 무엇 | 방식 | 실물의 지금 |

| **C4** | 화면 교체 — `OrderFilterModal` 을 목업 왼쪽 패널 모양으로 | `OrderFilterModal.tsx` |
| **C5** | 아웃풋 대조 — `labFilterOutput.test.ts` 13건이 **실물 아웃풋**에도 통과하게 | 검사 이관 |

🔴 **C 는 앱(Kotlin)까지 내려간다.** `scrap.ts:179-181` 의 «떼어내는 키 목록»과
`filterVersion` 해시, 앱 파서를 함께 고쳐야 한다. **여기서 마이그레이션은 없다** (지금은 테스트 단계).

## 7. 크기와 위험 — 정직하게

| 단계 | 손대는 줄 수(어림) | 위험 | 되돌리는 길 |
|---|---|---|---|
| A1 | +80 | 낮다 | 블록 제거 |
| A2 | ~120 교체 | **중간** — 세 검사가 지키는 자리 | `rowOf` 한 함수 되돌리기 |
| A3 | +150 | 중간 | 배선 끊기 |
| B1 | +250 (3층) | **높다** — DTO 변경 | 옛 `routePolyline` 을 남긴 채 더한다 |
| B2~B4 | ~600 | 중간 | 무대 토글로 옛 화면 |
| C1~C2 | ~500 | **높다** | 앱까지 걸린다 |
| C3~C5 | ~700 | **가장 높다** | 스키마 판 |

**A 는 하루, B 는 이삼일, C 는 그 이상이다.** A→B→C 순서면 **각 단계에서 멈춰도 화면이 쓸 만하다.**

## 8. 이식하면서 지킬 것 (형 문서 §3 을 잇는다)

**① 목업을 지우지 않는다.** 다만 **실물이 원천이 되고 목업이 그것을 부르게** 뒤집는다 —
지금 `JudgmentSeat` 이 그 모범이다(목업이 실물 부품을 부른다).

**② 한 단계에 한 커밋.** A1·A2·A3 도 각각이다.

**③ 단계마다 «실물 배선 검사»를 새로 만든다.** 목업 검사는 목업만 지킨다.

**④ 게이트는 전부 돌린다** — `tsc -b`(client) · `tsc --noEmit`(server) · `npx jest` ·
`pnpm test:web` · `pnpm lint:gate` · `pnpm audit:dead` · `pnpm audit:docs`.

**⑤ 화면을 바꾸면 화면으로 확인한다** — `pnpm lab`(P3 이후) 또는 CDP 실측.
숫자가 안 보이면 기사님과 내가 같은 것을 본 게 아니다.

**⑥ 이 문서를 갱신한다.** 단계가 끝나면 그 줄에 커밋 해시를 적는다.
