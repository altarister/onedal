## 읽는 법

**처분 칸은 기사님이 채운다.** 낱말은 다섯뿐이다 (계획서 §9 낱말 계약):

| 말 | 뜻 | 없어지는 것 |
|---|---|---|
| **가져온다** | 목업 것을 실물에 **새로 만든다** (실물 것은 그대로) | 없음 |
| **바꾼다** | 실물 것을 목업 것으로 **교체** (옛 것은 플래그 뒤로) | 화면에서만 |
| **더한다** | 실물 것 **옆·아래에 붙인다** | 없음 |
| **내린다** | 화면에서 **안 보이게** (코드는 남는다) | 화면에서만 |
| **지운다** | 코드에서 **없앤다** | 🔴 되돌리기는 커밋 revert 뿐 |

**위험 등급**: 🔴 높음(다른 것이 함께 무너진다) · 🟡 중간(검사·규칙과 부딪힌다) · 🟢 낮음

🔴 **먼저 알아야 할 것 — 목업이 둘이다.**
`SheetMockup.tsx`(시트 목업, 2478줄)는 **이미 2026-09-05~06 에 실물로 이식됐다.**
지금 실물 콜 타이틀이 곧 그것이다. 이번에 옮기는 것은 **`MapMockup.tsx`(지도 실험실, 4417줄)** 이다.
그래서 «목업 거로 바꾼다»는 **«시트 목업 → 지도 실험실»** 을 뜻한다 — 둘을 섞어 말하면 저번처럼 어긋난다.
