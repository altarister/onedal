## 2. 되돌리는 법 — **먼저 만든다**

되돌릴 자리가 없으면 배포하지 않는다.

### 코드
```bash
git tag live-2026-05-11 origin/main        # 지금 라이브에 이름을 준다
git push origin live-2026-05-11
```
롤백:
```bash
git push origin +live-2026-05-11:main      # 5월 코드로 되돌림 → 자동 재배포
```

🔴 **`main` 은 "지금 라이브에 있는 것"이다.** 작업은 브랜치에서 하고 배포할 때만 합친다.
`main` 에서 직접 작업하면 롤백이 한 줄로 끝나지 않는다.

### DB
배포 스크립트가 **코드 갱신 전에** 자동으로 뜬다 (§4-1). 손으로 하면 잊는다.

## 3. F 먼저 — 관제앱이 라이브를 보게 한다 (배포 전, 로컬)

관제앱(`client-app/android/`, `kr.co.onedal.dashboard`)은 `dist` 를 품고 돈다.
API 주소가 상대경로(`/api`)라 **그대로 빌드하면 웹뷰 자기 자신에게 요청한다.**

- [ ] **F-1** `VITE_API_URL=https://1dal.altari.com/api` 로 빌드
- [ ] **F-2** `npx cap sync android` → APK 빌드 → 설치
- [ ] **F-3** 앱에서 로그인 → **소켓이 붙는지** (Cloudflare WS 를 여기서 미리 본다 = D 도 같이 검증)
- [ ] **F-4** 위치 권한 허용 → 좌표가 서버로 나가는지
- [ ] **F-5** 화면 꺼짐 방지(`KeepAwake`)가 실제로 도는지

⚠️ 웹뷰 origin 이 `https://localhost` 라 라이브(HTTPS)와 **혼합 콘텐츠 문제가 없다.**
   반대로 `server.url` 로 라이브를 직접 띄우면 **GPS 가 막힌다** (http/https 아닌 원격 origin은
   보안 컨텍스트 판정이 달라진다). **dist 를 품는 지금 구조를 유지한다.**

> 예비책: 같은 주소를 **폰 크롬**으로 열면 그대로 관제웹이다 (라이브가 HTTPS 라 GPS 된다).
> 앱이 안 되면 즉시 갈아탄다. 단 화면이 꺼지면 추적이 멎으므로 **화면 자동 꺼짐을 "안 함"** 으로.

## 5-B. 라이브 수용 시험 — **집에서, 출발 전에** (약 30분)

> 배포가 "떴다"와 "된다"는 다르다. **차에 타기 전에 여기서 다 걸러 낸다.**
> 순서가 중요하다 — 아래로 갈수록 앞의 것에 기댄다. 막히면 **거기서 멈추고** 고친다.

| # | 확인할 것 | 통과 신호 | 막히면 |
|---|---|---|---|
| ① | 서버가 새 코드인가 | `/api/health` 가 **JSON**, `git.commit` 일치 | §4-4 로 |
| ② | 로그인 | 구글 로그인 → 대시보드 진입 | OAuth 도메인 설정 |
| ③ | **소켓** | 관제웹이 새로고침 없이 갱신 | `polling` 폴백 추가 (코드 수정 필요) |
| ④ | 설정 저장 | 저장 후 **새로고침해도 남아 있다** | DB 쓰기 문제 |
| ⑤ | 스캐너 도달 | 폰 카드에 A24, `수집` 이 올라감 | `isLiveMode`·5G |
| ⑥ | **판정(카카오)** | 콜 하나 잡아 색이 🔵🟢🟡 중 하나 | **전부 🔴 이면 키가 없다** |
| ⑦ | KEEP → 경로 | 지도에 경로가 그려짐 | 경로 연산 |
| ⑧ | **관제앱 GPS** | S23 에서 내 위치가 지도에 찍힘 | §3 으로 |
| ⑨ | 좌표 전송 | 관제웹 시각이 움직임 | 테더링·소켓 |

🔴 **⑥ 이 오늘 조용히 무너지기 쉬운 자리다.** 카카오 키가 라이브 `.env` 에 없으면
판정이 전부 🔴 로 뜨는데, 화면은 멀쩡히 도니 *"원래 그런가"* 로 넘어가기 쉽다.
**색이 하나라도 🔵🟢🟡 로 나오는 것을 눈으로 본다.**

### "관제앱이 새것인가"를 확인하는 법

스캐너 앱은 화면에 `📦 v…` 를 띄우지만 **관제앱에는 그런 표시가 없다** (`versionName 1.0` 고정).
대신 **어제 만든 기능이 보이는지**로 확인한다 — 폰 카드에 이게 있으면 새것이다:

```
1234  콜 리스트  합짐 탐색  20:39:13 (수집:16 수락:3 취소:1 · 훑음 6→0 도착지4)
```

`· 훑음 …` 조각과 **앞의 시각**은 2026-08-23 에 생겼다. 5월 빌드에는 없다.

주행 중에 판단하면 늦는다. **시각으로 못박아 둔다.**

| 시각 | 상태 | 결정 |

### 🔴 7-0. 먼저 알아야 할 것 — **주행 중에는 새 콜이 안 온다**

시뮬레이터(`onedal-sim`)는 **라이브에 없다** — `onedal-web` 워크스페이스에도, 배포
스크립트에도 들어 있지 않다. 기사님 맥에서만 돈다. A24 가 5G 로 나가면 집 랜에 못 닿고,
관제웹에는 **직접 콜 입력 UI 가 없다.**

**콜이 없으면 경로가 없고, 경로가 없으면 도착 감지·경유·진행도를 시험할 수 없다.**

→ **출발 전에 집에서 경로를 만들어 두고 나간다.**

- [ ] 맥에서 시뮬레이터 기동, 기사님 위치를 **초월**로
- [ ] 목적지 지역을 **구로**로 두고 콜을 흘려 A24 가 잡게 한다
- [ ] 관제웹에서 **KEEP** → 경로가 생긴다
- [ ] 지도에 경로가 그려진 것을 **눈으로 확인하고** 출발

> 주행 중 A24 는 콜을 못 잡지만 **하트비트는 계속 간다** — 그것만으로도
> *"스캐너가 5G 로 라이브에 붙어 있다"* 가 시험된다. 그게 A24 의 오늘 몫이다.

### 7-1. 출발 전 (집 앞, 시동 걸기 전)

- [ ] 🔴 **관제앱 지도에 내 위치가 찍히는가** — 안 찍히면 **출발하지 않는다**
- [ ] 좌표 옆 시각이 **움직이는가** (멈춰 있으면 테더링이 끊긴 것)
- [ ] 경로가 지도에 그려져 있는가
- [ ] A24 카드가 초록이고 시각이 움직이는가

### 7-2. 주행 중 (약 1시간)

- [ ] 좌표가 따라오는가 (지도에서 내 점이 움직인다)
- [ ] **지나온 구간이 지워지는가**
- [ ] 남은 거리·예상 도착이 줄어드는가
- [ ] 신호 약한 구간(터널 등)을 지난 뒤 **스스로 복구되는가** ← 소켓 재연결
- [ ] 화면이 꺼지지 않는가

### 7-3. 도착 (구로 고려대병원)

- [ ] 🔴 **도착 감지가 뜨는가** — 오늘의 가장 큰 관문
- [ ] 하차 처리 → 콜이 종료로 넘어가는가
- [ ] 집에 와서 `pnpm ledger` 로 **장부 대조** — 화면은 메모리, 장부는 빈 사고가 네 번 있었다

### 7-4. 무엇이 잘못됐는지 아는 법 (주행 중)

| 증상 | 어디가 문제 |
|---|---|
| 지도 점이 안 움직임 · **시각은 움직임** | GPS 가 안 잡힌다 (권한·실내·정확한 위치 꺼짐) |
| 지도 점도 시각도 **둘 다 멈춤** | **테더링이 끊겼다** (아이폰 확인) |
| 좌표는 가는데 **경로가 안 줄어듦** | 서버 연산 문제 — 돌아와서 로그를 본다 |
| A24 카드가 회색 | 스캐너 쪽 데이터·접근성 (오늘 시험의 본류는 아니다) |

⚠️ **주행 중에 고치려 하지 않는다.** 증상만 기억(가능하면 화면 캡처)하고 §9 에 적는다.

## 8. 남은 위험 — 알고도 안 막는 것

**막을 수 있는데 안 막는 것이 아니라, 오늘 범위 밖이라 안고 가는 것**이다. 나중에 놀라지 않으려고 적는다.

- **소켓 폴백이 없다** (`transports: ["websocket"]`). 5-B ③ 이 통과하면 오늘은 넘어가되,
  통과 못 하면 코드를 고쳐야 배포가 의미 있다
- **아이폰 테더링은 단일 실패점이다.** 끊기면 관제앱이 서버와 끊긴다 (GPS 는 계속 잡힌다)
- **관제앱에 버전 표시가 없다** (`versionName 1.0` 고정). *"무엇이 도는가"* 를
  기능 유무로 판단해야 한다 (5-B 참조). 다음 판에 버전 표시를 넣는 것이 맞다
- **주행 중 새 콜을 못 잡는다** (§7-0). 시뮬레이터를 라이브에 올리거나 관제웹에
  직접 콜 입력을 만들기 전까지는 계속 그렇다
- **증거 사진 없음** (§0). 카메라 플러그인부터 없다
