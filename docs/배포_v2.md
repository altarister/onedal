이 시스템은 지금까지 **책상 위에서만** 돌았다. 집 랜, 고정된 맥, 앉아 있는 기사님.
오늘 처음으로 **움직이면서 · 끊기면서 · 실제 좌표로** 돈다.

| # | 얻는 것 | 왜 오늘이어야 하나 |
|---|---|---|
| ① | **인터넷 너머로 사슬이 이어지는가** | 세 조각이 각자 다른 망에 있다 — 집 랜에서는 이 조건이 안 만들어진다 |
| ② | **움직이는 좌표**로 경로·진행도·도착 감지가 도는가 | 시뮬 좌표는 매끄럽다. 실제 GPS 는 튀고 끊기고 늦는다 |
| ③ | **음영 구간에서 스스로 복구되는가** | 터널·지하차도. 만들어 낼 수 없는 조건이다 |

| ⑥ | 라이브 DB 를 새로 만들었을 때 **국면 5탭이 시드되는가** | 로컬 DB 는 이미 채워져 있어 안 드러난다 |
| ⑦ | 관제앱이 **웹뷰에서 GPS 를 읽는가** | 앞으로 사진·하드웨어의 **전제**가 되는 사실 |
| ⑧ | `훑음 N→N` 이 **실전에서 읽히는가** | 어제 만든 것의 첫 실사용. 축이 주행에 따라 옮겨 가는지 |

> 한 번에 본다. 굳이 따로 나가지 않아도 된다.

### 못 얻는 것 — **한계를 알고 들어간다**

| 한계 | 왜 |
|---|---|
| **진짜 배차망의 화면** | 시뮬레이터다. 실제 인성콜의 글자 배치·팝업·지연은 시험되지 않는다 |

| **수익성 판정의 정확도** | 요율·거리는 시뮬 값이다. 색이 **나오는지**만 보지, **맞는지**는 못 본다 |
| **하루 7콜 운행 모델** | 한 구간 1회다. 합짐이 쌓이고 적재가 차는 흐름은 안 나온다 |
| **앱 내부 로그** | logcat 뿐이라 주행 뒤 사라진다 (§9-1) |
| **사진·하드웨어** | 기능 자체가 없다 (§0) |
| **장시간 안정성** | 1시간이다. 하루 종일 돌 때의 메모리·타이머 누수는 안 드러난다 |
| **문제지의 상차지가 안 따라온다** | 시뮬 위치는 GPS 를 안 본다 (§7-0-1). 실제 배차망과 다른 점이다 |

🔴 **가장 큰 한계: 이건 "제품이 되는가"가 아니라 "선이 이어지는가"의 시험이다.**
성공해도 *"실전에서 돈을 번다"* 는 뜻이 아니고, 실패해도 *"제품이 틀렸다"* 는 뜻이 아니다.

## 2. 되돌리는 법 — **먼저 만든다**

되돌릴 자리가 없으면 배포하지 않는다.

### 코드
```bash
git tag live-2026-05-11 origin/main        # 지금 라이브에 이름을 준다
git push origin live-2026-05-11
```
롤백:
```bash
git push origin +live-2026-05-11:main      # 5월 코드로 되돌림 → 자동 재배포
```

🔴 **`main` 은 "지금 라이브에 있는 것"이다.** 작업은 브랜치에서 하고 배포할 때만 합친다.
`main` 에서 직접 작업하면 롤백이 한 줄로 끝나지 않는다.

### DB
배포 스크립트가 **코드 갱신 전에** 자동으로 뜬다 (§4-1). 손으로 하면 잊는다. 최근 5개 보관.

되돌리기 (EC2 에서):
```bash
cd ~/onedal/onedal/onedal-web/server
ls -la data.db.backup-*                      # 어느 것으로 돌아갈지 눈으로 고른다
pm2 stop all                                 # 쓰는 중에 바꾸면 깨진다
cp -a data.db.backup-<고른것> data.db
pm2 start all
```

🔴 **코드와 DB 는 짝이다.** 5월 코드로 되돌렸으면 **5월 DB(백업)** 로 같이 돌아가야 한다.
8월 스키마의 DB 를 5월 코드에 물리면 조용히 어긋난다.

### 3-B-0. ~~더 싼 길 — 터널~~ ❌ **안 쓰기로 함** (기사님 결정 2026-08-23: *"1 서브 도메인"*)

> **아래는 검토만 하고 안 간 길이다.** 지우지 않고 남기는 이유는, 서브도메인이 막혔을 때
> **되돌아올 자리**이기 때문이다 (DNS 가 안 풀리거나 EC2 빌드가 실패했을 때).
> 남은 일은 `?loop=1` + 문제지뿐인데 **둘 다 이미 만들어 뒀으므로**, 이 길로 갈아타는 데
> 드는 것은 `cloudflared` 한 줄과 폰에 주소를 다시 넣는 것뿐이다.

```bash
cd onedal-sim && pnpm dev                       # 맥에서 평소처럼
cloudflared tunnel --url http://localhost:5173  # 다른 창
→ https://<임의이름>.trycloudflare.com          # 즉시 HTTPS · 계정 불필요
```

| | 서브도메인 배포 (3-B-1) | **터널** |
|---|---|---|
| DNS | A 레코드 | **불필요** |
| Express Host 분기 | 필요 | **불필요** |
| `deploy.yml` 빌드·경로 필터 | 필요 | **불필요** |
| 남는 일 | — | **`?loop=1` + 구로 문제지뿐** |
| 대가 | 없음 | **맥이 집에서 깨어 있어야 한다** (절전·화면보호기 끔) |
| 주소 | 고정 | 실행할 때마다 바뀐다 (폰에 직접 입력) |

🔴 **터널의 대가: 맥이 자면 배차망이 통째로 죽는다.** 쓰게 되면 절전을 끄고
`caffeinate -dimsu` 를 걸어 둔다. 주소는 실행할 때마다 바뀌므로 폰에 다시 넣어야 한다.

**서브도메인으로 정한 이유**: 문제지는 오늘 하루 쓰고 버릴 것이 아니다. 앞으로 재현 시험을
할 때마다 필요하고, 그때마다 맥을 켜 두고 주소를 새로 받는 것은 매번 드는 비용이다.

### 3-B-1-a. 🔴 Cloudflare 에서 무엇을 누르나 (기사님)

기사님: *"이거 어떻게 하는 거야? 알려 주면 할게."*

1. `dash.cloudflare.com` 로그인 → **`altari.com`** 도메인 선택
2. 왼쪽 메뉴 **DNS → Records** → **`Add record`**
3. 이렇게 채운다:

| 칸 | 넣을 값 |
|---|---|
| **Type** | `A` |
| **Name** | `rehearsal` ← 이것만. `rehearsal.altari.com` 이라고 다 쓰지 않는다 |
| **IPv4 address** | **`1dal` 레코드에 적힌 것과 똑같은 IP** (같은 목록에 있다. 복사해서 붙인다) |
| **Proxy status** | **주황 구름 켬** (Proxied) ← 꺼져 있으면 HTTPS 가 안 붙는다 |
| **TTL** | Auto |

4. **Save** → 보통 1~5분이면 풀린다

확인 (맥에서):
```bash
curl -s -o /dev/null -w "%{http_code}\n" https://rehearsal.altari.com/
```
`200` 이면 됐다. `52x`·`53x` 면 아직 EC2 에 시뮬 빌드가 안 올라간 것이고(배포 전이라 정상),
연결 자체가 안 되면 DNS 가 아직 안 풀린 것이다.

⚠️ **`1dal` 과 같은 IP 여야 한다.** 다른 서버를 가리키면 그쪽엔 시뮬레이터가 없다.
⚠️ 주황 구름을 **끄면**(DNS only) 인증서가 없어 `https://` 가 실패한다 — GPS 와 무관하지만
   폰에서 경고가 뜨고 접속이 막힌다.

### 3-B-1. 주소를 어떻게 붙이나 (오래 쓸 길) ✅ **이 길로 정함**

> ❓ *"`1dal.altari.com/rehearsal/inseong` 뭐 이렇게 한다는 거 아니었어? 내가 잘못 보았나?"*
> — 잘못 보신 게 아니다. **경로 방식도 후보였고**, 아래 표의 오른쪽 칸이 그것이다.
> 기사님이 *"1 서브 도메인"* 을 고르셔서 **왼쪽으로 갔다.** 경로 방식은
> `vite base` 와 `BrowserRouter basename` 을 손봐야 하는데, 그러면 **로컬(5173)과 배포본이
> 갈라져** 문제지가 한쪽에서만 맞는 일이 생긴다. 서브도메인은 시뮬레이터를 **루트로**
> 서빙하므로 그 코드를 하나도 안 건드린다 — 그래서 오늘 코드가 빨리 끝났다.

**추천: 서브도메인** (`rehearsal.altari.com` → 같은 EC2, Express 가 Host 로 분기)

| | 서브도메인 (추천) | 경로 (`1dal.altari.com/rehearsal/`) |
|---|---|---|
| DNS | Cloudflare 에 A 레코드 하나 (기사님 5분) | **불필요** |
| 인증서 | Universal SSL 이 1단계 서브도메인을 덮는다 | 그대로 |
| **`onedal-sim` 코드** | **안 건드림** (루트로 서빙) | `vite base` + `BrowserRouter basename` 손봐야 함 |
| 로컬(5173)과 차이 | 없음 | 생긴다 (배포본만 base 가 붙는다) |

시뮬레이터 코드를 안 건드리는 쪽이 낫다 — **로컬과 배포본이 갈라지면 문제지가 로컬에서만
맞는 일이 생긴다.** DNS 가 안 풀리면 경로 방식으로 되돌린다.

- [ ] **기사님**: Cloudflare 에서 `rehearsal` A 레코드 → 1dal 과 같은 EC2 IP (프록시 켬)
- [ ] Express 에 Host 분기 + `onedal-sim/dist` 정적 서빙
- [ ] `deploy.yml`: `onedal-sim` 빌드 단계 추가 + **경로 필터에 `onedal-sim/**` 추가**
      (지금은 `onedal-web/**` 만 배포를 깨운다 — 안 넣으면 시뮬만 고쳐도 안 올라간다)

### 3-B-2. 🔴 문제지는 **다 내면 멈춘다**

```ts
// 문제지를 다 냈으면 null(더 안 낸다) — 랜덤으로 되돌아가면 채점이 흐려진다.
```

**채점에는 맞지만 주행에는 안 맞는다.** 16문제 × 45초면 **12분**이고, 나머지 50분은
조용하다. 주행은 1시간이다.

- [ ] `?loop=1` 옵션 추가 — 있으면 문제지를 **처음부터 되돌려 흘린다**.
      **없으면 지금과 똑같다** (채점 모드는 안 건드린다)

### 3-B-3. 구로 문제지 (`?preset=구로&loop=1`)

주행 시험용이라 `expect`(채점 정답)는 비운다 — 그날 필터 상태에 달렸기 때문이다
(`presets.ts` 가 이미 그렇게 구분해 둔다).

**✅ 작성 완료 — 10건** (`presets.ts` 의 `'구로'`)

| # | 콜 | 무엇을 본다 |
|---|---|---|
| ① | 초월 → **구로** · 9.5만 | **오늘의 주인공.** 이게 잡혀야 §7-3 도착 감지로 간다 |
| ② | 초월 → 금천 · 8.8만 | 합짐 후보 (구로 바로 옆) |
| ③ | 초월 → 영등포 · 9.9만 | ②보다 우회가 크다 — 순위가 뒤인지 |
| ④ | 초월 → **파주** · 12만 | **떨어져야 정상.** 요금은 제일 높은 미끼 — `도착지 N` 이 세어지나 |
| ⑤ | 초월 → 분당 · 6.2만 | 길목 콜 — 경유 반경 안에 드나 |
| ⑥ | 초월 → 구로 · **2.2만** | 방향은 맞는데 단가가 안 나온다 — `요금 N` |
| ⑦ | 초월 → 영등포 · **5t** | 차종이 안 맞는다 — `차종 N` |
| ⑧ | 초월 → 광명 · 7.8만 | 한 바퀴의 마지막, 평범한 콜 |
| ⑨ | **구로 → 초월** · 9.2만 | 🏠 **복귀 첫짐** (기사님 지적 2026-08-23) |
| ⑩ | 영등포 → 경안동 · 8.5만 | 🏠 복귀 합짐 — ⑨에 붙는가 |

🔴 **⑨⑩ 은 갈 때 저절로 걸러진다.** 상차지가 구로 쪽이라 초월에 있을 땐 멀어서 떨어지고,
구로에 닿으면 가까워져 통과한다. 서버 필터는 **실제 GPS** 를 보므로 **가만히 둬도 국면이
저절로 넘어간다.** 갈 때 이 둘이 `상차지 N` 으로 세어지는 것이 **정상**이다.

⚠️ 문제지의 상차지는 **고정 좌표**다 (§7-0-1). 주행하면 뒤로 멀어지므로 `오늘만` 으로
상차지 반경을 넉넉히 여는 것이 여전히 필요하다.

## 5-B. 라이브 수용 시험 — **집에서, 출발 전에** (약 30분)

> 배포가 "떴다"와 "된다"는 다르다. **차에 타기 전에 여기서 다 걸러 낸다.**
> 순서가 중요하다 — 아래로 갈수록 앞의 것에 기댄다. 막히면 **거기서 멈추고** 고친다.

|---|---|---|---|

| ⑤ | 스캐너 도달 | 폰 카드에 A24, `수집` 이 올라감 | `isLiveMode`·5G |

### ⑥ 카카오 키는 **부팅 로그로 먼저 안다**

콜을 잡아 보기 전에, 서버 기동 로그에 이 줄이 있으면 키가 없는 것이다:

```
⚠️ [환경변수] KAKAO_REST_API_KEY 미설정 — 관련 기능이 동작하지 않습니다.
```

`validateEnv()` 가 부팅 때 찍는다. **이걸 먼저 보면 콜을 잡아 볼 필요도 없다.**

🔴 **⑥ 이 오늘 조용히 무너지기 쉬운 자리다.** 카카오 키가 라이브 `.env` 에 없으면
판정이 전부 🔴 로 뜨는데, 화면은 멀쩡히 도니 *"원래 그런가"* 로 넘어가기 쉽다.
**색이 하나라도 🔵🟢🟡 로 나오는 것을 눈으로 본다.**

### "관제앱이 새것인가"를 확인하는 법

스캐너 앱은 화면에 `📦 v…` 를 띄우지만 **관제앱에는 그런 표시가 없다** (`versionName 1.0` 고정).
대신 **어제 만든 기능이 보이는지**로 확인한다 — 폰 카드에 이게 있으면 새것이다:

```
1234  콜 리스트  합짐 탐색  20:39:13 (수집:16 수락:3 취소:1 · 훑음 6→0 도착지4)
```

`· 훑음 …` 조각과 **앞의 시각**은 2026-08-23 에 생겼다. 5월 빌드에는 없다.

| 하는 일 | GPS 를 읽어 서버로 보낸다 · 기사님이 본다 | **배차망 화면을 띄우고** + **그 화면을 읽어 콜을 잡는다** (두 몫) |
| 전원 스위치 | 앱 아이콘 | **접근성 토글** ([TRD §0](../onedal-app/docs/TRD.md)) |
| 같이 도는 것 | — | 시뮬레이터 앱 (`https://map.altari.com/inseong`) |

🔴 **두 폰은 서로 다른 망을 탄다.** 그래서 **라이브가 필요한 것이다** — 예전처럼 집 랜의
`172.30.x.x` 를 보게 하면 둘이 만나지 못한다. 배포 뒤에는 **둘 다 인터넷으로** 같은
`https://1dal.altari.com` 을 본다.

### 6-1. S23 (관제앱) 준비

- [ ] 아이폰 **개인용 핫스팟** 켜고 S23 연결 — 데이터가 실제로 되는지 브라우저로 확인
- [ ] 관제앱 APK 설치 (§3)
- [ ] 로그인 (구글)
- [ ] **위치 권한 → "앱 사용 중 허용" + "정확한 위치" 켬**
- [ ] **배터리 최적화 제외** (설정 → 앱 → 1DAL → 배터리 → 제한 없음)
- [ ] **화면 자동 꺼짐 "안 함"** — 브라우저 폴백을 쓸 때 특히 중요
- [ ] **충전 케이블 연결** (GPS + 화면 상시 켬 = 1시간이면 배터리가 훅 준다)
- [ ] 거치대 고정

⚠️ **유심이 없어도 GPS 는 잡힌다** — GPS 는 수신기다. 다만 **첫 위치 획득**은 테더링
데이터가 있어야 빠르다. 출발 전 실내가 아니라 **밖에서** 한 번 잡아 두는 것이 좋다.

⚠️ **아이폰 핫스팟이 끊기면** 좌표는 계속 잡히지만 **서버로 못 간다.** 화면의 시각이
멈추는 것으로 알 수 있다 (§6-4). 아이폰도 충전에 꽂아 둔다.

### 6-2. A24 (스캐너) 준비

- [ ] **접근성 → 원달 토글이 켜져 있는지** (앱 아이콘이 아니라 이게 전원이다)
- [ ] 앱에서 **`isLiveMode` 켬** — 이걸 켜야 `https://1dal.altari.com` 을 본다
      (끄면 다시 로컬 `172.30.x.x` 로 돌아온다. 되돌릴 수 있다)
- [ ] **시뮬레이터 앱 주소를 `rehearsal` 로** — 볼륨 위 → 주소 직접 입력
      `https://rehearsal.altari.com/inseong/dispatch?preset=구로&loop=1`
- [ ] 시뮬레이터 설정: **기사 위치 = 초월**, 목적지 방향 = 서울/구로
- [ ] 🔴 **구로행 콜(문제지 ①)이 실제로 화면에 뜨는지 출발 전에 눈으로 확인**
- [ ] 배터리 최적화 제외 (**원달앱·시뮬레이터 앱 둘 다**)
- [ ] **화면 켜 둠** — 꺼지면 배차망을 못 읽는다 (관제앱에 `💤 화면 꺼짐` 으로 뜬다)
- [ ] **충전 케이블** — 화면 상시 켬 + 5G + 스크래핑이면 배터리가 빨리 준다
- [ ] 관제앱 폰 카드에 A24 가 **초록으로** 뜨고 시각이 움직이는지

⚠️ **시뮬레이터 앱이 화면 맨 앞에 있어야 한다.** 다른 앱으로 덮으면 원달앱이 읽을 화면이
없어지고, 관제앱에 `알 수 없는 화면` 으로 뜬다.

## 7. 저녁 실주행 (초월 → 구로 고려대병원)

### 7-0. 콜은 **주행 중에도 온다** — 배차망도 라이브다

기사님 확인 2026-08-23: *"`https://map.altari.com/` 에 라이브 되어 있는 시뮬레이터가
붙어 있어. **가는 중에 콜을 잡아야** 작동하는 것을 우리가 로그에 남겨 둘 수 있어."*

```
A24 화면    시뮬레이터 앱  →  https://rehearsal.altari.com/inseong/dispatch?preset=구로&loop=1
A24 접근성  원달앱이 그 화면을 읽고 자동 터치
            → https://1dal.altari.com 로 보고  →  S23 관제앱에 뜬다
```

> 🔴 **주소는 `rehearsal` 이다** (§3-B). 기본값인 배포본(`map.altari.com`)은 **랜덤**이라
> 구로행 콜이 안 나올 수 있다. 시뮬레이터 앱 **볼륨 위 → 주소 직접 입력**으로 바꾼다.
> rehearsal 이 제때 안 서면 배포본으로 폴백하되, **그때는 구로행이 안 나올 수 있음을 안고 간다.**

**A24 한 대가 두 몫을 한다** — 화면에는 시뮬레이터가 떠 있고, 접근성 서비스가 그걸 읽는다.
셋 다 인터넷을 타므로 집 랜이 필요 없다. **오늘 시험의 사슬이 끊기는 데가 없다.**

> 시뮬레이터 앱은 **볼륨 위 버튼**으로 주소를 바꾼다. 기본값이 배포본이라 **그대로 두면 된다.**
> ⚠️ **문제지(16콜 `?preset=오탐`)는 배포본에 없다** — 그건 레포의 `onedal-sim` 에만 있다.
> 오늘은 **랜덤 콜**이 흐른다. 시험 목적(실제 주행 중 왕복)에는 그게 맞다.

### 🔴 7-0-1. 조정 하나 — 시뮬레이터의 "기사 위치"는 **GPS 를 안 본다**

시뮬레이터는 콜을 **설정 화면에서 고른 위치** 기준으로 만든다 (`InseongSetupPage` 의
`📍 기사 현재 위치`). 실제 GPS 를 따라오지 않는다.

그래서 초월로 두고 출발하면, **구로에 가까워질수록 상차지가 뒤에 남아** 콜이 상차지
거리에서 떨어지기 시작한다. 관제앱에 이렇게 뜬다:

```
· 훑음 8→0 상차지 8      ← 콜이 끊긴 게 아니라 "너무 멀어서" 떨어진 것이다
```

**이것 자체가 정상 동작이고 좋은 로그다.** 다만 *"가는 중에 콜을 잡는 것"* 이 목적이므로
출발 전에 한쪽을 넉넉히 열어 둔다.

- [ ] 출발 전 **`오늘만`** 으로 **상차지 반경을 넉넉히** (40km 안팎) — 초월 기준 콜이
      주행 내내 통과한다. `오늘만` 이라 자정에 저절로 돌아온다
- [ ] 시뮬레이터 설정에서 **기사 위치 = 초월**, **목적지 방향 = 서울/구로**

### 🔴 7-0-2. 주행 중 결재는 **하지 않는다**

콜이 잡히면 관제앱에 **안전취소 30초** 안에 결재가 뜬다. **운전 중에는 누르지 않는다.**
안 누르면 안전취소로 정리되고, **그 과정도 그대로 로그에 남는다** — 오늘 필요한 것은
*"콜이 잡히고 판정까지 왕복했다"* 이지 KEEP 자체가 아니다.

- 누르실 거면 **신호 대기 중에만**
- 시뮬레이터라 취소가 실제 배차망 취소 횟수에 들어가지 않는다

### 7-0-3. 그래도 경로 하나는 만들어 두고 나간다

**도착 감지**를 시험하려면 목적지가 구로인 콜이 하나 살아 있어야 한다.

- [ ] 출발 전 집에서 **구로 방면 콜 하나를 KEEP** → 지도에 경로가 그려진 것을 눈으로 확인
- [ ] 그 상태로 출발한다 (주행 중 잡히는 콜은 그 위에 얹히거나 안전취소된다)

### 🔴 7-0-4. **동네 한 바퀴 먼저** (10분)

본 주행을 나가기 전에 **집 근처를 10분만 돌아 본다.**

- [ ] 좌표가 따라오는가
- [ ] 콜이 잡히는가
- [ ] 관제앱이 안 죽는가

여기서 끊기면 **집에서 고치면 된다.** 구로까지 가서 알면 그날 저녁이 통째로 날아간다.
**10분으로 한 시간을 산다.**

### 7-1. 출발 전 (집 앞, 시동 걸기 전)

- [ ] 🔴 **관제앱 지도에 내 위치가 찍히는가** — 안 찍히면 **출발하지 않는다**
- [ ] 좌표 옆 시각이 **움직이는가** (멈춰 있으면 테더링이 끊긴 것)
- [ ] 경로가 지도에 그려져 있는가
- [ ] A24 카드가 초록이고 시각이 움직이는가

### 🔴 7-2-0. 운전 중에는 **화면을 보지 않는다**

앞 절에 *"주행 중 확인할 것"* 을 표로 적어 뒀지만, **그걸 달리면서 보라는 뜻이 아니다.**

**로그가 대신 본다.** 서버 로그·장부·`FilterTally` 가 전부 남으므로, 기사님이 실시간으로
관찰하지 않아도 **분석에 필요한 것은 하나도 잃지 않는다** (§9).

- 관찰은 **정차했을 때만** — 신호 대기, 휴게소
- 중간 점검은 **딱 한 번**이면 충분하다 (휴게소 등)
- 이상하면 **그 자리에서 화면 캡처만** 하고 넘어간다. 원인은 집에서 본다
- 🔴 **주행 중에 고치려 하지 않는다.** 오늘 얻으려는 것은 로그이지 즉석 수리가 아니다

### 7-2. 정차했을 때 · 돌아와서 확인할 것 (약 1시간 주행)

- [ ] 좌표가 따라오는가 (지도에서 내 점이 움직인다)
- [ ] **지나온 구간이 지워지는가**
- [ ] 남은 거리·예상 도착이 줄어드는가
- [ ] 신호 약한 구간(터널 등)을 지난 뒤 **스스로 복구되는가** ← 소켓 재연결
- [ ] 두 폰 다 화면이 꺼지지 않는가
- [ ] 🔴 **콜이 계속 잡히는가** — 관제앱에 새 카드가 뜨고 색(🔵🟢🟡)이 붙는가.
      **이게 오늘 로그에 남기려는 것**이다
- [ ] 폰 카드의 `· 훑음 N→N` 이 **스캔마다 바뀌는가** (어제 만든 것의 실전 첫 확인)

### 7-3. 도착 (구로 고려대병원)

- [ ] 🔴 **도착 감지가 뜨는가** — 오늘의 가장 큰 관문
- [ ] 하차 처리 → 콜이 종료로 넘어가는가
- [ ] 집에 와서 `pnpm ledger` 로 **장부 대조** — 화면은 메모리, 장부는 빈 사고가 네 번 있었다

### 7-4. 무엇이 잘못됐는지 아는 법 (주행 중)

| 증상 | 어디가 문제 |
|---|---|
| 지도 점이 안 움직임 · **시각은 움직임** | GPS 가 안 잡힌다 (권한·실내·정확한 위치 꺼짐) |
| 지도 점도 시각도 **둘 다 멈춤** | **테더링이 끊겼다** (아이폰 확인) |
| 좌표는 가는데 **경로가 안 줄어듦** | 서버 연산 문제 — 돌아와서 로그를 본다 |
| A24 카드가 회색 | A24 데이터(5G)·접근성 토글 |
| A24 가 `알 수 없는 화면` | **시뮬레이터 앱이 앞에 없다** (다른 앱이 덮었거나 화면 꺼짐) |
| **콜이 안 잡힘** · `훑음 N→0 상차지 N` | 정상이다 — 초월이 뒤로 멀어졌다 (§7-0-1). 반경을 더 열었어야 하는 것 |
| **콜이 안 잡힘** · `훑음 0` 또는 줄 없음 | 시뮬레이터가 콜을 안 흘리고 있다 (앱을 다시 앞으로) |

⚠️ **주행 중에 고치려 하지 않는다.** 증상만 기억(가능하면 화면 캡처)하고 §9 에 적는다.

## 8. 남은 위험 — 알고도 안 막는 것

**막을 수 있는데 안 막는 것이 아니라, 오늘 범위 밖이라 안고 가는 것**이다. 나중에 놀라지 않으려고 적는다.

- **소켓 폴백이 없다** (`transports: ["websocket"]`). 5-B ③ 이 통과하면 오늘은 넘어가되,
  통과 못 하면 코드를 고쳐야 배포가 의미 있다
- **아이폰 테더링은 단일 실패점이다.** 끊기면 관제앱이 서버와 끊긴다 (GPS 는 계속 잡힌다)
- **관제앱에 버전 표시가 없다** (`versionName 1.0` 고정). *"무엇이 도는가"* 를
  기능 유무로 판단해야 한다 (5-B 참조). 다음 판에 버전 표시를 넣는 것이 맞다
- **시뮬레이터의 기사 위치가 GPS 를 안 본다** (§7-0-1). 주행하면 상차지가 뒤로 남는다.
  오늘은 반경으로 덮지만, 제대로 하려면 시뮬레이터가 실제 좌표를 따라가야 한다
- **배포본에는 문제지가 없다.** 재현 시험(16콜)은 여전히 집 랜에서만 된다
- **증거 사진 없음** (§0). 카메라 플러그인부터 없다

### 9-1. 무엇이 남고 무엇이 사라지나

| 로그 | 어디에 | 주행 뒤에 남나 |
|---|---|---|
| **서버 로그** | EC2 `~/onedal/onedal/onedal-web/server/logs/server-YYYY-MM-DD.log` | ✅ **주력.** 단 **3일치만** 남고 부팅 때 정리된다 |
| **장부(DB)** | EC2 `data.db` → `pnpm ledger` | ✅ 콜별 단계·신고·약속 |
| **FilterTally** | 서버 로그·기기 세션 | ✅ **앱의 판단이 요약되어 올라온다** |
| A24 앱 로그 | `Log.d` → **logcat 뿐** | ❌ **사라진다.** 파일에도 안 쌓고 서버로도 안 보낸다 |
| 관제앱 콘솔 | 웹뷰 | ❌ (원격 디버깅을 붙여야 보인다) |

🔴 **앱 내부 로그는 못 건진다.** 케이블로 노트북에 매달고 달릴 수는 없다.

✅ **그래서 어제 만든 `FilterTally` 가 여기서 값을 한다.** *"왜 안 잡았나"* 의 답이
축별 숫자로 **서버까지 올라와 남는다.** 이게 없었으면 오늘 주행은 *"안 잡히더라"* 로
끝났을 것이다.

- [ ] 그래도 **화면 캡처**를 남긴다 — 이상한 장면은 그 자리에서 찍는다 (§7-4)

돌아와서 뒤지지 않는다. 아래 질문의 답을 찾는다.

### 배포 중 걸린 것 둘 — 다음을 위해 적는다

**① 🔴 자동 백업이 `data.db` 한 파일만 떴다.**
SQLite 는 **WAL 모드**라 최근 데이터가 `data.db-wal` 에 있다. 그날 WAL 이 **4.1MB** 였는데
백업(172KB)에는 안 들어갔다 — **그대로 롤백했으면 6월 이후가 통째로 빠졌다.**
지우기 전에 손으로 세 파일을 다 떠서 오늘은 무사했다 (`*.SAFE-20260823-042725`).
→ `deploy.yml` 을 **세 파일 다 뜨도록** 고쳤다. 되돌릴 때도 **셋을 같이** 복원한다.

**② `pm2 stop all` 이 조용히 실패했다.**
비대화형 SSH 는 `~/.bashrc` 를 안 읽어 **`nvm` 이 안 실리고 `pm2` 가 없다.** 그런데
`2>/dev/null` 로 stderr 를 버려서 **성공한 줄 알았다.** 파일 상태를 보고서야 알았다.
→ EC2 에서 pm2 를 쓸 때는 **먼저 nvm 을 싣는다.** 배포 스크립트는 이미 그렇게 하고 있다.
```bash
export NVM_DIR="$HOME/.nvm"; [ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh"
```
→ 그리고 **stderr 를 버리지 않는다.** 이 레포가 반복해 당한 *조용한 실패*의 한 형태다.

**③ 지워진 계정의 토큰을 서버가 곱게 못 받는다.**
DB 를 새로 만들면 앱이 든 JWT 의 `user_id` 가 없어져 `getUserSession` 이 FK 위반으로
**예외를 던진다.** *"재로그인이 필요합니다"* 로 끊어야 맞다 → [todo.md](../todo.md) 로.
