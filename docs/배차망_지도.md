* **[기획/공통코드_배차망_분기_정리.md](기획/공통코드_배차망_분기_정리.md)**: 배차망 이름을 직접 묻는 하드코딩 분기를 제거하고, `IDispatchAppPlugin` 플러그인 레지스트리로 일원화한 아키텍처 (앱 코어 리팩터링 완료).
