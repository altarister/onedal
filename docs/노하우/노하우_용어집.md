# 노하우 용어집 — 자막 파일별 원본 추출

> 📌 **이 문서는 "합치기 전" 상태다.** 기사님 지시(2026-08-20):
> *"문서마다 하나씩 사용하고 있는 용어들을 추출하고 어떤 의미로 쓰이고 있는지 정의해서…
> 분류는 자막 파일별로 해주고 **중복을 허용**할게. 나중에 내가 읽어 보고 하나로 합칠 거야."*
>
> 그래서 같은 말이 여러 절에 다시 나온다. **뜻이 조금씩 다르게 쓰인 것도 그대로 뒀다** —
> 어느 쪽으로 합칠지는 기사님이 정하신다.
>
> `1DAL →` 는 우리 [용어집](../용어집.md)·코드의 대응어다. 없으면 **우리에게 없는 개념**이다.
> 자막은 자동 생성이라 오탈자가 많다. 명백한 것은 바로잡아 적었다(`저교란`→`적요란` 등).

|---|---|

| **묶다** | 여러 콜을 한 번에 실어 가도록 합치는 것. `1DAL →` **합짐** |
| **뿌리다** | 하차하다. *"수원 들렀다가 평택 가서 다 **떨으면**"* |
| **파도** | 콜이 특정 지역·시간대로 몰려 뜨는 흐름. *"물건 나오는 대로 가야 하는, 파도를 맞서 항해하는 항해사"* · *"인천 쪽으로 오는 파도가 치길래"*. `1DAL →` **없음** |
| **급송** | 즉시 출발해야 하는 콜. 일반 콜보다 시한이 짧다 |
| **예약 픽업** | `2시 픽업` 처럼 시각이 지정된 콜. 그 시각까지 다른 일을 할 수 있다 |
| **시급** | 하루 매출 ÷ 일한 시간. 콜마다 실시간으로 다시 계산한다 — *"지금 총 79,000원인데 시급 3만이 안 나오니 하나만 더"* |
| **동선이 안 맞다** | 잡으면 경로가 꺾여 손해인 콜. *"파주 3만, 의정부 3만이 떴는데 **동선이 안 맞아요. 과감히 버리세요**"* |
| **뭘 안 잡느냐** | 무엇을 잡느냐보다 중요한 판단. 이 영상의 핵심 표현 |
| **위성지도** | 공단·창고처럼 진입로가 복잡한 곳을 미리 보는 방법 |

## ④ 기사님! 일을 왜 그딴 식으로 하세요! (주선사 관계)

| 용어 | 뜻 |
|---|---|
| **기사 평가** | 주선사가 남기는 기사 평판. 전산에 뜨고 콜을 잡을 때마다 상대에게 보인다. *"악플만 쭈르르 달려 있을 것"* — 잘해도 칭찬은 잘 안 달린다 |
| **신용도** | 기사 신용 등급. 취소비 대신 요청해 올릴 수 있다 |
| **배차 제한 · 차단** | 주선사가 특정 기사에게 자기 콜을 안 보이게 하는 것. **차단된 사실 자체도 평가에 올라간다** |
| **공유센터** | 인성의 분쟁 조정 기구. 기사·사무실 양쪽에 페널티를 줄 수 있다 |
| **칼질** | 주선사가 운임을 깎는 것 |
| **직권 배차** | 사무실이 특정 기사에게 콜을 지정해 넣는 것 |
| **150% 규칙** | *"인성 150% 내비 시간 내에 못 들어왔다, 그 규칙을 어겼다 하면 **공식적인 제재**를 받을 수도 있다"* — 관행이 아니라 규칙 |
| **첫 한 달 기강** | 신규 3주 동안 주선사 전화가 쏟아지는 관행. 가입 날짜가 상대에게 보인다 |
| **무리한 콜 배차** | 시간상 못 지킬 조합을 찍어 두는 것. 초반에는 피하라고 권한다 |

## ⑤ 인성퀵 그렇게 설정하시면 콜 다 놓쳐요 (필터 설정)

| 용어 | 뜻 |
|---|---|
| **자동배차** | 조건에 맞는 콜을 자동으로 띄우는 설정. 반경 · 도착지 · 금액 셋으로 이뤄진다. `1DAL →` **콜 필터** |
| **반경** | 내 주위 몇 km 안의 콜을 띄울지. 서울 5~7km · 경기 외곽 7~15km. 첫 콜을 잡으면 **줄인다** (7→5km). `1DAL →` **상차 반경** |
| **도착지 설정** | 목적지 지역 필터. 🔴 *"너무 처음부터 도착지를 다 한정시켜 버리면 우연하게 묶을 수 있는 콜을 다 놓치고 **묶는 실력도 줄어든다**"* — 첫 콜(또는 두 번째)까지는 안 걸고 본다 |
| **금액 설정** | 최소 운임 필터. `1DAL →` **minFare** |
| **수수료 23%** | 화주가 낸 금액에서 떼는 비율. 화주 3만원 → 기사 화면에 23,000원 |
| **🔴 필터를 낮춰 거는 법** | 수수료율이 사무실마다 달라 `22,900원`처럼 애매하게 올라온다. **23,000원으로 걸면 100원 차이로 놓친다** → 23,000 원하면 **21,000원**에, 27,000 원하면 **24~25,000원**에 건다 |
| **점 → 선** | 콜 하나는 점, 둘을 잡으면 선이 되어 **동선이 강제**된다 |
| **운행 취소 횟수** | 취소 가능 횟수 제한. 도착지를 넓게 열면 이게 부담이 된다 |
| **플랜 B** | 콜이 안 뜰 때의 대비책. *"한 시간이고 두 시간이고 기약 없이 기다릴 수 없잖아요"* |
| **총량의 법칙** | 초반에 운이 없으면 나중에 좋아진다는 경험칙 |

## ⑥ 퀵서비스 고수들의 특징 (태도·습관)

| 용어 | 뜻 |
|---|---|
| **복기** | 그날 탄 콜을 되돌아보는 것. *"오답노트를 쓴다"*. 고수의 핵심 습관으로 꼽는다 |
| **우상향** | 수익이 꾸준히 오르는 것. *"한번 수익이 늘어나면 떨어지진 않아요"* |

| **상향 평준화** | 카페·유튜브에 잘 버는 사람 글만 올라와 기준이 높아 보이는 현상 |
| **오더 성격** | 콜마다 다른 특성(급한가·짐이 어떤가·화주가 어떤가). 하루에 다섯 가지 이상 만난다 |
| **작은 일에 연연하지 않기** | 몇 천원 손해는 넘긴다. *"기분 좋게 일하는 값"* |

| **중간 기착지** | 경로 중간의 하차 지점. **거기서 또 하나 묶을 기회**가 생긴다. *"중간 기착지마다 한 번씩 더 묶을 수 있을 만한 기회가 있다"* |

| **초콜(첫 콜)** | 그날 첫 콜. *"첫 콜이 하루의 운명을 결정한다"* |
| **빈도수 · 경우의 수** | 그 방향으로 콜이 **또 뜰 가능성**. 첫 콜을 고르는 두 번째 기준. *"청주·천안 가는 건 그 밑으로 내려가는 게 또 뜰까 생각하면 경우의 수가 작죠"* |
| **콜 잡는 세 기준** | ① 요금 ② 동선 ③ **뒤에 더 묶을 만한 콜이 뜰 방향인가** |
| **콜창** | 콜 목록 화면. *"도착지 10분 전부터 콜창을 보면서"* |
| **금액의 유혹** | 동선을 무시하고 비싼 콜을 잡는 것. *"금액의 유혹에 안 빠지신 게 실력이 빠르게 는 큰 이유"* |
| **서울을 뚫다 / 돌다** | 서울 관통은 막히니 외곽 순환으로 우회하는 것 |
| **폭기콜(복귀콜)** | 집으로 돌아가면서 잡는 콜 |

## ⑨ 퀵서비스 시작 2달 만에 연봉 1억 (월천 기사 인터뷰)

| 용어 | 뜻 |
|---|---|
| **월천** | 월 매출 1,000만원. 실수령은 유류·톨·정비 등 **약 30%** 를 뺀 값 |
| **3합짐 · 4합짐** | 세 개·네 개를 합쳐 싣는 것. `1DAL →` **합짐1콜 · 합짐2콜** (세는 방식이 다르다) |
| **다마 · 다마소 · 다마중 · 다마대** | 다마스 기준 짐 크기 구분. 적요란에 이 표기만 오는 경우가 많다 |
| **적요란** | 짐 설명란. 🔴 *"적요란이 너무 안 맞아요"* — `다마중` 이라 해서 갔더니 지퍼백 하나, `박스 11개` 라더니 1톤 짐. `1DAL →` **적요** |
| **빈차로 들어가다** | 짐 확인 없이 픽업지로 가는 것 |
| **2회전** | 오전·오후 두 번 도는 것. *"오전 15만 + 오후 15만 = 30만"* |
| **공단 출근 시간** | 지역마다 콜이 쏟아지는 시각이 다르다. **공단 8:30 · 지식산업센터 9:00~9:30**. 🔴 콜 빈도가 `지역 × 시간대` 라는 실증 |
| **10시 전에 픽업을 끝낸다** | 점심 전(또는 1시까지) 하차를 마쳐 오후 2회전을 시작하기 위한 기준 |
| **고르면 못 번다** | 초보가 콜을 재다 아무것도 못 잡는 것. *"바퀴가 굴러가면 무조건 돈은 돼요"* |
| **취소비** | 헛걸음했을 때 받는 보상. 못 받는 경우도 많다 |
| **30클럽** | 하루 30만원을 찍는 사람들의 모임/게시판 |
| **주행일지** | 그날 탄 콜을 기록해 공유하는 것 |
| **시간을 녹인다** | 경험을 쌓는 것을 이르는 말. *"시간을 때려박은 스타일"* |
| **가지 말라는 곳** | 승용차로는 가면 안 되는 상하차 지점(물류창고 · 연화부두 등). 지역 커뮤니티가 공유한다 |

## 🔴 우리에게 **없는** 개념 (합칠 때 눈여겨볼 것)

| 용어 | 어디서 | 왜 중요한가 |
|---|---|---|
| **파도** · **공단 출근 시간** | ①⑨ | 콜 빈도가 `지역 × 시간대`. 갇힘·브릿지 판단의 재료인데 우리는 데이터가 없다 |
| **브릿지** | ② | 운임이 아니라 **자리**를 사는 콜 |
| **내일착짐(예약콜)** | ② | 전날 밤에 다음 날 방향이 정해진다. 우리 필터·판정은 *"지금 뜬 콜"* 만 본다 |
| **일반인데 급송처럼** | ③ | 긴급도. 모든 콜에 같은 시한을 주면 안 된다 |
| **블라인드 주소** | ③⑨ | `평택시` 로만 오면 경로·시한이 낙관적으로 계산되는데 표시가 없다 |
| **기사 평가 · 신용도 · 배차 제한** | ④⑧ | 150% 를 넘겼을 때의 실제 대가 |
| **바운더리** · **중간 기착지** | ⑦ | 첫 콜이 여는 후보 범위 / 경로 중간에서 또 묶을 기회 |
| **빈도수(그 방향에 또 뜰까)** | ⑦ | 첫 콜을 고르는 **두 번째** 기준인데 우리는 요금·거리만 본다 |

## ⚠️ 같은 말이 다르게 쓰인 것 (합칠 때 정해야 할 것)

- **묶다 / 합짐** — ①은 `묶다`, ②⑨는 `합짐`. 뜻은 같다
- **복귀** — ⑥에서는 *"오늘 탄 콜을 되돌아본다"*(복기), ⑦에서는 *"집으로 돌아간다"*(복귀콜).
  자막 자동 생성이라 표기가 섞였다. **우리 `복귀`는 후자**다
- **150%** — ③⑧은 *"지키는 선"*, ①은 넘기면서도 일한다. ④가 *"제재가 있다"* 로 정리한다
- **반경** — ⑤는 `내 주위 반경`(상차), ⑦의 `바운더리`는 **하차 후보 범위**. 서로 다른 것이다
