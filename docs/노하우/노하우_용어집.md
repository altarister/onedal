# 노하우 용어집 — 유튜브 자막 9편에서 추출

> 📌 **[용어집.md](../용어집.md) 와 같은 형식으로 썼다** (기사님 지시 2026-08-20).
> 절 번호도 용어집을 따랐으므로, 합치실 때 **같은 번호의 절에 그대로 붙이면 된다.**
> 용어집에 없는 주제(주선사 관계 · 실력과 태도 · 제도)는 **§A~§C 로 따로 뒀다.**
>
> - **키** = 우리 코드 식별자. `—` 는 **코드에 대응물이 없다**는 뜻이다
> - **구분**: `업계` 업계에서 실제 쓰는 말 · `은어` 업계 은어 · `배차망` 인성/화물24시 화면 표기 ·
>   `채널` 이 유튜브 채널이 만든 말(업계 표준어가 아님)
> - **출처**: ①~⑨ (맨 아래 목록). 여러 편에 나오면 다 적었다
> - **용어집 대응**: 우리 [용어집](../용어집.md) 의 같은 말. `없음` 이면 **우리에게 없는 개념**이다
> - 자막은 자동 생성이라 오탈자가 많다. 명백한 것은 바로잡아 적었다 (`저교란`→`적요란` 등)

## 🔴 합칠 때 정하셔야 할 것

**하나 — 같은 말이 다르게 쓰인다**

| 말 | 어떻게 갈리나 |
| --- | --- |
| **복귀** | ⑥ *"오늘 탄 콜을 되돌아본다"*(복기) / ⑦ *"집으로 돌아간다"*(복귀콜). 자막 자동 생성이라 표기가 섞였다 — **우리 `복귀` 는 후자다** |
| **반경** | ⑤ 는 `내 주위 반경`(상차), ⑦ 의 `바운더리` 는 **하차 후보 범위**. 이름이 비슷해 섞이기 쉽다 |
| **150%** | ③⑧ 은 *지키는 선*, ① 은 넘기면서도 일한다. ④ 가 *"제재가 있다"* 로 정리한다 |
| **내착 / 내일착짐** | 용어집은 *마감*(다음날까지 내리면 됨), ② 는 *잡는 시점*(전날 밤에 미리 잡아 둠) |

**둘 — 우리에게 없는 개념 (🔴 표시한 것)**

`150%` · `파도` · `공단 출근 시간` · `브릿지` · `블라인드` · `빈도수` ·
`일반인데 급송처럼` · `시급` · `기사 평가/신용도/배차 제한`

이 중 **`150%` 와 `시급`** 은 [시간체계_개발계획](../시간체계_개발계획.md) 이 이미 다루고 있고,
나머지는 **실측 데이터가 쌓여야** 다룰 수 있다.
