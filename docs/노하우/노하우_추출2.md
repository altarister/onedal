## 2. 합짐 — 예산 안에서 붙이고, 순서가 값을 정한다

| 노하우 | 출처 | 1DAL |
|---|---|---|
| **3콜이 균형점** — 소형차는 `333`(3콜×3회 = 9콜), 1t 는 3콜×2회 = 6콜 | ②·기사님 | ✅ 기획 §2 와 일치. 차종이 **횟수**를 가른다 (§7) |
| **1~2번째는 잘 안 물어보고 싣고, 3·4합짐부터 상차지 통화**로 사이즈를 확인한다 | ⑨ | ✅ 적재 확신도 + 통화 시트 |
| 짐 조합은 **큰 것 하나 + 작은 것 여럿** — 큰 짐이 자리를 잡고 남은 틈에 작은 것이 들어간다 | ② | ✅ 기획 §2 「마지막 자리는 작은 짐에」 |
| **중간 기착지마다 한 번 더** — 하차 10분 전부터 콜리스트를 보며 다음 방향을 고른다 | ⑦ | ✅ 근접 예고 + 하차지 주변 유지 |
| 🔴 **남하 릴레이** — 왕복(333)이 아니라 **편도로 흘려보내며 길에서 계속 줍는다.** 강남 3픽업 → 분당 → 용인 → 청주 → 대전, 내려가며 2콜을 더 잡아 동시 최대 5콜. 하차지에서 다음 콜을 잡으니 이동(묶음) 횟수가 1회다 | ⑫ | — §7 표의 새 유형. 우리 전진 국면(첫짐→합짐→운행)이 이 릴레이를 자연스럽게 담는지 볼 것 |
| **도착지 콜밭을 알고 잡는다** — 대전 문평동 도착지 *"근처가 콜밭이에요. 그걸 알고 있었기 때문에 찍었다"* · *"대전은 대부분 북대전이라 나쁘지 않다"* (콜밭 = 콜이 많이 뜨는 지역) | ⑫ | 🔧 하차지 주변 콜 빈도(§3 바운더리와 같은 데이터) — intel 이 재료 |
| **놓친 콜은 1분 기다려 본다** — 다른 기사가 잡아도 바로 취소할 수 있다. 단 *"취소 페널티 때문인지 요즘은 취소를 안 한다"* | ⑫ | ✅ 안전취소 30초·취소 카운터와 정확히 같은 판의 규칙 — 상대편에서 본 모습 |
| **하차지를 한 줄로 늘어놓으면** 거리가 짧아도 여럿이 붙는다 (수원→수원→화성→평택 남쪽 일직선) | ① | 🔴 판정이 *"하차지가 얼마나 모여 있나"* 만 보면 이 조합을 놓친다 → 🔧 |
| **픽업 순서는 잡은 순서가 아니다** — 3분 거리에 있는 것을 먼저 처리한다 | ③ | ⚠️ `planArrivalStops` 가 상차 순서까지 최적화하는지 확인 필요 |
| 급송은 **시간을 역산해** 아슬아슬하면 잡는다 (오토바이 콜을 차로 받아 맞춘다) | ⑦ | — `isExpress` 는 있으나 판정에 시간 검산이 없다 |
| **시간 제약이 다른 콜을 섞는다** — 급송 하나 + `2시 픽업` 하나. 기다리는 동안 급송을 처리 | ① | 🔧 대기 시간을 다른 콜의 재료로 쓰는 발상 |

## 3. 동선 — 서울을 피하고, 경로가 꺾이는 콜을 버린다

| 노하우 | 출처 | 1DAL |
|---|---|---|
| **단가보다 동선이 먼저다** — *"단가가 안 좋아도 동선이 더 중요"* | ① | 🔧 판정이 요율 위주라 이 축이 약하다 |
| 🔴 **뭘 안 잡느냐가 더 중요하다** — 3만원짜리도 동선이 안 맞으면 버린다 | ① | ✅ 기획 §3 「경로를 꺾는 콜은 결국 손해」 |
| **서울 관통은 피한다** — 막히고, 추가로 묶을 융통성이 죽는다. 외곽 순환으로 돈다 | ⑦ | ✅ 지도 시간 버튼 → 경유 재파생 · 📖 사용설명서 |
| 대기는 **모서리**에서(한가운데는 사방으로 흩어져 애매) · 하차 후에는 가운데가 좋다 | ⑦ | — 대기와 재출발의 기준이 다르다 |
| **노선(루트 족보)**: 콜은 산업단지 → 산업단지로 뜬다. 지역마다 위/옆/아래 핵심 노선이 있다 | ⑧ | 🔧 후속 콜 빈도의 데이터적 실체 |
| **바운더리** — 첫짐 방향이 정해지면 하차 후보 범위가 넓어진다 (*"일산을 잡으면 의정부·양주·파주·김포 어디가 떠도 붙는다"*) | ⑦ | 🔧 첫짐 판정에 이 값어치가 안 들어간다 |
| 청주·천안행은 후속이 안 뜬다 · 충남·양평은 **탈출이 운빨** | ⑦ | 🔧 하차지 주변 콜 빈도 표시 |

## 4. 시간 — 150% 선과 통화 타이밍

| 노하우 | 출처 | 1DAL |
|---|---|---|
| 🔴 **150%** — `내비 × 1.5` 안에 도착. **픽업 시각마다** 콜별로 마감을 따로 잰다 | ③ | 🔴 **없음** → 🔧 기획 §9. 우리 `시한` 과 **다른 값**이다 |
| 🔴 못 지키면 **공식 제재**를 받을 수 있다 — 배상은 없지만 **배차 제한·기사 평가**가 남는다 | ④ | 🔧 §9-2 「시한이 둘」의 근거 |
| **주선사에게 하는 말**로 쓴다 — *"150%도 안 채우고 더 빨리 갑니다"* | ⑦ | 🔧 주선사 통화 카드 (기획 §9-4 ②) |
| 🔴 **모든 콜에 150% 를 똑같이 주지 않는다** — 휴대폰·공장 부품·카센터는 *"일반으로 불러 놓고 급송처럼"* 가야 한다 | ③④ | 🔴 **긴급도 개념 없음** → 🔧 적요 파서가 재료를 이미 읽는다 |
| **예약 픽업은 당길 수 있다** — *"10시 예약이라고 꼭 10시에 들어가야 되는 건 아닙니다"* | ③ | 🔧 예약 시각을 하드 제약으로 두면 안 된다 |
| **통화 타이밍 셋** — 나오기 **전에** 주선사 · 픽업까지 **절반**(20분 남음)에 출발지 · 도착 **30~40분 전**에 도착지 | ③ | 🔧 *"지금 통화할 때입니다"* 알림 · 📖 사용설명서 |
| **오전 픽업은 10시 전에 끝낸다** → 1시까지 전부 하차 → 1시부터 2회전 | ⑦⑨ | — 하루 모델과 부합. 안 지키면 *"내려와서 콜사(콜 없음) 맞는다"* |
| **점심을 긴 주행에 겹친다** — 콜이 적은 시간이라 그때 가장 먼 구간을 달린다 | ② | 🔧 기사님 계획의 `점심 1시간` 이 별도 블록이 아닐 수 있다 |
| 🔴 **긴급도를 전수 확인하면 동선이 자유로워진다** — 3콜 전부 "안 급함"을 알고 있었다(물류창고 = 언제든 무방 · 받는지도 모르는 판촉물 · 2시 마감). 그래서 픽업 순서·합짐 추가를 마음대로 조립했다 | ⑫ | 🔧 기획 후보 12(긴급도)의 가장 좋은 근거 — **긴급도를 알면 시한이 아니라 예산이 된다** |
| **급송 딱지를 그대로 믿지 않는다** — 29분 만에 급행했더니 *"받는 고객이 해외 출장 중. 보내는 사람만 급했다"* | ⑫ | — 긴급도의 원천이 발신자라는 한계. 통화 확정(우리 순서)이 답이다 |
| 🔴 **지각이 확정되면 쿨하게 인정한다** — *"주선사에서 전화 오면 쿨하게 인정하고 죄송하다 말씀을 남기고 일 처리"*. 변명 대신 원인 복기: 욕심 한두 개 + 충전 미비 + 추돌사고 정체 + 충전기 고장이 겹쳤다 | ⑫ | 📖 ④의 "늦을 것 같으면 먼저 연락"과 짝 — 늦기 전엔 선연락, 늦은 뒤엔 인정 |

### 🔴 평균 합짐 수는 **차종과 무관하게 3에 수렴한다**

```
① 승용차   9콜 ÷ 3회 = 3.0    구로→평택(5) / 오산→인천(2) / 인천→서울(2)

1t        6콜 ÷ 2회 = 3.0    광주→파주(3) / 파주→광주(3)
```

**달라지는 것은 합짐 수가 아니라 ⓐ 이동 횟수와 ⓑ 콜당 거리다.**

```
승용차   3콜 × 43km  × 3회 = 9콜 · 26만원
1t      3콜 × 80km  × 2회 = 6콜 · 25~30만원   ← 같은 돈을 절반의 콜로
```

→ §2 의 *"3콜은 목표가 아니라 균형점"* 이 **세 차종에서 모두 확인된다.**
   짐칸·상하차·시간 세 제약이 어느 차종에서나 3 근처에서 만나기 때문이다.

### 🔴 그런데 **물리적 주행은 1t 가 절반이다** (기사님 실측 2026-08-20)

기사님: *"1톤은 200~300이라 차이가 많이 난다."*

배송거리 합은 비슷한데(385 vs 390km) **하루에 실제로 굴리는 거리가 두 배 다르다.**

```
              배송거리 합   실제 주행      비
승용차 ①        385km      400~500km    1.0~1.3배   ← 실주행이 더 크다
1t             390km      200~300km    0.5~0.8배   ← 실주행이 절반
```

**합짐이 겹치기 때문이다.** 1t 한 묶음(3콜)을 풀어 보면 —

```
배송거리 합   65km × 3콜            = 195km      (운임은 이걸로 받는다)
실제 주행     65km + 양 끝 순회 20   = 약 85km    ← 0.44배
왕복 2회      약 170km + 접근        = 200~250km  ✅ 기사님 값과 맞는다
```

같은 길을 한 번만 달리면서 **운임은 세 번 받는다.** 이게 §2 합짐의 실체다.

반대로 승용차는 9콜을 3묶음으로 나눠 처리하면서 **픽업하러 여기저기 돈다** —
그 이동이 배송거리를 넘어선다(1.0~1.3배). 콜이 많다는 것은 **픽업 지점도 많다**는 뜻이다.

🔴 **그래서 1t 는 매출이 같아도 기름값·피로가 절반이다.** §10 의 *"순익 = 매출 × 0.7"* 도
차종마다 다른 값이어야 한다 — 그 27~30% 는 **400~500km 를 굴리는 기사의 숫자**다.

⚠️ **거리는 대부분 자막에 없다.** ① 은 지역명에서 추산했고 ② 는 아예 없다. 자막이 밝힌 것은
⑨ 의 카니발 기사가 말한 **하루 400~500km(많은 날 600km)** 뿐이라, 승용차 실주행은 그 값을 빌렸다.
확실한 것은 **1t 의 200~300km 하나뿐이다**(기사님 실측).

```
승용차   단가가 낮아 많이 잡아야 한다. 대신 상하차가 싸서 많이 잡을 수 있다

```

  선점했다 — 시간대별 수급을 알았다면 다르게 골랐다. §1 의 "일찍 일어난 벌레" 그대로.

### ⭐ 1t 실측 하나 — 야상을 쓰는 하루 (⑪ 나는 용달러다 · LPG)

**우리와 같은 1t 의 하루**다. 지금까지 1t 칸은 기사님 **목표값**뿐이었는데, 처음으로 실측이 생겼다.

```
전날 밤   야상 2건을 미리 싣는다 (다음 날 아침 하차분)
새벽 3~4시  눈 뜨면 바로 출발 — "6시에 출발해야 하면 눈 뜨자마자 나간다"
08:00     첫 하차 · 09:00 둘째 하차   ▶ **9만원으로 하루를 시작**
낮        빈파레트 8개(10km·30분) · 수작업 콜 · 원두 30박스(1파레트)
14:30     내일 몫 야상 2건을 미리 싣는다
16:30     마무리 — **5콜 · 350,000원** (야상 91,000원은 내일 매출로 넘김)
```

| | 값 |
|---|---|
| 콜 수 | **5콜** |
| 매출 | **350,000원** · **콜당 70,000원** |
| 기본 컨디션 | 25~30~35만원 |
| 연료 | LPG (하남 휴게소 1,158원/L) |

🔴 **콜당 70,000원 — 스타리아(49,804원)의 1.4배**다. §7 표의 *"1t 는 단가가 높아 적게 잡아도
된다"* 가 실측으로 확인된다. 5콜로 35만원이면 기사님 목표(6콜 25~30만)를 넘는다.

🔴 **야상이 그 비결의 절반이다.** 아침 8시·9시에 이미 9만원을 벌고 시작한다 —
그 시간대는 원래 *"콜을 기다리는 시간"* 인데, **전날 밤에 그 시간을 미리 사 둔 것**이다.
②의 `내일착짐` 과 같은 구조인데, 이쪽은 **1t 판이고 습관으로 굳어 있다.**

### 🔴 7일을 보니 **시급이 가장 안 흔들린다**

| | 최소 ~ 최대 | 최대/최소 |
|---|---|---|
| 매출 | 138,500 ~ 312,000원 | **2.25배** |
| **km당** | 554 ~ 1,250원 | **2.26배** ← 가장 흔들린다 |
| 콜당 | 41,667 ~ 56,250원 | 1.35배 |
| **시급** | 24,800 ~ 30,383원 | **1.23배** ← 가장 안정적 |

매출은 두 배 넘게 흔들리는데 **시급은 24,800~30,383원 안에 모인다.**
→ 기사님이 *"소형은 시급을 중요하게 생각한다"* 고 하신 것이 **데이터로 확인된다.**
   흔들리는 값으로는 판단할 수 없고, **안정적인 값이라야 기준이 된다.**

⚠️ **1t 도 그런지는 모른다.** 1t 는 거리가 짧고 콜이 적으니 km당이 더 안정적일 수 있다 —
**우리 실측이 쌓이면 이 표를 1t 로 다시 그려 봐야 한다.** 그게 §7 의 *"분모를 무엇으로 할까"* 의
가장 확실한 답이 된다.

### 🔴 스타리아는 **1t 만큼 달리면서 절반을 번다**

```
스타리아   261km · 4.8콜 · 콜당 50,180원 · 시급 28,268원
1t        200~300km · 6콜 · 콜당 100,000원 · 목표 25~30만
```

거리는 거의 같은데 **콜당 단가가 절반**이다. 9시간으로 환산하면 스타리아도 25.4만원이라
매출은 비슷한데, **같은 돈을 벌려고 같은 거리를 굴린다** — 기름값·마모는 그대로다.

→ §7 의 결론을 강화한다. **큰 차의 이점은 매출이 아니라 `km당 단가`** 다.
   같은 시급을 내면서 **덜 굴리는 것**이 1t 의 값어치다.

### 🔴 그래서 **차종마다 보는 값이 다르다** (기사님 2026-08-20)

기사님: *"큰 차들은 **km당 단가**를 중요하게 생각하고, 소형은 **시급**을 중요하게 생각하는 것 같다."*

숫자를 놓고 보면 왜 그런지가 드러난다.

| | 1t | 승용차 |
|---|---|---|
| 하루 | 250km · 27.5만 · **6콜** | 450km · 26.4만 · **9콜** |
| km당 | **1,100원** | 587원 |
| 시급 | 30,556원 | 28,696원 |
| **9시간 동안** | 6콜 — **시간이 남는다** | 9콜 + 픽업 이동 — **시간이 꽉 찬다** |
| **병목** | **거리**(기름값·마모)와 **적재** | **처리 횟수**(상하차·픽업 이동) |

**남는 것으로는 재지 않는다.** 1t 는 시간이 남으니 시급으로 재면 웬만한 합짐이 다 통과한다 —
정작 아픈 곳(기름값·짐칸)을 못 본다. 승용차는 반대로 거리가 아니라 **하루에 몇 개를 처리하느냐**가
매출을 정하니 시급으로 잰다.

### 두 기준이 **갈리는 자리**가 실제로 있다

같은 합짐(운임 4만원)을 두 기준으로 재 보면 답이 엇갈린다.

```
ⓐ 고속으로 멀리 도는 합짐   거리 +40km · 시간 +20분
   km당  1,176 → 1,120원   ▼ 버린다
   시급 33,333 → 42,042원   ▲ 붙인다      ← 시급만 보면 놓치는 함정

ⓑ 가까운데 상하차가 긴 합짐  거리 +8km · 시간 +50분
   km당  1,176 → 1,505원   ▲ 붙인다
   시급 33,333 → 36,554원   ▲ 붙인다
```

🔴 **ⓐ 가 1t 가 조심해야 할 자리다.** 시간은 조금밖에 안 먹는데 거리를 많이 늘린다 —
시급은 오르지만 **기름값이 그 이상을 먹는다.** 반대로 소형차는 ⓑ 처럼
거리는 짧은데 시간을 먹는 콜을 조심해야 한다.

### ⚠️ 이 통찰이 우리 설계를 하나 뒤집는다

| | 지금 | 맞나 |
|---|---|---|
| 앱 1차 필터 | `요금 ≥ 배송거리 × 단가` = **km당 단가** | ✅ **1t 에 맞다** |
| 서버 합짐 판정 | 우회 비용(**분**)으로 순위 | ⚠️ 시간 축이다 |
| [기획 §5](../콜_시한과_합짐_예산.md) 가 제안한 최종 기준 | **시급** | 🔴 **소형차 논리였다** |

기획 §5 에 *"합짐 판정의 최종 기준은 시급일 수 있다"* 고 썼는데,
그건 **시간이 병목인 차종의 셈법**이다. 1t 는 시간이 남으므로 그 식으로는
ⓐ 같은 합짐을 걸러내지 못한다.

→ **차종에 따라 분모를 바꾼다**는 것이 이 통찰의 결론이다.
   우리는 이미 `vehicleType` 을 알고 있으므로 고를 수 있다.

```
큰 차(1t~)   붙인다 ⟺ (매출 + 운임) / (주행 + 추가주행) > 매출 / 주행    ← km당 단가
소형·승용     붙인다 ⟺ (매출 + 운임) / (소요 + 추가시간) > 매출 / 소요    ← 시급
```

⚠️ 다만 **둘 다 봐야 하는 것**일 수도 있다 — 시간은 §4 의 150% 선이 이미 따로 막고 있으니,
1t 에서 시급은 *"할 수 있나"* 가 아니라 *"얼마나 이득인가"* 를 재는 보조 축으로 남을 수 있다.
**기사님 확인이 필요하다.**

### 12-3. 🔴 이 편이 우리 설계에 던지는 것

**① 합짐의 값은 "자기 우회"가 아니라 "뒤에 주는 피해"다.**
지금 판정은 콜 하나의 우회 km 를 본다. 그런데 실제로 아픈 것은 **그 우회가 뒤 콜 전부를 미는 것**이다.
콜 4개를 실었으면 한 시간 우회는 **네 시간짜리 손해**다.

**② 국면이 하나 빠졌다 — 「탈출」.**
`복귀`는 집으로 가는 것이고, `탈출`은 **콜이 있는 곳으로 나오는 것**이다. 방향이 다르다.
외지 하차 뒤에 무엇을 잡을지는 **집 방향이 아니라 "콜이 뜨는 곳" 방향**이다.

**③ 시간은 지역과 화물에 따라 다르다.**
`잡은 시각 + 60분` 은 시내 기준이다. 광역 장거리는 더 널널하고, 픽업 20분도 30분까지 봐 준다.

**④ "언제"가 "어디"만큼 중요하다.**
오전 9~10시 · 오후 2시에 물건이 나온다. 기획 §B(후속 콜 빈도)에 **시간축**을 넣어야 한다.
