# 주소 검증

시뮬레이터가 만든 주소가 **카카오에서 실제로 통하는지** 검사한다.

## 왜 필요한가 (2026-08-24 신설 근거)

1회차 필드 테스트에서 카카오 길찾기가 4번 실패했고, 원인을 찾는 데 하루가 걸렸다.
찾고 보니 **주소 사전에 들어 있던 두 주소**였다.

```
경기 광주시 목현동 558 쏘카 광주정비센터
  → 좌표는 나온다 (127.204247, 37.441881)
  → 길찾기는 ❌ 코드 103 «도착 지점 주변의 도로를 탐색할 수 없음»

경기 파주시 파주읍 파주리 169 CJ대한통운 파주터미널
  → 주소검색·키워드검색 둘 다 «결과 없음»
  → 그런데 폴백 다섯 개 중 하나가 엉뚱한 좌표를 물고 왔다 → 101
```

🔴 **좌표가 나온다고 쓸 수 있는 주소가 아니다.** 셋을 다 봐야 한다.

## 무엇을 검사하나

| | 검사 | 실패하면 |
|---|---|---|
| **①** | 지오코딩 — 좌표가 나오나 | 카카오가 모르는 주소. **버린다** |
| **②** | 길찾기 — 그 좌표로 경로가 서나 | 도로에서 떨어진 지번. **버리거나 도로변 주소로 바꾼다** |
| **③** | 폴백 일치 — 주소검색과 키워드검색이 같은 곳을 가리키나 | 폴백이 **엉뚱한 곳**을 물고 올 수 있다. 사람이 확인 |

③이 중요하다. 서버의 `geocodeAddress` 는 폴백 쿼리 5~6개를 **병렬로 쏘고 먼저 맞는 것을 채택**하므로,
원본을 못 찾아도 **조용히 다른 곳을 답으로 준다** (규칙 ④ *"없는 숫자를 지어내지 않는다"* 와 어긋나는 자리).

## 쓰는 법

```bash
# 시뮬 주소 사전 전체
python3 .claude/skills/주소검증/scripts/verify_addresses.py \
    --json onedal-sim/packages/core-simulator/src/data/mockLocationData.json

# 문제지 (presets.ts 의 pickup/dropoff 를 긁는다)
python3 .claude/skills/주소검증/scripts/verify_addresses.py \
    --ts onedal-sim/packages/core-simulator/src/presets.ts

# 주소 몇 개만
python3 .claude/skills/주소검증/scripts/verify_addresses.py \
    --addr "경기 광주시 목현동 558 쏘카 광주정비센터" "경기 광주시 경안동 167-1 경안천 체육공원"
```

- API 키는 `onedal-web/server/.env` 의 `KAKAO_REST_API_KEY` 를 자동으로 읽는다. **키를 화면에 찍지 않는다**
- 기준 출발지 기본값은 **기사님 생활권(초월, `127.2945543,37.3766579`)** 이다.
  근거: 2026-08-23 주행 로그의 실제 출발 좌표. `--origin x,y` 로 바꿀 수 있다
- 호출 수가 많으므로(주소당 2~3회) 큰 파일은 시간이 걸린다. `--limit N` 으로 잘라 시험할 것

## 결과를 어떻게 쓰나

```
✅ 정상        그대로 쓴다
❌ 좌표없음     주소 사전에서 뺀다 — 카카오가 모르면 서버도 모른다
❌ 도로없음     지번 중심점이 도로 밖이다. 도로변 주소로 바꾼다
⚠️ 폴백불일치   주소검색과 키워드검색이 다른 곳을 가리킨다. 눈으로 확인
```

🔴 **`❌` 는 시뮬에서 빼면 사라지지만, 실전 배차망에서는 같은 주소가 또 온다.**
그때 서버가 어떻게 할지는 별개 문제다 — 규칙 ⑤-2 대로 *"모르면 모른다고 표시하고 기사님께 넘긴다"* 가
맞는지, 지금처럼 판정 자체를 포기할지는 **아직 정해지지 않았다.**

## 고칠 때 손대는 곳

| 무엇 | 어디 |
|---|---|
| 랜덤 시뮬이 뽑는 주소 사전 (140개) | `onedal-sim/packages/core-simulator/src/data/mockLocationData.json` |
| 문제지 (`pickup`·`dropoff`·`pickupFallback` 좌표) | `onedal-sim/packages/core-simulator/src/presets.ts` |
| 옛 사본 (참고용) | `ex/mockLocationData.json` |

⚠️ `presets.ts` 는 좌표가 **하드코딩**되어 있다. 주소를 바꾸면 `lon`·`lat` 도 같이 바꿔야 한다 —
이 스크립트가 새 좌표를 함께 출력한다.
