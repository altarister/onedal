# 주행 시나리오 만들기

**«무엇을 확인하고 싶은가»** 를 받아 `pnpm drive` 가 먹을 문제지를 만든다.
이 스킬은 **문제지까지**다. 돌려서 검수하는 것은 [주행검수](../주행검수/SKILL.md) 가 한다.

## 🔴 왜 나눠 놓았나 — 문제지가 틀리면 검사가 거짓말한다

2026-08-29 에 이 실패를 실제로 했다. 8/25 사고(*"4km 앞 하차지를 두고 30km 밖 상차지로
갔다"*)를 재현하려고 문제지를 짰는데 —

```
첫짐:  곤지암 상차 → 세종대왕면 하차     ← 곤지암을 «4km 앞» 이라 적었다
합짐:  가남 상차 → 태전 하차
```

**곤지암은 상차지였다.** 상차지는 이미 다녀와 **경로에서 빠지는 자리**다. 정작 남는
하차지(세종대왕면)는 **27.5km 밖**이라 *"코앞 하차지"* 라는 상황이 **아예 없었다.**

🔴 **검사 11건이 전부 통과했다.** 다른 것을 통과한 것이다. 기사님이 화면을 보고
*"가남에 갔다가 곤지암에 와 있는 이게 맞다는 거야?"* 라고 물어서야 드러났다.

→ 그래서 이 스킬은 **거리를 반드시 검산**하고, 그 숫자를 문제지에 적어 둔다.

## 받는 것 — 테스트 의도

사람이 말로 준다. 예:

- *"주행 중에 합짐이 붙었을 때 코앞 하차지를 먼저 하는가"*  ← 8/25 사고
- *"만재 상태에서 큰 짐이 오면 차종에서 걸리는가"*
- *"복귀 국면에서 역방향 콜이 차단되는가"*

## 만드는 순서

### ① 의도를 «거리 관계»로 번역한다

의도가 성립하려면 **어떤 거리 관계가 필요한가**를 먼저 적는다. 이게 검산의 기준이 된다.

```
의도: 주행 중 합짐 — 코앞 하차지를 먼저 하는가
필요: · 첫짐의 **하차지**가 현위치에서 가깝다      (≤ 5km)
      · 합짐의 **상차지**가 멀다                  (≥ 25km)
      · 합짐의 하차지는 더 멀다                   ← 되돌아오면 왕복이 눈을 가린다
```

🔴 **«상차지»와 «하차지»를 혼동하지 않는다.** 이미 상차한 콜은 상차지가 경로에서 빠진다
(`hasVisitedStop`). *"가까운 정거장"* 은 **하차지**여야 한다.

🔴 **한 방향으로 짠다.** 되돌아오는 경로는 «순서» 문제와 «콜 자체의 성질» 문제가 섞여
   사람이 결과를 못 읽는다. 기사님이 실제로 그렇게 막혔다 (2026-08-29).

### ② 경로를 그린다

```
집 ─ 첫짐상차 ─ 첫짐하차 ─ 합짐상차 ─ 합짐하차     (서 → 동 한 방향)
              ↑
        합짐이 붙는 지점 (첫짐 하차지 3~4km 앞)
```

### ③ 주소를 찾는다 — **캐시부터 본다**

```bash
cd onedal-web/server && node -e '
const db=require("better-sqlite3")("local.db",{readonly:true});
for(const r of db.prepare("SELECT query,x,y FROM geocode_cache WHERE query LIKE ? LIMIT 5").all("%곤지암%"))
  console.log(r.query, r.x, r.y);'
```

캐시에 있으면 **그걸 쓴다** — 카카오를 안 불러도 되고, 리허설 문제지에도 그대로 쓸 수 있다.
없으면 [주소생성](../주소생성/SKILL.md) 으로 만들고 [주소검증](../주소검증/SKILL.md) 으로 확인한다.

### ④ 🔴 거리를 검산한다 — **이 단계를 건너뛰지 않는다**

```bash
python3 .claude/skills/주행시나리오/scripts/check_scenario.py --json /tmp/시나리오.json
```

이 스크립트가 답하는 것:
- 의도가 요구한 거리 관계가 **실제로 성립하는가**
- 두 순서(길목부터 vs 상차먼저)의 **총거리 차이**가 얼마인가 — 차이가 작으면 문제지가 무디다
- 되돌아오는 구간이 있는가

**차이가 5km 미만이면 문제지를 다시 짠다.** 그 정도로는 규칙이 바뀌어도 눈에 안 보인다.

### ⑤ 문제지를 코드에 넣는다

`onedal-web/scripts/drive.mjs` 의 좌표 상수와 ①의 거리표를 함께 고친다.
**거리를 주석에 적는다** — 다음 사람이 검산 없이 믿지 않도록.

## 넘길 때

문제지가 서면 [주행검수](../주행검수/SKILL.md) 로 넘긴다. 거기서 돌리고, 실패하면
**이 스킬로 되돌아와** 주소·경로를 고친다.

## 함정

- ⚠️ **좌표는 지어내지 않는다.** 지오코딩 캐시나 카카오가 준 것만 쓴다 (주소생성 스킬의 원칙과 같다)
- ⚠️ **콜을 DB 에 직접 넣지 않는다.** 세션 복구는 로그인 때 한 번만 돌아서, 달리는 중에
  넣은 행은 영영 세션에 안 들어온다. `drive.mjs` 는 앱이 올리는 진짜 경로
  (`/orders/confirm` → `/detail`)를 쓴다 — 2026-08-29 에 이걸 몰라 방문 순서가 통째로 비었다
- ⚠️ **기대 색을 단정하지 않는다.** 2026-08-29 에 «🟡 이 정상» 이라 적었는데 **🔵 꿀 73점**이
  나왔다 — 우회가 커도 시급·버퍼·경유 적중이 좋으면 꿀이다. 색은 **판정이 정하는 것**이지
  문제지가 정하는 것이 아니다. 문제지에는 «무엇을 볼지»만 적는다
