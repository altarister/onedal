# 주소 생성

시뮬레이터 문제지에 쓸 **실제로 통하는 화물 배송지**를 만든다.

## 🔴 원칙 — 주소를 지어내지 않는다, 카카오가 아는 것을 가져온다

2026-08-23 주행에서 카카오 길찾기가 네 번 실패했고, 원인은 **사람이 손으로 지어 붙인 주소**였다.

```
경기 파주시 파주읍 파주리 169 CJ대한통운 파주터미널
  → 카카오는 이 주소를 모른다
  → 그런데 서버 폴백이 «CJ대한통운 파주Sub터미널» 을 물고 왔다
  → 시도6 폴백은 «터미날약국» 을 물고 왔다

경기 광주시 경안동 493-4 이마트 광주점
  → 번지로는 못 찾는다
  → 폴백이 «올리브영 경기광주점» 좌표를 답으로 줬다   ← 어제 실제로 이게 쓰였다
```

**이름만 비슷한 엉뚱한 가게가 콜의 좌표가 된다.** 좌표가 틀리면 거리·우회가 틀리고,
그게 곧 **판정 색**이 된다 (규칙 ⑤-3: 색을 틀리는 것이 이 시스템의 가장 큰 사고).

→ 그래서 이 스킬은 **카카오 장소검색이 실제로 돌려준 곳**만 쓴다.
   장소 이름도 주소도 카카오가 준 그대로 쓴다. 사람이 덧붙이지 않는다.

## 만들어지는 주소가 갖춰야 할 것

| | 조건 | 왜 |
|---|---|---|
| ① | 카카오 장소검색에 **실재**한다 | 지오코딩이 반드시 성공한다 |
| ② | 그 좌표로 **길찾기가 선다** | 103(도로 없음)이 안 난다 |
| ③ | **도로명주소**가 있다 | 지번만 있는 곳은 도로에서 먼 경우가 많다 |
| ④ | 화물이 실제로 **드나드는 곳** | 관광지·산·마을은 배송지가 아니다 (어제 교훈) |

## 쓰는 법

```bash
# 광주 → 이천 → 여주 축으로 50개
python3 .claude/skills/주소생성/scripts/generate_addresses.py \
    --course 광주이천여주 --count 50 \
    --out /tmp/새주소.json

# 지역·업종을 직접 정해서
python3 .claude/skills/주소생성/scripts/generate_addresses.py \
    --regions "경기 이천시 부발읍" "경기 여주시 가남읍" \
    --kinds 물류센터 공장 우체국 --count 20
```

- 코스 `광주이천여주` = 초월·곤지암·경안·태전·오포 · 이천(마장·부발·신둔·대월·호법) · 여주(가남·점동·능서·여주동)
  근거: [필드테스트.md §3-6](../../../docs/필드테스트.md) 기사님 실제 동선
- 업종 기본값은 **화물이 드나드는 곳** — 물류센터·공장·우체국·농협·하나로마트·산업단지·자재상
- API 키는 `onedal-web/server/.env` 에서 자동으로 읽는다. **화면에 찍지 않는다**

## 결과를 어디에 넣나

| 쓸 곳 | 파일 |
|---|---|
| 랜덤 시뮬이 뽑는 주소 사전 | `onedal-sim/packages/core-simulator/src/data/mockLocationData.json` |
| 문제지 (`pickup`·`dropoff`·`pickupFallback`) | `onedal-sim/packages/core-simulator/src/presets.ts` |

⚠️ 기존 `mockLocationData.json` 의 `lon`·`lat` 은 **전부 `126.9401, 37.2886` 로 같은 가짜**다.
이 스킬은 **진짜 좌표**를 넣는다 — 그래야 `presets.ts` 의 `pickupFallback` 에 그대로 쓸 수 있다.

## 만든 뒤에는 반드시

```bash
python3 .claude/skills/주소검증/scripts/verify_addresses.py --json /tmp/새주소.json
```

생성기가 이미 ①②를 보지만, **검증은 따로 돌린다.** 만든 쪽과 검사하는 쪽이 같으면
같은 실수를 두 번 못 잡는다.

## 콜로 조합할 때 (다음 단계)

주소만으로는 문제지가 안 된다. 콜은 이렇게 만들어진다.

```
상차지 + 하차지 + 요금 + 차종 + (기대: 잡아야 하나 / 말아야 하나)
```

- **요금**은 `거리 × 차종 단가` 로 잡되, «떨어져야 정상» 인 콜은 일부러 미달로 만든다
- **기대값**(`expect`)을 적어야 채점이 된다 — 지금 구로 문제지는 비어 있다
  ([필드테스트.md §3-7](../../../docs/필드테스트.md))
- 국면(첫짐·합짐·운행·복귀)마다 답이 달라지는 콜을 넣는 것이 이 문제지의 값어치다
