# [계획] 로그를 줄이고 태그를 붙인다 — 나중에 문제를 찾을 때 한 줄로 찾히게

기사님 확정 (원문 요지):
- *"불필요한 로그, 로그켓 콘솔로그들을 꼭 필요 / 줄여도 됨 / 불필요로 분류해줘"* → 세 에이전트(1f · 04 · ab)가 각자 분류해 1f 가 취합

## 바꾸는 모습

**1단계 — 줄인다 (04 순서)**
- ①-1 앱 로그 파일의 «불필요» 걷기 → 다음 이천 한 바퀴에서 «꼭 필요» 줄이 전부 남아 있고 `pnpm log` · 픽커 채점기 · 앱 검사가 초록이면 끝
- ①-2 서버 파일 «불필요» + 관제웹 중계 끊기 → 같은 확인
- ①-3 «줄여도 됨»(바뀔 때만 · 요약) — 서버(ab) · 앱(04) 나눠서 → 한 판 줄 수가 서버 ≈ 400 · 중계 ≈ 100 · 앱 ≈ 400 이면 끝

**2단계 — 태그를 붙인다**
- 태그 열 개, 셋이 같은 낱말(용어집): `#콜단계` 잡음·도착·완료·취소 · `#판정` 점수·색·합짐 방향 · `#결재` KEEP·CANCEL·ACK·버튼 · `#필터` 상차·하차 목록·국면·반경 · `#누름` 터치·안 먹힘 · `#화면` 화면 종류 바뀜 · `#위치` GPS·정차·모의 주행 · `#통신` 보고·응답·소켓 · `#경고` WRN·ERR·이상 징후 · `#부팅`
- 붙는 자리는 **시각 다음 첫 토막** 하나: 서버 `02:08:24.101 #판정 🎨 …` · 앱 파일 `… #누름 👉 …`. 이모지는 그대로(눈으로 빠르게), 태그는 기계용
- **로거가 붙인다** — 호출부가 글자로 안 쓴다. 서버 `fileLogger` 에 `log(tag, msg)` 한 벌, 앱 `AppLogger.d(logcatTag, tag, msg)` 처럼 인자 하나 추가 · `roadmap(tag, …)`. 관제웹 중계·앱 roadmap 이 서버로 올라갈 때 태그를 그대로 싣는다
- 태그 목록은 한 곳 `onedal-web/shared/src/logTags.ts` ↔ 원달앱 `LogTag.kt` — 짝(생성기 또는 «같다» 검사 하나 · README 「짝이 있는 것」에 한 줄)
- 태그 없이 찍힌 줄은 로거가 `#없음` 을 붙인다 → `pnpm log` 요약이 `#없음` 줄 수를 찍고, 목표는 0. 검사는 «`#없음` 이 HEAD 보다 늘면 빨간불»(audit:docs ⑥ 방식)
- 🔴 **태그는 모든 줄의 꼴을 바꾼다** — 1단계의 «줄 걷기»와 달리 로그 파일을 **파싱하는 도구**(`pnpm log` 자체 파서 · 픽커 채점기의 «🧾 [알람 필터]» JSON 추출 · `appLoop` 등 줄 꼴을 읽는 스크립트)의 정규식이 어긋난다. 2단계 줄별 안에 «로그 파일을 읽는 도구 전수(`grep -rl 'logs/' onedal-web/scripts onedal-sim/scripts onedal-web/server/tests`)를 찾아 **같은 커밋에서** 갱신하고, 옛 꼴(태그 없는 줄)도 한동안 읽히게 둔다» 한 줄을 넣는다(ab 보강)
- 끝: 한 판의 모든 줄에 태그가 있고 `#없음` = 0

**3단계 — 읽기**
- `pnpm log --tag 결재` · `pnpm log call <id> --tag 누름` · 요약에 «태그별 줄 수» 표
- 끝: 오늘 네 판의 질문 다섯(아래 ④)이 각각 명령 한 줄로 답이 나온다

**이번에 하지 않는 것** — 로그 레벨 체계 개편 · 파일 회전 정책 · 로그캣의 폰 시스템 줄(우리 것 아님) · 브라우저 콘솔 자체 줄이기

## ③ 지금 DB 값 대조

새 DB 칸 없음 · 새 설정값 없음. 태그 열 개는 코드 상수(shared ↔ Kotlin 짝). 로그를 줄여도 장부(DB)는 그대로라 궤적·단계·판정은 `pnpm db` 로 그대로 본다.

## ⑤ 이 수정이 기사님 하루에 무엇을 하나

- **좋은 콜**: 그대로 — 로그는 운행 동작을 바꾸지 않는다. 걷는 줄에 판정·필터·누름의 근거는 없다(전부 «꼭 필요»에 남는다)
- **노이즈**: 준다 — 관제웹 그리기 나레이션·매초 위치가 서버 파일에서 빠져 «수상한 줄» 요약이 진짜 경고만 보인다
- **기사님 손**: 그대로 — 화면·설정 변화 없음. ⚠️ 잃는 것 하나: 정차 중의 매초 GPS 는 로그에서 사라진다(궤적 DB 에는 남는다)
