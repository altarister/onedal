# 46 · 시뮬레이터 — 인성 · 화물24시 첫 화면 · 상세 «뒤로»

기사님 말씀: «지금 우리 시뮬레이션은 시뮬레이션 페이지에서 바로 리스트 페이지로 가거든. 각각 초기 화면을 넣어줘 — 이미지는 화물24시/01_메인_홈화면.png, 인성/인성홈.png» · «상세에 들어갔다 히스토리백을 앱에서 작동하니까 시뮬레이션 페이지로 돌아와서 진행을 할 수가 없어 — 각각 페이지를 만들어 작동할 수 있도록» · 이해 확인 «맞아»(인성은 «실행», 화물24시는 «화물정보»를 누르면 목록).

## 1. 지금은 이렇게 돈다
- 준비 화면(`/` · `onedal-sim/src/pages/SetupPage.tsx`)에서 배차망을 고르면 `/dispatch?net=…` 로 가고, `DispatchPage` 가 `SIM_NETS[net].Screen`(인성 `InsungSimScreen` · 화물24시 `Hwamul24SimScreen`)을 그린다 — **첫 화면 없이 곧바로 목록**.
- 상세: `SimNet.detailInHistory` — 인성 · 화물24시 `false`(상태만 바꿈) · 픽커 `true`(`?detail=` 로 방문 기록 한 칸). 그래서 인성 · 화물24시 상세에서 원달앱이 «뒤로»를 누르면 브라우저가 **준비 화면**으로 돌아가 진행이 끊긴다(`nets.ts` 주석이 바로 이 일을 적어 둠).
- 픽커는 첫 화면이 있다 — `PickerSimScreen` 의 `started` **상태**로 `PickerHomeScreen`(«시작하기») → 목록. 방문 기록에는 안 남아, 목록에서 «뒤로»면 역시 준비 화면.
- 원달앱 쪽: 화면 정의 표(`onedal-web/shared/src/networkPages.ts`)에 화물24시 홈(«전국24시콜화물» · HOME)은 있고 **인성 홈은 없다**. 배차망을 가르는 글자 묶음(`networkMarkers`)은 인성 «신규 · 빠른설정» · 화물24시 «화물정보 · 자동새로고침»뿐이라 **두 홈 화면에서 원달앱이 배차망을 못 알아볼 수 있다**(픽커는 «시작하기»가 들어 있음).

## 2. 만드는 것 — 세 배차망 한 순서 «첫 화면 → 목록 → 상세 → 뒤로»(다른 것은 배차망 설정 인자)
1. **첫 화면 둘** (`onedal-sim/packages/ui-simulators/src/insung/InsungHomeScreen.tsx` · `hwamul24/Hwamul24HomeScreen.tsx` — 있는 폴더에 새 파일)
   - 인성: «인성퀵화면분할» · 그룹 두 줄(체크) · 실행 · 설정 · 5:5 · 종료 · 원격지원요청 · «INSUNG DATA» — «실행»을 누르면 목록.
   - 화물24시: «전국24시콜화물» 머리 · 위치 · 잔액 · 화물정보 · 배차내역 · 화물등록 · 음성등록 · 스마트배차 · 협력업체 · 고객센터 · 공지사항 · 가상계좌 · 차량조회 · 아래 탭(홈 · 화물정보 · 마이페이지 · 환경설정) — «화물정보»를 누르면 목록.
   - 글자는 실물 캡처 그대로(원달앱이 글자로 화면을 가른다 · 웹뷰라 칸 사이 공백이 붙어 올 수 있음 — onedal-app CLAUDE.md).
2. **화면을 방문 기록으로** (`DispatchPage` · `nets.ts`): 첫 화면 → 목록 → 상세를 주소 칸 하나(`?view=list` · `?detail=`)로 쌓는다. 세 배차망 모두 `detailInHistory: true` 꼴로 같게 — 원달앱 «뒤로»: 상세 → 목록 → 첫 화면 → 준비 화면 순.
   - 픽커도 같은 길로 맞출지(지금은 상태) — 맞추면 «한 순서»가 되나 픽커 시험 흐름이 바뀜 → **이번엔 인성 · 화물24시만**, 픽커는 «찾음»에.
3. **원달앱이 두 홈을 알아보게** (`networkPages.ts` → `pnpm gen:pages` → `InsungPages.kt` · `Hwamul24Pages.kt`):
   - 인성 페이지 목록에 «홈 «인성퀵화면분할»» HOME 한 줄(근거 `ex_images/인성/인성홈.png`).
   - `networkMarkers` 에 인성 `["인성퀵화면분할"]` · 화물24시 `["전국24시콜화물"]` 한 묶음씩 — 🔴 `NetworkByScreenTest` 가 «다른 배차망 화면에 그 글자가 없는지» 대조.
   - 원달앱 새로 깔기 필요(A24).

## 3. 단계마다 끝 · 못 잡는 것
1. 첫 화면 둘 — 끝: 시뮬 `vitest`(onedal-sim) 화면 글자 검사(«인성퀵화면분할» · «실행» / «전국24시콜화물» · «화물정보») 빨간불 → 초록 + `pnpm shot` 두 장을 실물 캡처와 눈으로 대조. 못 잡는 것: 실물과의 생김새 차이(글자만 맞춤).
2. 방문 기록 — 끝: 시뮬 검사 «상세 → 뒤로 = 목록 · 목록 → 뒤로 = 첫 화면»(빨간불 먼저). 못 잡는 것: 원달앱이 실제로 누르는 «뒤로»(폰 확인).
3. 원달앱 알아보기 — 끝: shared `networkPages.test` · 원달앱 `NetworkPagesPairTest` · `NetworkByScreenTest` · `ScreenTableDetectTest` 에 두 홈 원문 문제지 → HOME · 배차망 맞음. 못 잡는 것: 웹뷰가 실제로 붙여 보내는 글자 모양(A24 로그로 확인).
- 전체: 커밋 직전 게이트 한 번(관제웹 `tsc -b` 포함) · onedal-sim 은 push 하면 실서버 리허설에도 올라감(기사님 push).

## 4. 순위 검산
- 2(뒤로)가 없으면 시뮬 시험이 상세 한 번에 끊긴다 — 가장 급함. 1(첫 화면)은 원달앱이 «홈 → 목록»을 실물처럼 지나가는지 시험할 재료. 3이 없으면 1이 «미등록 팝업»이 된다 — 1과 3은 같이.
