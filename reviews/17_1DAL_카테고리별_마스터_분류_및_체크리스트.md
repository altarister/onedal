## 📱 [CATEGORY 1] 안드로이드 앱 & 스캐너 보안 (Mobile App & Security)
> 배차망(인성콜 등) 스크래핑, 터치 주입, 서비스 생명주기 및 매크로 탐지 방어

### Phase_1.1.1 가우시안 타이밍 지터링
- **내용**: 0.001초 기계식 클릭 완전 폐기, 인간의 신체 반응 속도(`평균 130ms ±25ms`) 가우시안 정규분포 딜레이 주입.
- **우선순위 이유**: 배차망 보안 모듈(V3 등)의 서버 로그 분석에서 기계식 클릭 패턴으로 분류되어 **계정 영구 정지(생업 중단)**되는 위험 1순위 방어.
- **출처**: [13번 화이트해커, 06번 기획자]

### Phase_1.1.2 터치 좌표 랜덤화
- **내용**: 버튼 정중앙 동일 좌표 반복 클릭 방지, 버튼 영역 내 `±8px` 랜덤 가변 오차 부여.
- **우선순위 이유**: 항상 일정한 픽셀 좌표를 타격하는 것은 매크로 탐지 솔루션의 기초 판정 기준이므로 반드시 무작위화 필요.
- **출처**: [13번 화이트해커]

### Phase_1.1.3 아날로그 제스처 터치 (`dispatchGesture`)
- **내용**: 단순 가상 클릭 이벤트(`performAction`) 대신 손가락 누름-유지-뗌의 실제 물리 터치 곡선 시뮬레이션 주입.
- **우선순위 이유**: 최신 안드로이드 OS에서 배차앱이 가상 클릭 차단 플래그(`FLAG_IS_ACCESSIBILITY_EVENT`)를 활성화했을 때 터치 씹힘을 원천 우회.
- **출처**: [13번 화이트해커, 09번 앱개발자]

### Phase_1.1.4 Foreground Service 상주화 & 불사조 부활
- **내용**: 스캐너 서비스를 포그라운드 알림으로 상주시키고, OS 강제 종료(Kill) 감지 시 브로드캐스트로 자동 즉각 부활.
- **우선순위 이유**: 주행 중 안드로이드 OS가 메모리 확보를 위해 스캐너를 죽이면 기사는 켜진 줄 알고 1시간 동안 빈 차로 달리게 됨 (소리 없는 사망 방어).
- **출처**: [09번 앱개발자]

### Phase_1.1.5 서비스 사망 감지 워치독 (Watchdog)
- **내용**: 접근성 서비스의 실제 동작 여부를 1초마다 감시하여 서비스 정지 시 화면 모퉁이 적색 경보등 및 강력 진동 경보.
- **우선순위 이유**: 서비스가 비정상 종료되었을 때 기사가 즉시 알아채고 수동 재기동할 수 있는 안전장치.
- **출처**: [09번 앱개발자]

### Phase_1.1.6 삼성 One UI 배터리 최적화 제외 가이드
- **내용**: 앱 첫 실행 시 삼성 스마트폰의 '배터리 사용량 제한 없음' 설정 화면으로 원클릭 유도.
- **우선순위 이유**: 갤럭시 폰의 절전 모드가 켜져 있으면 화면이 꺼진 지 3분 만에 백그라운드 프로세스가 동결(Freeze)됨.
- **출처**: [09번 앱개발자]

### Phase_1.3.8 Zero-Allocation 노드 풀링 (`AccessibilityNodeInfo.recycle()`)
- **내용**: 참조 완료된 노드를 즉시 시스템 풀에 반환하고 텍스트 파싱 객체를 재사용하여 힙 메모리 할당 제로화.
- **우선순위 이유**: 매초 수백 개 노드 생성으로 GC가 돌면 0.1~0.3초간 폰이 멈춤(프리징). 0.05초 만에 사라지는 특A급 꿀콜을 놓치는 주원인 제거.
- **출처**: [09번 앱개발자]

### Phase_1.3.9 화면 변경 델타(Delta) 스캔 최적화
- **내용**: 전체 화면 노드를 매번 훑지 않고 배차앱 리스트 뷰 영역만 타겟팅하여 스캔.
- **우선순위 이유**: 스캔 오버헤드를 80% 줄여 CPU 부하를 낮추고 스마트폰 발열 억제.
- **출처**: [09번 앱개발자]

### Phase_2.1.9 네트워크 통신 현대화 (OkHttp + Coroutines)
- **내용**: `HttpURLConnection` 완전 폐기 및 OkHttp 커넥션 풀링 + Kotlin Coroutines 비동기 파이프라인 전환.
- **우선순위 이유**: 3개월 실전 주행 중 음영 지역 네트워크 랙으로 인한 스캔 스레드 블로킹(ANR 멈춤) 방어.
- **출처**: [09번 앱개발자]

### Phase_3.1.4 패키지명 난수화 빌드 파이프라인 (Polymorphic APK)
- **내용**: 기사마다 설치되는 앱의 패키지명과 클래스명을 무작위 난수로 자동 빌드.
- **우선순위 이유**: 대외 상용 배포 시 배차망이 특정 패키지명을 블랙리스트에 등록하여 일괄 차단하는 사태 무력화.
- **출처**: [13번 화이트해커]

### Phase_3.1.5 R8/ProGuard 다중 난독화 & 무결성 검증
- **내용**: 클래스/메서드 난독화, 하드코딩 문자열 AES-256 암호화, Keystore 해시 검증을 통한 자폭 로직.
- **우선순위 이유**: 상용 서비스 출시 후 경쟁사나 크래커에 의한 APK 디컴파일 및 소스코드 복제 방어.
- **출처**: [13번 화이트해커]

### Phase_3.2.5 온디바이스 NPU ML Kit OCR 듀얼 파서
- **내용**: 화면 캡처 비트맵에서 0.03초 만에 텍스트와 좌표를 추출하는 NPU AI OCR 보조 엔진 탑재.
- **우선순위 이유**: 배차앱이 UI 구조를 전면 개편하거나 접근성 트리를 난독화했을 때를 대비한 최후의 백업 스캐너.
