## 🚨 Tier 1: 생존 & 리스크 방어 (Priority 0: 최우선 필수)
> **"이것이 무너지면 배차망 계정이 잘려 생업이 끊기거나, 앱이 조용히 죽어서 일을 못 합니다."**

### 1. 배차망 매크로 탐지 회피 (스텔스 터치 엔지니어링)
- [ ] **가우시안 타이밍 지터링 (Gaussian Timing Jitter)**: 
  - 0.001초 기계식 클릭 완전 폐기. 숙련된 기사의 물리 반응 속도인 `평균 130ms, 표준편차 ±25ms` 랜덤 딜레이 적용.
- [ ] **터치 좌표 랜덤화 (Coordinate Randomizer)**:
  - 버튼 정중앙 클릭 방지. 버튼 영역 내 `±8px` 랜덤 오차 부여.
- [ ] **아날로그 제스처 터치 시뮬레이션 (`dispatchGesture`)**:
  - `performAction(ACTION_CLICK)` 대신 손가락 누름-유지-뗌의 실제 물리 터치 곡선 주입.

### 2. 안드로이드 접근성 서비스 '소리 없는 사망(Silent Death)' 방지
- [ ] **포그라운드 서비스(Foreground Service) 상주화**:
  - 시스템에 의한 임의 킬(Kill) 방지 및 OS 사망 감지 시 자동 재기동 브로드캐스트 구축.
- [ ] **서비스 사망 감지 워치독(Watchdog)**:
  - 스캔 중단 시 화면 모퉁이에 빨간색 경고등 노출 및 강력한 진동 알림.
- [ ] **삼성 One UI 배터리 최적화 제외 가이드**:
  - 앱 첫 실행 시 삼성 스마트폰의 '배터리 사용량 제한 없음' 설정 인텐트 원클릭 유도.

### 3. 법률 리스크 제로화: '배포/개인 모드' 물리적 격리 전략
- [ ] **대외 배포 버전: 100% 순수 알림 서비스(Notification Only)**:
  - 외부 배포 빌드에서는 자동 터치 코드를 완전히 배제하고, "화물차주 전용 AI 안전운전 및 운행비서 (HUD Assistant)"로 공식 포지셔닝 (형사 처벌 및 업무방해죄 리스크 0% 소멸).
- [ ] **개인 전용 빌드: 지터링이 적용된 프라이빗 자동 모드**:
  - 개발자 본인 단독 사용 빌드로 엄격히 분리하여 안전하게 실익 확보.

## 💰 Tier 2: 실전 수익 방어 (Priority 1: 기사 수익 직결)
> **"기사가 좋은 콜인 줄 알고 잡았다가 4층 계단 까대기나 3시간 물류센터 대기에 묶여 하루를 날리는 사태를 방어합니다."**

### 1. 적요란 텍스트 NLP 필터: '까대기/수작업' 자동 페널티
- [ ] **수작업/계단 키워드 감지 엔진**:
  - 적요란에 `계단, 수작업, 까대기, 구옥, 빌라, 원룸, 층, 동승` 감지 시 시급 계산용 작업 시간에 **+40~60분 자동 가산**.
- [ ] **지게차/독차 우대 가산점**:
  - `지게차, 파레트, 완제, 호이스트` 감지 시 작업 지연 리스크 0으로 판정하여 가산점 부여.

### 2. 대형 물류단지/공단 '출하 대기' 시간 자동 가산
- [ ] **대기 고위험군(Dwell Risk Zone) 좌표 DB 구축**:
  - 이천/용인 쿠팡·CJ 물류센터, 기아차 공단 등 출차 지연이 심한 지점 착지 시 **대기 페널티(+45~60분) 자동 합산**.
- [ ] **오후 3시 이후 퇴근길 세이프티 가드**:
  - 야간 복귀를 방해하는 장기 대기처 콜 경고 및 자동 필터링.

### 3. 과도 우회 콜(90분 이상) 감쇠 계수 적용
- [ ] **절대 우회 시간 캡(Cap) 적용**:
  - 단가가 높아도 추가 우회 시간이 90분을 초과하는 콜은 무조건 🟡(주의) 또는 🔴(거절)로 강등하여 기존 약속 파기 방지.

### 4. 트럭 적재함 LIFO(후입선출) 순서 검증
- [ ] **재적재(생노가다) 방지 순서 검증**:
  - 적재함 안쪽 짐을 먼저 내리는 순서(`A상차 → B상차 → A하차`) 발생 시 재적재 시간(+20분) 페널티 부여 또는 하차 순서 재조정.

## ⚡ Tier 3: 안전 & 체감 성능 최적화 (Priority 2: 운전 안전 및 렉 제거)
> **"시속 80km 주행 중 전방 주시를 유지하고, 열악한 LTE 환경에서도 0.1초 만에 앱이 뜨게 만듭니다."**

### 1. 전방 주시 HUD 스타일 Big 2-Chunk 숫자 도입
- [ ] **초단위 인지 미니멀 UI**:
  - 결재 화면의 잔글씨 제거 → **`+순수익(원)`**과 **`+추가시간(분)`** 2개의 거대 숫자만 전면 노출 (0.1초 인지).
- [ ] **노면 요철 오터치 방지 제스처 결재**:
  - 단순 탭 대신 오른쪽 슬라이드(수락) / 왼쪽 튕기기(취소) 스와이프 인터랙션 옵션 제공.

### 2. 관제탑 프론트엔드 1.66MB 번들 극한 다이어트
- [ ] **코드 스플리팅 (`React.lazy`)**:
  - 설정/디바이스/통계 모달을 동적 import로 분리하여 메인 주행 번들을 150KB 이하로 압축 (로딩 3초 → 0.3초).
- [ ] **화면 꺼짐 방지 (Wake Lock API)**:
  - 주행 중 안드로이드 시스템 절전으로 인한 화면 꺼짐 100% 차단.

### 3. 서버 런타임 현대화 & DB 블로킹 해소
- [ ] **AOT 정적 빌드 번들링**:
  - 운영 환경의 `tsx` 실시간 실행 폐기 → `esbuild` 사전 컴파일 및 `node dist/index.js` 구동 (메모리 40% 절감).
- [ ] **GPS/로그 메모리 링버퍼 일괄 커밋 (Bulk Insert)**:
  - SQLite 단일 쓰기 락 충돌(`SQLITE_BUSY`) 및 이벤트 루프 블로킹 95% 제거.

## 🚀 Tier 4: AI & 플랫폼 확장 (Priority 3: 미래 성장 동력)
> **"시스템이 완전 안정화된 후, 기사의 일일 수익을 30% 이상 끌어올리는 차세대 기술입니다."**

### 1. 머신러닝 실시간 동적 요율 (Dynamic Target Hourly)
- [ ] **우천·교통정체·수급 연동 서지 프라이싱**:
  - 비 오는 날 목표 시급 3만원 → 4.5만원 자동 상향, 한가한 시간대 탄력 하향으로 공차율 최소화.

### 2. 완전 핸즈프리 보이스 AI 비서
- [ ] **음성 브리핑 & 음성 결재**:
  - 화면 볼 필요 없이 스피커로 요약 안내 후 *"잡아!"* 음성 명령으로 100% 핸즈프리 수락.

### 3. 거점 순환 루프(Loop) 회전 배차 모드
- [ ] **당일 공차 제로 순환 알고리즘**:
  - 편도 복귀를 넘어 인근 거점 3~4개를 엮어 하루 종일 차를 채워 달리는 순환 배차 지원.

### 4. 카오스 시뮬레이터 & 자동화 회귀 테스트
- [ ] **가상 모빌리티 시뮬레이터 구축**:
  - 10대 가상 트럭 모의 주행 및 터널 통신 단절, 급유턴 등 고의 장애 자동 주입 스트레스 테스트.
- [ ] **골든 시나리오(160개 과거 버그) CI/CD 회귀 검증 파이프라인**.
