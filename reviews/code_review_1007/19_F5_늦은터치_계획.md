## 지금 이렇게 돈다

- `AutoTouchManager.kt:300` — 모든 누름이 쏘는 순간 `TapInFlight.Record(무엇, 그때 화면 종류, 시각)` 를 남긴다. `judge`(화면 알림마다 · 화면 처리보다 먼저)가 **화면 종류가 바뀌면** «먹혔다»로 지운다. 같은 무엇 · 같은 종류의 다시 누름만 막는다(`blocks`) — 다른 무엇은 막지 않는다(팝업 여닫기는 0.2~0.4초 간격이 필요).
- 채우기 시작은 두 곳이다 — 확정 전 상세 `handleInsungPreConfirmExecution`(IDLE) · 확정 뒤 상세 `handleConfirmedScreen`(IDLE · 보고 안 함). 둘 다 «이 화면 보고가 방금 원달앱이 누른 화면의 잔상인가»를 보지 않는다.

## 고침 — 줄별

1. `core/TapInFlight.kt` — 값만 받는 함수 하나를 더한다:
   `fun pendingOn(rec: Record?, screen: ScreenContext, nowMs: Long): Boolean = rec != null && rec.screen == screen && nowMs - rec.firedAtMs < SETTLE_MAX_MS`
   («이 화면 종류에서 누른 것이 아직 먹혔는지 모른다» — 판정 `judge` 가 종류 바뀜을 보면 기록이 비므로 그 뒤엔 거짓)
2. `core/AutoTouchManager.kt` — `fun pendingOnNow(): Boolean = TapInFlight.pendingOn(inFlight, screenNow, now)` 한 줄(기록은 이미 여기 있다).
3. **공통 한 자리** `HijackService.kt:1366-1373` 화면 종류별 갈래(모든 배차망의 상세 보고가 지난다 — 확정 전 → 공통 관문 `handlePreConfirmScreen` · 확정 뒤 → 배차망 칸 `onConfirmedDetail`) — 상세 두 종류 앞에서 «같은 종류에서 누른 것이 아직 안 끝났다(`pendingOnNow`) **그리고** 이 화면에서 시작한 일이 없다(세션 콜 번호 없음)»이면 로그 한 줄 남기고 그 보고를 넘긴다. 인성 채우기 · 픽커 상세 읽기 · 화물24시 상세 수집이 모두 이 뒤라 배차망마다 줄을 따로 두지 않는다(기사님 «같은 순서, 다른 것은 인자»).
   - «세션 콜 번호 없음»을 함께 보는 까닭: 같은 상세 안에서 원달앱이 «적요상세» · «확정»을 누른 뒤 오는 같은 종류 보고는 이미 시작한 일의 다음 걸음이다(번호 있음) — 막으면 안 된다. 결재 «닫기» · «취소»는 누르자마자 세션을 비우므로 그 뒤 같은 종류 보고는 «떠나는 화면»이다.
   - 확정 전 쪽도 같은 자리에서 막힌다 — 2차 필터 탈락 회피(«취소» · 뒤로) 뒤 늦은 «확정 전 상세» 보고.
- 손대지 않는 것: 누르기 직전 좌표 검사(이번 재현은 쏘는 순간 화면이 아직 상세였다 — 막을 자리가 아니다) · 세션 비우는 때 · KEEP «닫기» 길 · 서버 · 관제앱. 상태 이름(«확정 뒤»)으로 가르지 않는다 — «같은 화면 종류에서 누른 것이 아직 안 끝났다»는 사실 하나로.

## 못 잡는 것

- **손 «닫기» · «취소»**: `TapInFlight` 는 원달앱이 누른 것만 적는다. 그러나 이 길로는 안 난다 — 원달앱 결재 누름만 누르자마자 세션을 비우고(`pressDecisionButton` → `resetSessionState`), 손으로 닫으면 세션은 **목록이 보인 뒤에** 빈다(`HijackService.kt:1289` 목록 복귀). 그 전에 오는 늦은 상세 보고는 채워진 세션을 보고 «할 일 없음»(보고 끝)으로 끝난다. 폰 시험에서 손 «닫기» 한 번으로 확인한다.
- 손 클릭 알림 자체도 시뮬레이터에서 «〈글자 없음〉» · 안 옴이 있었다(15b) — 손 누름을 사실로 들고 같은 판단에 넣지 않는다.

## 각 단계 «무엇이 참이면 끝인가»

1. 단위: `pendingOn` — 같은 종류 · 진행 중 → 참 / 다른 종류 → 거짓 / `SETTLE_MAX_MS` 지남 → 거짓 / 기록 없음 → 거짓. 변이(종류 비교를 빼기 · 시간 비교를 빼기) 🔴.
2. 배선은 폰: 아래 시험에서 KEEP 세 번 중 «⏸️ [채우기 안 함]»이 찍히고 «출발지» 터치가 0.
3. 원달앱 단위 전부 · 원달앱을 읽는 서버 jest 초록 · 판 64.
