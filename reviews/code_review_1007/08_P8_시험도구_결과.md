## 2. 한 줄 결론

배포는 «DB 백업 → 코드 → 빌드 → 재시작 → 살았나»로 잘 짜였지만, **빌드가 깨지면 코드는 이미 새것으로 갈아 끼운 채 멈추고(P8-01), 실서버는 서버 코드를 타입 검사 없이 돌린다(P8-02).** 시험 도구는 실물과 다른 곳 셋이 있다.
