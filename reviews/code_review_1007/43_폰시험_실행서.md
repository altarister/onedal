# 폰 시험 실행서 — 작은 모델 에이전트용

누가 읽나: 폰 시험을 맡은 에이전트(Sonnet). 관제 세션(71)이 이 문서와 장면 번호를 주고, 결과는 장부로 받는다.
너의 일은 **돌리고 · 기록하고 · 멈출 때 멈추는 것**이다. 고칠지 · 맞는지 판단은 관제 세션이 한다.

## 0. 먼저 읽을 것
- 장면 · 맞는 동작 · 틀린 것: `38_70판_시험계획.json` 의 `gaps.rows`(expect · wrong 칸이 판정 기준)
- 장부: `38_시험기록.json` — 끝날 때 `runs` 에 한 판을 덧붙인다(덮어쓰기 금지 · 읽고 붙이고 쓴다)
- 스크립트 · 경로 파일: 같은 폴더의 `phone-test/`(레포 맨 위) — `g.py`(장면 돌리기) · `ledger.py`(장부 덧붙이기) · `run.py`(공통 함수 · S23 포트는 환경 변수 `S23=172.30.1.18:<포트>`) · `m1.py`(움직이는 장면) · `used_calls.json`(쓴 콜 조합) · `v71-unload.mjs`(콜 하나를 하차 완료까지 — 관제 세션 몫) · `*.gpx`(경로)
- `phone-test/`(레포 맨 위) 스크립트를 고치는 세션은 하나다(24) — 폰 시험 세션은 그대로 돌리기만 하고, 고칠 것은 24 에게 «무엇을 · 왜 · 어느 장면»으로 보낸다(따로 사본을 두고 고치면 두 갈래로 갈린다)
- 새 세션이 폰에 adb 로 붙기 전에는 관제 세션에 먼저 알린다 — 두 세션이 같은 폰을 누르면 부딪힌다
- S23 무선 adb 가 끊기면(와이파이가 잠깐 끊길 때 함께 끊김): `adb mdns services` 로 새 포트를 찾아 `adb connect` («이 네트워크에서는 항상 허용» 켜져 있음)

## 2. 절대 하지 않는 것
- `uiautomator dump` — 접근성 서비스를 내렸다 붙여 서버가 «앱 꺼짐»으로 본다
- 실물 카카오 픽커 누르기 · 수락
- 관제앱의 필터 · 설정 단추 누르기
- 실서버(EC2) 쓰기 · git push · 파일 지우기
- 로컬 서버 끄기 — 판 시작 R0 의 `pnpm reset:calls` 만 허락됨
- 관제앱 콜 줄의 «이 콜 처리» 메뉴(배차 방출 · 사무실 취소) — 시나리오에 적힌 단계가 아니면 사진으로도 열지 않는다(10-10 «✕ 닫기»로 알고 눌렀는데 «배차 방출»이었음 · 로컬 취소 횟수 +1)
- 폰 설정 바꾸기(`settings put` · 화면 꺼짐 · 밝기 · 개발자 옵션 등) — 기사님 폰 값이다. 필요하면 관제 세션에 묻는다
- **화면 확인 없이 여러 번 연달아 누르기** — 광고가 끼면 다른 앱 · 브라우저가 열린다(10-09 실제로 일어남)

## 3. 누르는 법
- 누르기 전마다 `adb shell dumpsys window | grep mCurrentFocus` 로 앞 화면을 본다
- 사진은 `adb exec-out screencap -p` → `sips -Z 1000` 로 줄여 읽는다. 좌표는 줄인 사진 기준 (x·1080/461, y·2340/1000)
- 앞 화면이 이것이면:
  | 앞 화면 | 할 일 |
  |---|---|
  | `…ads.AdActivity`(JoyStick 광고) | 위 띠 «앱으로 이동 ›» — 실제 좌표 (1007, 60) 또는 띠가 내려와 있으면 (1007, 159). 안 보이면 4초 기다렸다 다시 |
  | 동영상 광고(«동영상 건너뛰기» 오른쪽 위 · ▷| 왼쪽 위) | 건너뛰기 → 플레이 스토어가 열리면 BACK → «계속 ▷» → ✕ |
  | `com.android.vending`(플레이 스토어) | BACK 한 번. «설치»는 절대 안 누름 |
  | `com.sec.android.app.sbrowser`(브라우저) | BACK 한 번 |
  | 그 밖의 모르는 창 | 멈추고 사진과 함께 관제 세션에 보고 |

## 4. GPS JoyStick
- 이미 들어 있는 경로: `이천`(집 → 신둔 29.6km) · `g1a`(상차지 1km 앞 → 모다아울렛) · `g1b`(모다아울렛 → 이안로지스)
- 속도: 경로 재생은 **걷는 속도** 칸 값을 쓴다(지금 100km/h). 걷는 중에는 바꿔도 안 든다 — 바꾸려면 중단 → 다시 시작
- 경로 걸기: 본 화면 → «경로 설정» 라디오 → 아래 고르기 칸에서 경로 이름 → «도착시 멈춤» · «텔레 포트 시작» → 큰 단추 «시작» → 광고 넘김 → **관제앱을 앞으로**(`monkey -p kr.co.onedal.dashboard -c android.intent.category.LAUNCHER 1`)
- 걷는지 확인: `dumpsys location` 의 `Location[fused …]` 에 `mock` 이 있고 `vel=` 이 설정 속도(100km/h ≈ 27.8)인지
- 끝: `am force-stop com.theappninjas.fakegpsjoystick` → 15초 뒤 `dumpsys location` 에 `mock` 이 0 인지 확인(«중단»만 누르면 진짜 GPS 와 섞여 100m 씩 흔들린다)
- 새 경로 파일: 관제 세션이 만들어 `/sdcard/Download/` 에 넣는다 → 메뉴 «GPX 가져 오기 / 내보내기» → «수입» → 검색 → 파일 → «트랙» → 트랙 이름 → 초록 내려받기 단추 → «모든 경로 작성» → «경로 저장하기» → 이름 → «저장»

## 5. 판 순서
1. R0 — `cd onedal-web && pnpm reset:calls` → 콜 0 · `user_filters` 목적지 · 반경이 그대로인지 · 서버 로그 «✅ [Bootstrap 완료]»
   → **원달앱 «본 콜» 기억 비우기**: `curl -s -X POST http://localhost:4000/api/sim/call-memory/round` (개발 서버에만 있음 · 시뮬 회차만 올림 · 들고 있던 콜은 그대로)
   → 원달앱 로그 «🧹 [본 콜 기억 비움] 서버 회차 N» 이 다음 보고 응답 뒤에 서는지 확인 · 이러면 같은 상차 · 하차 · 요금 콜을 다시 써도 된다(요금을 바꿔 가며 피할 필요 없음)
   → 판 도중에는 부르지 않는다 — 시뮬 목록에 남은 옛 콜을 원달앱이 다시 판정해 잡을 수 있다
2. 시작 모드를 저장 칸 `suppliedMode` 로 읽어 둔다 → 끝에 그 값으로 되돌린다(finally)
3. 장면을 차례로 — 장면마다 한도 시간 · try 로 감싸 실패해도 다음 장면으로(G5 · G6 은 맨 끝)
   - 시험 콜은 그 순간 상차 · 하차 목록의 동으로 넣는다(목록 밖이면 원달앱이 «도착지 ❌»로 안 엶)
   - 원달앱은 «상차 + 하차 + 요금»이 같으면 «⏭️ [이미 본 콜]»로 건너뛴다 — 판 시작(R0)에 기억 비우기를 했으면 같은 콜을 다시 써도 된다 · 한 판 안에서 같은 조합을 두 번 쓸 때만 요금을 **천 원씩** 바꾼다(시뮬은 천 원 아래를 버림)
4. 정리 — 진행 중 콜이 남으면 관제 세션에 알린다(하차는 관제 세션이 넘김) · JoyStick 끄기 · mock 0 확인
5. 장부 — `ledger.append` · 장면마다 ✅/🔴/⚪ · 근거 로그 시각 · 사진 경로

## 5-1. 기사님 클릭 목록 — 스크립트가 대신 누른다
원달앱이 하는 일(자동 확정 · KEEP 뒤 닫기 · 안전취소 «취소»)은 누르지 않는다 — 그것을 보는 시험이다. 기사님이 실제로 누르실 것만 그 순간에 누른다(기사님 «가» 10-09).
| 순간 | 기사님이 누르실 것 | 어디 | 비고 |
|---|---|---|---|
| 알람 · 직접 모드에서 콜을 잡을 때 | 목록 줄 → 상세의 확정(인성 «배차» · 화물24시 «배차신청») | A24 시뮬 | 원달앱 «삑» 뒤에(읽는 중에 누르면 상세가 목록으로 돌아감) |
| 손 확정 뒤 KEEP 이 오면 | **«닫기»** | A24 시뮬 확정 뒤 화면 | 원달앱은 손 확정 콜을 안 닫는다(설계) — 안 누르면 다음 콜을 못 잡음 |
| 자동 확정 콜의 결재 | 결재석 KEEP / 거절 | S23 관제앱 | 원달앱 «확정 버튼 클릭» 뒤 |
| 연습 콜(계약 안 함) | 누르지 않음 — 결재석은 «보기만»(누르면 치움) | S23 관제앱 | 결재석이 8초쯤만 뜸(시뮬 10초 귀환) · KEEP 단추 없음(JudgmentSeat.tsx 직접 · 알람 카드) |
| 상차지에서 짐을 실었을 때 | 상차 완료(서 있으면 «도착»만 저절로 섬) | S23 관제앱 단계 시트 | «서 있음 → 도착»만 보는 장면에서는 누르지 않음 · 지나침 장면은 서버가 채움 |
| 하차지에서 내렸을 때 | 하차 완료(착불이면 수령 여부) | S23 관제앱 단계 시트 | 2km 떠나면 서버가 «떠남»으로 채움 |
| 마지막 하차 뒤 귀가 | 필터 창 귀가 단추 | S23 관제앱 | **필터 단추라 스크립트는 안 누름** — «기사님 손 필요» |
| 경보 빨간 줄 | «확인» | S23 관제앱 폰 칸 | 사진을 찍은 뒤 |
| 모드 바꾸기 | 접힌 모드 단추 → 자동 · 알람 · 직접 · 계약 안 함 | S23 관제앱 | 끝에 시작 값(suppliedMode)으로 되돌림 |
