## 2. 설계 — 저장과 넘기는 값을 가른다

- **저장(기사님이 고른 것)**: `user_devices.mode` ∈ {AUTO · ALARM · MANUAL} + 새 칸 «계약 안 함»(§3).
- **넘기는 값(폰 · 판정 · 원달앱)**: shared 한 함수 `phoneModeOf`(이미 있음 — 허락 꺼짐을 알람으로 바꾸는 곳)에 «자동 + 계약 안 함 → `SIMULATION`» 한 줄을 더한다. 서버의 모드 읽기(`getDeviceMode` · `resolveDefaultMode`)도 같은 함수를 지난다.
- 그래서 «넘기는 값 `SIMULATION`»을 읽는 자리(acts 표 · 원달앱 · 판정 · 결재)는 한 줄도 안 바뀐다. 모드 이름으로 가르는 조건문을 새로 만들지 않는다 — 스위치는 «넘기는 값»을 정하는 한 곳에서만 읽는다.
