## 0. 여쭐 것 (운행 동작 · 새 저장 칸만)

1. 🔴 **새 저장 칸 — 잡은 방식 모양.** 콜 장부에 새 칸 둘(«그때 모드» — 자동 · 자동(계약 안 함) · 알람 · 직접 / «상세페이지로 진입시킨 주체» — 원달앱 · 기사)을 더하고, 옛 `capturedVia` 칸과 옛 줄은 그대로 둔다(새 콜부터 새 칸에 적음 · 옛 줄의 AUTO 는 «원달앱이 확정» 뜻이라 새 칸과 섞지 않는다). 가: 이 모양으로 만든다 / 나: 다른 모양. **추천 가** — 한 사실 한 칸(규칙 ③) · 옛 줄을 건드리지 않는다. (71 고침: 옛 줄을 비우는 전제를 뺌)
2. **③ call.mp3 가 멈추는 때.** 가: 결재가 났거나(관제앱 KEEP · CANCEL, 기사님이 폰에서 확정) 폰이 목록으로 돌아오면 — 먼저 오는 것 / 나: 폰이 목록으로 돌아올 때만(결재를 누른 뒤 원달앱이 «닫기» · «취소»를 누르는 1~3초도 계속 울림). **추천 가** — 누른 뒤의 울림은 노이즈다.
3. **확정 안 된 콜(미리보기)의 소리 자리.** 가: 벨 점수를 넘으면 원달앱 폰이 판정 소리를 2초마다 되풀이하고(목록으로 돌아오거나 기사님이 확정하면 멈춤) 관제앱은 울리지 않는다 / 나: 폰은 판정 소리 한 번, 반복(call.mp3)은 관제앱이 지금처럼. **추천 가** — N6 «클릭할 곳에서만»과 같다. 2초는 코드 상수(설정창 없음).

정해 쓰는 것(원칙): 삑은 «서버가 상세 보고를 받았다고 답했을 때» 한 번 — 못 받았으면 판정도 안 뜨니 «곧 판정이 뜬다»는 약속이 거짓이 된다. 삑의 모양은 지금 목록 소리와 같다(삑 한 번 + 강한 진동 · `AlarmSignaler`).
