## 덧 — 33 이 오늘 밟은 함정 (같은 데서 안 넘어지게)

- 계획 우선 훅: 도구 앞 «계획:» 줄은 **짧은 한 줄로 메시지 맨 앞**에 — 긴 글 뒤에 쓰거나 «» 가 많으면 훅이 못 읽는 일이 있었다.
- zsh: 파일 목록은 배열 `F=(a b)` · `"${F[@]}"` — `$F` 는 안 나뉜다. `git commit` 은 `-m` 을 `--` 앞에.
- 복사본 → 본 트리: `git -C <복사본> diff <본 트리 HEAD> -- <파일>` 로 패치를 만들어 `git -C <본 트리> apply --check` 후 적용 — 복사본 기준 HEAD 로 만들면 이미 커밋한 줄이 섞인다. 경로는 늘 절대 경로(지금 위치가 server 면 상대 경로가 어긋난다).
- python 으로 고칠 때 바꿀 글에 작은따옴표가 있으면 heredoc 안 문자열을 큰따옴표 · 세 겹 따옴표로.
- 변이 뒤 되돌리기는 `cp 사본` 으로 — `git checkout -- 파일` 은 내 고침까지 지운다(10-08 한 번).
- 시뮬레이터: 인성 «확정 전 상세»는 10초 뒤 스스로 닫힌다 · 콜 둘을 동시에 띄우려면 시뮬 «개별콜» + `POST localhost:4000/api/sim/calls`(개발 서버 · 인증 없음) · 같은 요금 · 동이면 원달앱이 «이미 본 콜»로 건너뜀 · KEEP 이 쌓이면 다마스 콜이 «차종(다) ❌»(짐칸 참)으로 막힘.
