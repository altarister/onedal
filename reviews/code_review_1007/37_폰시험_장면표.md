- **깔기 전(ef 몫 · ef 의 P6 커밋 뒤 HEAD 로 한 번에)**
  1. 원달앱 판 번호: `onedal-app/app/build.gradle.kts` versionCode 69 → 70 — 커밋 «chore(원달앱): 판 번호 69 → 70 — <들어간 커밋들>».
  2. 원달앱 빌드 · 검사: `cd onedal-app && JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home" ./gradlew -q :app:testDebugUnitTest :app:assembleDebug`
  3. 관제앱: `cd onedal-web/client-app && pnpm build`(끝값 0 — `tsc -b` 포함) `&& npx cap sync android && cd android && JAVA_HOME=(위와 같음) ./gradlew -q assembleDebug` → `android/app/build/outputs/apk/debug/app-debug.apk`

  5. 서버는 로컬 `pnpm dev` — 서버 고침(P2 ⑤⑥ · P4 ④ · 7번)이 도는지 `bootedAt` 으로 확인(올리지 않음 · 폰 먼저 · 서버 나중).
- 로컬 서버(4000)에서. 집에서는 콜 확정 전까지가 원칙 — 확정이 있는 장면은 **시뮬레이터 인성**(실물 계약 없음). 픽커 실물은 수락을 누르지 않는다.
- 장면마다 첫 줄은 «기사님이 누르실 것». 제 준비(시험 콜 넣기)는 기사님이 «준비»라고 하신 뒤에 — 네 칸(제 준비 · 기사님 준비 · 하실 일 · 예상 결과) 먼저.
- 순서는 모드 바꾸기가 적게: 알람 → 자동 → 자동 + 계약 안 함 → 직접 → 끝에 원래 모드로.

## 가. 알람 (A24 알람)

### 1 · 목록에 맞는 콜 → 소리 없이 상세 → 삑 (6 가 · P4 ④)

- 실패: 목록에서 소리 · 관제앱 삑 · 상세를 열었는데 삑 없음.

### 1-2 · 화물24시 손 진입 상세 → 삑 · 판정 (X12 확인 · 69판 장면 6)
- **기사님이 누르실 것**: A24 알람 · 시뮬 화물24시 목록에서 콜 하나를 손으로 눌러 상세 → 그대로 둔다.
- 통과: 삑 한 번 · 관제웹 결재석에 그 콜의 판정(상차 · 하차 · 요금이 목록과 같음) · 원달앱 로그에 «요건 미달 — 상차 주소 짧음(상세정보…)» 없음.
- 실패: 삑 없음 · «요건 미달» · 요금이 잔액 값.
- 실물 화물24시는 시 이름을 줄여 «경기 군포 부곡동»으로 적는다 — 주소 온전 검사가 이것을 짧다고 보는지는 실물이 생긴 뒤(따로 기록).

### 2 · 확정 안 된 벨 콜 — 폰만 2초마다, 관제앱은 조용 (P4 ④ C)

- 통과: 원달앱 «🔔 [판정 소리]» 2초마다 · 관제앱 call.mp3 안 울림 · 상세 대기 끝나 목록 → «🔕 [판정 소리 멈춤]».
- 실패: 관제앱 call.mp3 가 울림 · 폰 판정 소리 없음.

### 3 · 손 먼저 동안은 소리 없음 · 손을 떼면 상세 삑 (6 가 · ef 판단)
- **기사님이 누르실 것**: A24 시뮬 인성 목록을 손으로 천천히 스크롤하는 중에 제가 맞는 콜을 넣는다 → 손을 뗀다.

- 실패: 스크롤 중 소리 · 손을 떼도 상세를 안 엶.

### 4 · 끊긴 동안 «심사 중»에 안 막힘 (X5-a · 번거로우면 뺌 — 단위 검사로 잠금)
