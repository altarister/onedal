## 1. 🔬 마스터 총평 (Executive Summary)

1DAL 시스템은 지난 수개월간 기사님의 실제 도로 주행 피드백(2026-08~09월 실측)이 코드베이스 전반에 매우 치밀하고 실전적으로 녹아들어 있습니다. 카카오 API 호출을 획기적으로 줄이는 Base 캐싱, 화주와의 약속을 지키는 150% 타임라인 사다리, 운전 중 시인성을 극대화한 35:65 심사석 등은 일반적인 상용 배차 소프트웨어 수준을 뛰어넘는 걸작입니다.

그러나 이번 **Line-by-Line 현미경 정밀 리뷰(Part 1~5)**를 통해, **"도로 위에서 즉각적으로 앱이 튕기거나(Crash)", "배차망 계정이 정지되거나(Ban)", "실시간 관제가 영구 먹통(Silent Death)이 되거나", "진동 터치로 인해 홈으로 튕겨 나가는"** 치명적인 결함들이 5개 파트 전반에서 식별되었습니다.

이 결함들은 단독 실전 운행(1월 중순) 이전에 **100% 핫픽스**되어야 하며, 해결 시 시스템의 실전 전투력은 완전무결해집니다.

## 4. 🧠 일반 개발 상식과 충돌하는 아키텍처 특이점 및 잠재적 결함 포인트 (Gotchas)

| 영역 | 일반 개발 상식 (기대치) | 1DAL 실제 아키텍처 (현실) | 잠재적 결함 및 주의 규약 |
|---|---|---|---|
| **세션 계층** | `UserSession`이 하위 `devices` 정보를 포함/소유 | `UserSession`과 `DeviceSession`은 물리적·메모리상 완전 분리 (독립 저장소) | `session.devices` 호출 시 런타임 `TypeError` 크래시 발생. 기기 모드는 반드시 `getDeviceMode(deviceId, userId)` 파사드 함수 사용 필수 |
| **테스트 체계** | 단위 테스트 720건 통과 = 화면 렌더링 무결점 | 정규식 문자열 스캔(`codeOnly`) 및 단편 Mock 위주로 실제 DOM 트리 미마운트 | 부모-자식 Prop 누락이나 스코프 미선언 변수(`ReferenceError`)가 은폐되어 사용자에게 WSOD(화이트스크린) 노출. RTL 마운트 스모크 테스트 필수 |
| **취소·종료 파이프라인** | 개별 호출부/이벤트 핸들러에서 조건부 취소 처리 | 5개 이탈 경로가 존재하여 각자 처리 시 가상 콜이 실제 기사 패널티로 누수 | 도메인 코어 `core/cancelCount.ts` SSOT 내부에서 가상 콜 판별 및 페널티 차단을 단일 캡슐화 |
| **데이터 영속성** | 메모리에 콜 객체가 존재하면 SQLite DB에도 행 존재 | 가상 체험 콜은 RAM(`myOrders`)에만 적재, SQLite `orders` 테이블에는 미저장 | DB 조회를 전제로 하는 `birthFirstStep` 등 하위 로직 호출 시 외래키/조회 예외 폭발. 반드시 `!isSimulated` 가드 필수 |
| **소켓 이벤트 구독** | 필요한 훅/컴포넌트에서 자유롭게 소켓 이벤트 리슨 | 소켓 리스너 다중 바인딩 금지 (단일 리스너 계약 강제) | 여러 컴포넌트가 직접 리슨 시 메모리 릭 및 상태 불일치 발생. Zustand 전역 스토어를 단일 바인딩 후 store를 구독 |
