# 📚 1DAL 서버(Node.js) 공식 문서 인덱스

이 문서는 1DAL 백엔드 서버(`/onedal-web/server`)의 아키텍처, 데이터 모델, 핵심 비즈니스 로직을 완벽하게 파악하기 위해 **앞으로 작성될 문서들의 리스트(List-up)** 입니다. 안드로이드 앱의 문서 구조와 1:1로 대응되도록 설계되었습니다.

---

## 🏛️ 1. 아키텍처 및 시스템 개요 (Architecture & System)

| 문서명 | 설명 | 앱(App) 대응 문서 |
|--------|------|-------------------|
| `SERVER_ARCHITECTURE.md` | 서버 전체 구조도, 폴더 스펙, 요청 처리 파이프라인(Routes -> Engine -> DB), 다중 앱 플러그인 연동 구조 | `APP_BLUEPRINT.md` |
| `SERVER_TASKS.md` | 서버 리팩토링 및 기능 추가를 위한 작업 진척도 (체크리스트) | `TASKS.md` |

## 🧬 2. 데이터 흐름 및 상태 관리 (Data & State)

| 문서명 | 설명 | 앱(App) 대응 문서 |
|--------|------|-------------------|
| `DATA_MODELS.md` | SQLite DB 스키마(v5) 및 인메모리 세션(`UserSessionStore`, `ActiveFilter`) 구조체 정의서 | `DATA_MODELS.md` |
| `DISPATCH_STATE_MACHINE.md` | 백엔드 합짐 관제 상태 머신 (`STANDBY` ➡️ `GATHERING` ➡️ `DRIVING`) 전이 다이어그램 | `SCREEN_STATE_MACHINE.md` |

## ⚙️ 3. 핵심 비즈니스 로직 (Core Engines)

| 문서명 | 설명 | 앱(App) 대응 문서 |
|--------|------|-------------------|
| `ORDER_EVALUATION_FLOW.md` | 콜 심사원 3단계 파이프라인 (형상 필터 검증 ➡️ 카카오/OSRM 궤적 연산 ➡️ 장/단점 라벨링) | `API_SPEC.md` |
| `PRICING_ENGINE_SPEC.md` | 다이내믹 요율 엔진 계산 공식 (차종별 단가, 수수료, 마진율, 수용 하한선 산출 알고리즘) | `EDGE_CASES.md` |
| `ROUTING_ALGORITHM_SPEC.md` | 합짐(Detour) 최적화를 위한 TSP(외판원 문제) 경로 정렬 알고리즘 및 카카오/OSRM 연동 명세 | (서버 전용) |

## 📡 4. 통신 프로토콜 및 API 명세 (Communication)

| 문서명 | 설명 | 앱(App) 대응 문서 |
|--------|------|-------------------|
| `API_SPEC.md` | 서버가 노출하는 모든 REST API 엔드포인트(`/api/scrap`, `/confirm` 등) 명세 및 응답 형태 | `API_SPEC.md` |
| `PIGGYBACK_PROTOCOL.md` | V2 피기백(Piggyback) 프로토콜 명세 (하트비트(`/api/scrap`) 응답에 관제탑 결재/명령을 태워 보내는 구조) | `API_SPEC.md` (통합됨) |
| `SEQUENCE_DIAGRAMS.md` | 앱 ↔ 서버 ↔ 관제탑(React UI) 간의 콜 캡처부터 배차 확정까지의 실시간 소켓/REST 통신 시퀀스 | `SEQUENCE_DIAGRAMS.md` |

## 🧩 5. 확장성 및 플러그인 (Extensibility)

| 문서명 | 설명 | 앱(App) 대응 문서 |
|--------|------|-------------------|
| `PLUGIN_INTERFACE_SPEC.md` | 서버용 다중 앱(인성콜, 24시 등) 지원을 위한 인터페이스(주소 정규화, 예외 요율 처리 등) 스펙 | `PLUGIN_INTERFACE_SPEC.md` |

## 🧪 6. 테스트, 예외 처리 및 환경 설정 (QA & DevOps)

| 문서명 | 설명 | 앱(App) 대응 문서 |
|--------|------|-------------------|
| `TESTING_STRATEGY.md` | 리팩토링된 서버 모듈(`PricingEngine`, `OrderEvaluator` 등)을 안전하게 검증하기 위한 단위/통합 테스트 전략 | `TESTING_STRATEGY.md` |
| `EDGE_CASES.md` | 카카오 API 장애/리밋, OSRM 대체, SQLite DB Lock, 고스트 응답(Ghost Defense) 등 서버 예외 상황 및 복구 시나리오 | `EDGE_CASES.md` |
| `ENV_CONFIG_SPEC.md` | 백엔드 구동에 필요한 `.env` 환경 변수(KAKAO_REST_API_KEY 등) 및 포트/설정 파일 명세 | (서버 전용) |
